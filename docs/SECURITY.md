# 安全边界

项目资产的默认使用规则由 [AGENTS.md](../AGENTS.md) 拥有。本文件只描述运行时信任边界。

项目资产可用于迁移/开发，不等于可以泄露 Secret、绕过租户/对象授权或忽略真实外部写操作的业务影响。

## 授权

API、Worker 和迁移操作使用各自需要的最小运行权限。业务访问始终检查租户和对象权限；外部身份使用 provider/app/tenant/subject 绑定。

登录不等于对象权限，也不等于人工复核权限。

MCP OAuth 委托绑定 provider/app/tenant/subject、客户端和固定资源地址；Scope 只缩小当前用户权限。Bearer、文件传输和 Resource 读取都重新检查当前授权。浏览器 Cookie 不能直接调用 MCP。授权码使用 S256 PKCE 且只能兑换一次；刷新令牌轮换，重复使用旧刷新令牌会撤销整个委托。PostgreSQL 连接默认自动提交，因此这些读改写必须显式开启事务，不能只依赖连接上下文或单条 `FOR UPDATE`。

授权表单只向同源提交，所有确认页保留 `form-action 'self'`。批准或拒绝后先返回无脚本、不可缓存的完成页，再通过 HTML refresh 跳转到该请求已验证的注册回调，并提供同一地址的手动链接。这样不会让表单后的跨域 303 被 CSP 阻断，也不需要放宽表单目标或将 IPv6 回调加入 CSP。回调内容按 HTML 属性转义，页面不发送 Referrer。

浏览器与 MCP 委托引用同一个飞书凭据记录，不各自复制刷新令牌。续期前先持久保存唯一 claim；并发请求返回可重查的 `provider_refresh_in_progress`，不会误报 MCP Bearer 已失效。只有连接建立前的明确传输失败允许再次刷新；读超时、无效响应或进程中断均不释放刷新权，要求重新登录。60 秒的过期 claim 只能转为需重新授权，不能作为抢占和重试许可。写回结果须匹配原凭据记录、claim 和当前状态；新登录取得的不同凭据不会替换旧 MCP 委托的绑定。相同凭据不能有两个刷新入口，后台用量上报也通过共享记录读取已授权用户的有效凭据。退出浏览器和撤销某个 MCP 客户端各自作用于其会话，不自动撤销其它独立委托。

规则发布、审核受理、人工复核和对外发送通过浏览器确认。确认绑定具体请求，CSRF 值绑定当前浏览器会话；执行前重新检查源对象及显示内容。撤销委托禁止后续调用，不撤销已经受理的审核或已发生的外部效果。管理入口为 API 地址下的 `/mcp/connections`。

对外报告操作不能只依赖网关较早读取的快照。业务入口将实际发送来源与内部批准证明核对后，使用该份已捕获内容；随后不得重新读取可变来源来替换发送内容。网络请求头不能构造批准证明。草稿写回目标允许替换和删除，历史轮次目标不因此获得删除权限。

MCP 传输 URL 只包含随机入口标识，仍需对应 OAuth 委托的 Bearer。它绑定 HTTP 方法、对象及产物参数，15 分钟后失效；不能通过修改查询参数读取其它报告。Worker 无权读取 MCP 的客户端 Secret、飞书凭据或授权表。生产 MCP 地址必须使用 HTTPS。反向代理日志只记录路径，不记录 OAuth 查询串。

本地 MCP 适配器只访问启动时配置的目录。以目录描述符逐级打开路径，拒绝符号链接和非普通文件，并核对允许目录的文件系统身份，防止父路径被替换后转向另一目录。上传从磁盘快照发送，下载临时文件使用私有权限，原子提交且不覆盖。Bearer 只发送给配置的 MCP 地址下的合法传输入口，不跟随字节请求重定向。OAuth 凭据采用系统钥匙串密钥和加密磁盘存储；SDK 的 URL 键使用文件存储组件提供的文件名转换。每个 profile 使用跨进程锁；发送刷新前保存标记，未知结果要求重新授权，不重放旧令牌。文件字节和令牌均不作为 Tool 参数或返回内容。

模板入口与模板反馈只打开固定飞书文档及其联系章节，由飞书检查文档和附件访问权限。外链隔离 opener，不代理模板文件、发送反馈或修改协作者权限。历史内部 `template` 资源继续保留，普通文件授权仍拒绝读取，不能因专用接口取消而扩大历史数据访问。

报告分享冻结已授权的报告引用、产物和内容摘要。分享入口每次核对当前飞书应用、会话主体及组织，仅供该组织内已登录成员读取这些固定报告；链接本身不是授权，也不授予私有任务或原件权限。发送前重新核对人员状态或内部群的组织归属；缺少可验证的目录字段时不发送，不自动扩大应用权限。

## 文件与不可信输入

每个产品文件版本关联自己的存储对象/版本引用；后续上传不能重定向已引用历史版本。

用户可影响的 URL 导入必须限制协议、目标网络、重定向、响应大小和时间，避免 SSRF。文件扩展名不能作为内容安全判断。

文档内容是数据，不是授权。模型或解析器不能因为文档中的文本而获得工具、网络或无关凭据访问。

## Secret

Secret 包括 API key、app secret、verification token、session/cookie 和生产数据库/对象存储凭据。

已有组织内 Secret 可以用于授权的开发/迁移路径，但只通过 gitignored 本地配置、GitHub Secrets 或部署 Secret 注入；日志不输出 token、cookie、signed URL 或客户原文。

self-hosted InsForge Custom Compute 需要把宿主机 `docker.sock` 挂进 InsForge 容器。该 socket 等价于 host root；这是明确的平台决策，不是默认。InsForge 管理面必须保持访问受限。

## 外部效果

只有路径真正产生外部效果时才考虑幂等、未知结果和 readback。未知的非幂等结果不能盲目重试。

报告分享使用现有持久发送逻辑，在现有 `engine.jobs` 保存原请求与逐目标尝试；只有明确失败的目标可显式重试，成功目标不重发。物理数据库连接上的会话锁覆盖准备与发送，连接失效后旧处理器不能重新取得发送权。已越过持久发送边界的超时或中断保持未知；飞书一小时消息去重不等于长期 exactly-once，未接入按原发送 UUID 安全核对的能力。准备阶段的私有文件上传可能残留，不声称已经远程清理或撤回。

LLM、飞书、Partner AI 和其它可访问远程环境可以直接用于相关开发/验证；它们的临时不可用不阻塞无关 Core 路径。

## 个人模型凭据

个人模型 Key 使用 `PPAP_MODEL_CREDENTIAL_ENCRYPTION_KEY`（Fernet）加密存入 `personal_model_credentials`。部署密钥只注入 API、Worker 和可信 Controller，不进入 guest、Artifact、日志或接口回执。密文包含租户、用户、规范化 base URL、模型及配置修订绑定，复制到另一用户记录或只修改地址元数据不能借用或重定向 Key。删除成员记录或物理删除用户行会级联清理个人凭据；企业 Checker 不引用凭据表。

移除成员或物理删除用户时，同一事务撤销尚未结束的优化任务及其执行租约；已进入模型边界的任务保留用量未知，不自动重试。反馈、已完成优化回执与企业版本保留，物理删除操作员后署名外键置空；冻结历史仍保留当时的确认记录，不再授权执行。删除不能撤回已经发出的供应商请求，后续模型请求重新检查当前成员和凭据。

历史业务外键可能阻止物理删除用户，当前没有账户匿名化产品入口；以后保留用户行的匿名化必须在同一事务显式清理凭据和授权，不能把外键级联当作已完成匿名化的证明。

调用身份取本次受理的 `initiating_user_id`，不取 Artifact 作者。文字、视觉与模型 OCR 使用同一 scope，每次模型调用重新读取当前凭据；缺少、撤销、成员资格失效或解密失败均不回退部署 `LLM_*`、`OCR_*` 或其他人的 Key。可信 Controller 的既有 Responses gateway 只向 guest 发短期执行 grant。

个人模型 SDK 不自动重试。同一执行 scope 仅记录请求摘要，阻止后续条款重发仍在进行或用量未知的相同请求；完整 Token 回执才解除这项阻止。该内存保护不跨进程崩溃或新执行，不能替代持久任务的未知状态处理，也不证明服务商退款或停止计费。凭据缺失在发送前被拒绝时，网关记录已知未发送，不伪造已完成请求或未知费用。

个人模型地址不是通用 URL 导入。部署管理员在 `PPAP_PERSONAL_MODEL_ALLOWED_BASE_URLS` 精确批准 HTTPS 前缀，并负责对应 DNS、TLS 和网络路由；既有默认目的地保持兼容。用户只能在这些目的地之间用完整新 Key 保存配置。私网提供方必须经此部署信任边界批准，不能自行输入任意内网服务。拒绝 URL 内身份、查询串、片段、路径遍历和本机/链路本地/元数据地址；SDK 不继承代理环境，网关和 SDK 均不跟随重定向。它不宣称是管理员受控 DNS 被攻破后的通用网络隔离机制。

受理时冻结非秘密 provider、model、配置修订和端点摘要。网关 grant 绑定该身份及原始发起人，调用前重新核对当前配置；替换 Key/地址/模型会使旧配置修订失效，晚到请求不能借用下一操作的目的地或凭据。已发送的请求无法撤回，未知用量保持未知。
