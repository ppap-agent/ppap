# PDF 的观察与表格建模

PDF 的文本读取顺序不等于表格行序。优先使用已提供的原件快照：`pages` 保留页码、页面尺寸和文本块；`tables` 保存成功读取的页内原生网格，表 ID 为 `page-N`。`coverage` 明确哪些页有网格、哪些页仍未解析。没有网格不等于该页没有业务内容。

把一页分为标题/元数据、表头、正文和页脚等区域。通过边界线、文本对齐及表头关系建立候选网格。合并单元格是跨行或跨列的区域，不是几个缺值格。多行文字可能属于同一单元格，按换行直接切记录会改变业务含义。

网格单元格的 `source.page/bbox` 来自原 PDF，使用左上角为原点的 PDF 点坐标。引用使用调用方 schema 的 `pdf_cell`，填写真实 page、row、column；宿主从冻结网格解析位置与内容。页内行列不是 Excel 坐标，也不接受模型自行补出的 bbox。表外文字仍用原 `pdf_block` 引用。

每页分别建立 Binding，再由同一 input use 覆盖相关页。续页先确认业务表关系、列位置、上下页记录衔接；不合成跨页行号，也不默认删除每页第一行。第一页之后的无表头续页可用空 `header_rows`，映射依据须说明实际续页关系；这种绑定不能声明已确认缺字段。若记录跨页拆开或需要跨页字段关系，按缓存程序使用明确的局部 Judge；不能把多个片段伪装成同一物理行。

未知网格槽位、图片或未解释矢量内容重叠的空白单元格和异常几何分别保持未知。已提取的非空原生文字可参与文本判断，但不证明图片或视觉符号已经解释。重建子格内部没有文字，不证明包围它的原区域没有图形，也不证明勾选状态。超页坐标不裁剪成“已验证”位置；旋转页、非零裁剪原点或未解析页不能据文本块臆造表格绑定。与规则有关而尚不能绑定的范围，在相应 input use 中写入 `unresolved_scopes`，保留已有有效绑定。

文字跨格时，从字符/词位置核对网格边界；无法可靠分配就保留原块，并检查页面图像。文本稀少可能是扫描件，也可能关键内容在图片内。勾选、符号、签章及视觉层级需要对应区域图像。

优先先验证一页上的表头和几个有辨识度的记录，再批量应用到结构相同的页；每页仍检查列结构与边界。保留实际覆盖的页和区域。没有可靠关联的正文不能因抽取为空而通过。

原生网格读取不执行 OCR。扫描文字、勾选、向量符号和签章仍需对应页面图像及实际识别；未解决时保留未知。当前宿主计算直接读取原 PDF 网格，不将派生工作簿坐标当作原件定位。
