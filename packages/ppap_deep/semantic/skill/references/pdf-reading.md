# PDF 的观察与表格建模

PDF 的文本读取顺序不等于表格行序。先记录页码、页面尺寸、文本块及 bbox；需要表格时保留词或字符级几何证据。`document_tools.py inspect` 提供文本块观察，不自动声称恢复了行列。

把一页分为标题/元数据、表头、正文和页脚等区域。通过边界线、文本对齐及表头关系建立候选网格。合并单元格是跨行或跨列的区域，不是几个缺值格。多行文字可能属于同一单元格，按换行直接切记录会改变业务含义。

建模的最小记录为：`page, bbox, text, row_span, col_span, extraction_method, state`。在映射到业务字段时保留这些来源。坐标以实际页面观察确定，不在可复用 Skill 中固化某供应商的固定位置。

跨页拼接前检查：相同业务表、表头语义兼容、列次序有可验证映射、上一页尾部与下一页首部是否为同一记录。只去除已确认的重复表头；不默认删除后续每页第一行。列重映射后出现单元格重叠或文字丢失时，拆开处理并保留未知状态。

文字跨格时，从字符/词位置核对网格边界；无法可靠分配就保留原块，并检查页面图像。文本稀少可能是扫描件，也可能关键内容在图片内。勾选、符号、签章及视觉层级需要对应区域图像。

优先先验证一页上的表头和几个有辨识度的记录，再批量应用到结构相同的页；每页仍检查列结构与边界。保留实际覆盖的页和区域。没有可靠关联的正文不能因抽取为空而通过。

允许调用现有 PDF 提取工具，前提是其输出保留来源并适用于当前观察。是否转换成 Excel 是实现选择，不是每份 PDF 必须满足的假设。
