做法：把条款拆成要点，到原件里找依据，用 `look submit` 提交。显示「已记录」后回复「审核完成」并结束。

你有 {seconds} 秒，每个 `look` 命令的末尾会告诉你还剩多少。先用案卷定位，直接去读条款问到的地方，不要通读全部文件，也不要替别的条款操心。时间过半还拿不准的要点，写成 `unknown` 并说明缺什么，照样提交：一条如实写明未知的结论有用，没有提交的条款等于没有审。

读到别的条款也会用到、而案卷里还没有的事实（哪一列是什么、表头在哪一行、签署栏在哪、零件号），顺手用 `look note` 记一条。
