# 读表格和页面

## 合并与空白

只有属于真实合并区域的格子才继承左上角的值。普通空白不向下填充：上下两行相似，中间的空格也可能是真的漏填。

纵向合并常表示多条记录共属一道工序；继承工序名不会把这些记录变成一条。横向合并跨多个字段时，先看它是标题、备注还是一个值。

数字 0 和 FALSE 是值，不是空白。空白、没有这个字段、公式无缓存值、读不到，是四件不同的事。图章、签名、勾选控件不在单元格文字里，不能凭单元格为空就说没有。

## 多层表头

先找出互相支持的一组表头和它下面的正文，再解释单个词。表头常跨几行：沿着列向上收集父子标签，例如「特性 → 产品」「抽样 → 频率」。

同一个词在不同父标签下是不同字段：「日期」可能在编制、修订或批准下面；「产品」可能是产品名称，也可能是特性的子列。表名和工作表名只是线索，以表内的内容为准。

## 哪些行是正文

先界定候选区域，再判断每一行是不是业务记录。编号、边框或空行都不能单独决定。结合填写内容、列的分布、重复出现的表头、分节标题、修订履历和脚注来区分。

正文行可以没有工序号却仍有检验项目或控制方法，它是上一道工序的后续记录，不能因为编号为空就排除。已经确认是业务记录的行，必填项空着就是空着，不能把它改判成「未用的模板行」。

## 扫描页和图片文件

没有文字层的页只能看图。做法：先 `look ocr` 整页转写，知道这页写了什么；再对条款关心的内容（零件号、日期、签名、数值）用 `--grid` 找到位置，`--clip` 放大后自己看图确认。转写和你看到的不一致时，以放大后看到的为准；放大后仍分不清的字，就是未知。

引用扫描页的内容时写 `"seen": true`，`where` 写 `page:页码`，`quote` 写你确认看到的内容，并写上放大的位置 `clip`。

## 图章、签名和图形符号

- 受控章、签名、特性符号常是内嵌图片：`look pictures` 列出它们锚在哪个单元格，`look picture` 取出来看。同一张图可能被多处引用。
- 流程图的符号可能是绘制的图形（`look pictures` 会列出形状和附近的单元格），也可能是单元格里的字符（□ ◇ △ ○）。两种都要看。
- 图形之间的连接和相对位置只有渲染后才看得出：`look render` 看整页。
- 章内文字、签名是否手写，要放大到看得清再判断；看不清就写未知，不要按「大概是」下结论。
