详细需求说明：

### 一、 封面页（CoverSheet）审核需求
**1. 基础信息完整性（条款1）**
*   **页面检查：** 必须存在名为“CoverSheet”的页面。
*   **字段识别：** 页面中必须包含以下五个关键字段：**零件号、零件名、项目、项目阶段、日期**。
*   **内容检查：** 以上五个字段对应的填写内容均**不能为空**。

### 二、 测量报告页结构与内容审核
**2. 核心列完整性（条款2、5）**
*   **列表识别：** 报告中必须包含：测点号、坐标 X/Y/Z、上公差、下公差、主要控制方向等列。
*   **行内容检查：** 当“测点号”列有内容时，其同行的坐标值、公差及控制方向列内容也**不能为空**。
*   **类型审核：** 必须存在“类型”列，且其内容仅限 **“CC”、“SC”或“AC”** 三种。

**3. 特定方向下的公差逻辑（条款3）**
*   **规则：** 当“主要控制方向”为特殊值（如 **ND, Gap, Flush, ND-, Gap-, Flush-**）时：
*   **判定：** 对应的“上公差”和“下公差”必须填写为 **“NA”**。

**4. 坐标方向下的数值逻辑（条款4）**
*   **规则：** 当“主要控制方向”为坐标轴或特定方向（如 **X, Y, Z, ND, Gap, Flush** 等）时：
*   **判定：** 对应的“名义值”应为空，但“测量偏差值”必须存在内容。

### 三、 图表一致性与偏差校验
**5. 图文对标审核（条款6）**
*   **测点匹配：** 报告中“测点图/截面”区域标注的所有标记点，必须能在下方的“测点号”表格列中找到一一对应的行。

**6. 偏差范围校验（条款7）**
*   **适用类型：** 针对 Hole&Slot、Surface、Trim、SubDatum、Gap&Flush 等测量表。
*   **判定标准：** “测量偏差值”必须在公差范围内。
    *   **计算公式：** 偏差值需处于 `[名义值 + 下公差, 名义值 + 上公差]` 之间。
    *   **默认值：** 若“名义值”为空，按 **0.00** 计算。

### 四、 统计指标计算与预警（对中性与极差）
**7. 对中性（Centering）计算与审核（条款8、9）**
*   **适用条件：** 方向为 X/Y/Z/ND，且偏差值（Part1...PartN）不为空，且公差不为“NA”。
*   **计算公式：** `Centering = (-名义值 + 实测平均值) / (上公差 - 下公差)`。
    *   *注意：计算平均值时需剔除空格。*
*   **判定等级：**
    *   **不通过：** 绝对值 > 0.66（系统需提醒用户具体哪些行超标）。
    *   **通过但预警：** 0.33 < 绝对值 ≤ 0.66。
    *   **通过：** 绝对值 ≤ 0.33。

**8. 极差（Range）计算与审核（条款10、11）**
*   **适用条件：** 方向为 X/Y/Z/ND，且偏差值不为空，且公差不为空或不为“NA”。
*   **计算公式：** `Range = (实测最大值 - 实测最小值) / (上公差 - 下公差)`。
    *   *注意：计算极值时需剔除空格。*
*   **判定等级：**
    *   **不通过：** 绝对值 > 0.66（需提醒用户具体超标行）。
    *   **通过但预警：** 0.33 < 绝对值 ≤ 0.66。
    *   **通过：** 绝对值 ≤ 0.33。
