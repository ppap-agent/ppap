# UAES 规则库版本

改动 UAES 规则、条款检查结果、规则确认问卷或 UAES 检查程序的条款正文前，先读本文件。

## 版本与修订

- **版本**（v0.0、v1.0、v2.0……）由条款集合决定：条款数量或新旧条款的对应关系变了（新增、删除、拆分、合并），就升版本号。只升第一位，第二位固定为 0。
- **修订**（m0、m1、m2……）是同一版本内的改动：条款集合不变，只改条款内容。
- 每个版本的 m0 是这个版本最初的原件；之后每一步修订都从上一修订出发。客户发来的新稿同样按这条判断：条款集合没变是新修订，变了是新版本的 m0。
- 已确认的修订冻结，不再改；只有已确认的修订能在线上跑审核。
- 一份修订里每处与上一修订不同的地方都要能追到来源：问卷答复、客户裁决，或原件里的修订与裁决说明。说不出来源的改动不进修订。
- 经他人转达、没有客户原始答复记录的口径，不当作客户已确认。
- **确认人是产品负责人**：候选是否成为下一修订、同一问题答复不一致时取哪一种，都由产品负责人决定。

## 一轮修订怎么走

1. **出问卷**：对当前修订跑条款检查，把发现的问题做成卡片；平台自己裁定或新增、客户还没确认的内容也做成卡片。用 `questionnaire.py load` 导入要作答的企业，可以导入多个企业，各企业的答复分开保存。
2. **整理候选**：根据答复写候选，线下 Markdown，放在 `assets/uaes/rulebook/<版本>/候选 m<i+1>.md`，一个版本同时只有一份。候选随答复反复修改，不跑审核。
3. **确认**：产品负责人看候选并确认。
4. **落版**：确认后生成 `rulebook/<版本>/m<i+1>/`（若答复要求增删、拆分或合并条款，则生成下一个版本的 `m0/`），写对照，删除候选文件（历史在 Git 里）。上一修订的问卷用 `questionnaire.py close` 关闭，答复保留可查。
5. **上线**：更新检查程序（见下文），作为系统规则的新版本整套部署到 ppap-test，在现网核对规则页和审核结果。
6. **下一轮**：对新修订重新跑条款检查、出新问卷；上一修订的问卷不搬过去，已答清的问题不再问。问卷全部答完、条款检查也查不出问题时，这一修订不再是「待澄清」。

## 候选怎么写

候选要让产品负责人不用翻别的文件就能决定，信息给全，但按决定需要的顺序排：

- 开头一段：基于哪个修订、问卷答了几张、还剩几张、有几处答复不一致；这次建议改几条。
- **要你决定的**放最前：答复不一致的卡片，并列每个人的答复（署名、时间）和建议取哪一种、为什么。
- **建议修改**：逐条写条款编号和名称、当前原文、建议改成的原文（改动处标出）、依据的卡片和答复人；改了条款集合的单独标明，确认后会升版本。
- **不改的**：已答复但不需要改条款的卡片，写一句为什么。
- **还没答的**：列出卡片，说明这一轮不处理、会在下一修订的问卷里重新出现。

## 用户看到什么

产品里遵循「不让用户思考，但不隐藏信息」：

- 规则页显示当前版本和修订，用户的话写作「v1.0 修订 1」，不显示 m1 或内部编号。
- 「待澄清」的修订在规则页标出，并写明还有几个问题待确认；每条条款下直接挂它的问卷卡片，点进去就能作答。
- 和上一修订相比改了哪些条款、依据是什么，在规则页能看到，不用另找文档。
- 审核结果里，因规则更新、检查程序还没改好而没检查的条款，写明「规则已更新，暂未检查」，不显示成通过，也不显示成出错。
- 重审时有更新的修订或版本，默认用新的，提醒「审核规则已更新」，用户可以沿用上次的。

## 目录

- 每个已确认的修订放在 `assets/uaes/rulebook/<版本>/<修订>/`：规则库原件或修订文本、逐类抽取的 `rules/*.json`、通用判定说明。入库后不改。
- 条款检查的审查记录与报告、问卷导入文件、检查程序使用的条款正文，都从对应修订的这些材料生成，不各自维护另一份。
- 每次升修订或升版本，在目标版本目录里附一份对照：每条新条款对应哪条旧条款，按判定结果是否会变分为「意思不变」「意思变了」「新增」，删除或合并的写明去向，并列出每条相关的问卷卡片。
- 卡片用条款编号（如 `CP:8`）指向条款，检查程序用同一套编号，不另建映射。旧编号不复用。
- 版本和修订靠目录与 Git 历史识别，不另建台账或清单。

## 检查程序与审核

- 检查程序按文件类型成组。条款意思变了的文件类型，以及读取这些类型的关联类型，重新验证；没变的沿用原程序。
- 程序判断与新条款意思一致的，重新验证后沿用；意思变了的条款和新增条款，在程序改好前一律记未检查，不借旧程序给结论。
- 人工判定样本只在条款意思不变时沿用；意思变了的，按新条款请人工复核。
- 已受理的审核轮次仍用当时冻结的规则和程序，不改写历史。
