# v0.0 修订 1（线上 52 条）→ v1.0 修订 0（63 条）对照

「线上」即 v0.0 修订 1：`packages/audit/src/audit/checkers/uaes/U01`–`U19` 里检查程序使用的 52 条（客户 52 条稿加 2026-11-13 控制计划裁决）。v1.0 修订 0 是 `m0/` 里的原件。按条款文字比较：对同一份提交文件，新旧条款给出的通过／不通过／待审核结论是否会不同。只要能举出一份结论不同的文件就算「意思变了」。标「待复核」的是新旧文字本身读不准、需要人再看的。

「问卷卡片」是 `assets/uaes/clause-check-semantic-v2/问卷导入.json` 里涉及该条的卡片编号。

比较只看条款文字，没有追溯线上旧的通用判定口径（例如占位词“/”“TBD”算不算已填）；把它算进来，部分「意思不变」的条款也可能变。检查程序实际怎么判，上线前另行核对。
