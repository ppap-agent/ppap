# PHOTO:1 条款语义检查报告

- **规则文件**：生产件样品照片（UAES 审核规则库 规范性条款 v1.0）：UAES-PHOTO-图片格式-校验（PHOTO:1）
- **规则原文**：提交的生产件样品照片文件必须为图片格式（jpg／jpeg／png／bmp／tif／tiff）；文件属于图片格式时通过，否则不通过。 判定以文件头魔数为准，扩展名不作为唯一依据：魔数属括号所列图片格式之一即符合；WebP 等未列入的格式不能通过。文件为 0 字节、或文件头不足 4 字节无法判型的，属文件对象不可获取，按不通过处理并提示补交原始图片文件，不记未审——“未提交可读文件”与“证据无法辨识”是两件事，前者按缺件处理。 非图片容器一律不通过，不以内含实物图像作为替代载体：.pdf／.xlsx／.xls／.docx 等文档容器，即使内含可提取的实物照片或其缩略预览图，也不构成本条通过条件；带表头与签章的《样品照片报告》PDF 同样判不通过。执行时不得以“容器内确有图像对象”为其放行，也不得把“可提取图像”当作图片格式的等效载体。 此处为本册保留的口径，与“允许内嵌清晰实物照片的 pdf／xlsx／docx 样品照片报告”不同；对外说明时须按本册口径表述，不得混用两种载体标准。容器内确有图像对象的，仍按“载体不符”判不通过，并在依据中写明该容器内含 N 个图像对象、建议供应商改交原始图片文件；此类情形的整改指向是改交载体，不是重拍照片。 同批多张照片分多个文件提交时，逐份判定，每份都须满足图片格式；不得只判第一份而把其余记作不适用。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **扩展名写 .jpg 而实际是 PNG 时如何判**：原文以文件头为准，PNG 在所列格式内，结论唯一为通过。
- **PDF 照片报告内照片清晰能否通过**：原文明确容器内有图也判不通过，并说明这是本册保留口径。
- **同批一份 jpg 一份 PDF 时如何判**：原文要求每份都须是图片格式，PDF 不满足，结论唯一。
