# SSH:1 条款语义检查报告

- **规则文件**：样品阶段履历（UAES 审核规则库 规范性条款 v1.0）：UAES-SSH-工程更改一览表-字段校验（SSH:1）
- **规则原文**：样品阶段履历文件必须包含“工程更改一览表”；表中须有“项目”“零件号”“变更内容简述”“变更原因”“时间”五个字段或列（“时间”列的同义写法含“日期”“变更时间”“变更日期”）。字段或列名称含义相近的，按满足要求处理。缺表或缺任何一类字段即不通过。 表头存在疑似同义、但归一化后既不能确认等价也不能确认缺失的列名（如“变更履历”“其他”“备注”），交人工裁定并写明原列名，不判不通过。 本句只兜真正的模糊词：已能对应到五个字段的词（“变更说明”“更改日期”“修订记录”）按本条前文“字段或列名称含义相近的，按满足要求处理”执行，不得塞进本句转人工。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
