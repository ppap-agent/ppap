# MSA:5 条款语义检查报告

- **规则文件**：测量系统分析评价（UAES 审核规则库 规范性条款 v1.0）：UAES-MSA-Cgk结论-可接受性（MSA:5）
- **规则原文**：适用子件：含 Cg／Cgk 评定区的测量能力报告（文件名或表头含“Cgk”“能力指数”“Capability Index”）。计划表、Kappa 报告、GR&R 报告不含该评定区，本条对它们记“不适用”，不得记作通过。 “不适用”须写明依据，不占通过／不通过结论位，不计入通过率分母；“本文件无评定区”与“评定区在别的文件里”是两件事，后者不得按不适用处理。 文件内须存在 Cg 与 Cgk 两个能力指数，且位于同一评定区块；两个指数均须 ≥ 1.33。同一报告有多组 Cg／Cgk 评定的，每一组都须不低于 1.33，任一组不达标即不通过。 全部满足才通过，否则不通过。 文件自带“要求：Cg 和 Cgk 1.33”一类要求行时，以该行印的阈值为准；若该阈值与 1.33 不同，登记冲突交客户裁决，不得静默择一。评定区只有一个指数、或指数值只有标签而无实测值（空白、公式未算出）的，不通过。 文件自带“是否合适／判定”栏（是／否、OK／NG）时，该栏与实测值矛盾（栏标“是”而实测低于阈值，或栏标“否”而实测达标）的，以实测值为准并登记冲突，不得因判定栏标“是”就判通过，也不得因判定栏标“否”就不看实测值。 本条只判 Cg／Cgk 的结论可接受性。该结论不得用作“重复性与再现性报告是否存在”“Kappa 报告是否存在”等存在性判定的证据；反之，报告存在也不推出本条通过。 1.33 的取值依据为测量系统分析手册第四版，并以文件自带要求行为准。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
