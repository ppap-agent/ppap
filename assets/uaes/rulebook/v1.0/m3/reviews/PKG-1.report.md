# PKG:1 条款语义检查报告

- **规则文件**：包装方案（UAES 审核规则库 规范性条款 v1.0）：UAES-PKG-内容块-完整性（PKG:1）
- **规则原文**：文件内容标题必须包含“包装方案”；文件还必须同时包含“零件基础信息”“供应商基础信息”“包装设计的基本要求”“针对该零件包装的特殊要求”“包装方案信息”“包装材料清单”六个内容块。以上七项全部满足才通过，否则不通过。 标题按“含”判定，不按整字段等值判定。 代表供应商的编制、审核、批准签署栏还须同时具备手写签字与受控印章或公章；纯打印体姓名不构成签字，电子手写签名图层与电子签章图层分别视为签字与印章。要求的签字均已手签时，签署区有一处有效印章即可，不要求每栏都盖；印章盖在共用盖章处或仅盖在批准栏，均可。客户（UAES）审批栏在供应商提交阶段可以留空，不计缺项。签字与印章任一缺失，或签署栏整栏全空，不通过。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 内容块名称写法不同

原文：「六个内容块」

例子：文件有一节小标题为“零件信息”，内容是零件号、名称、重量、尺寸；其余五个内容块的小标题与规定名称完全相同；标题含“包装方案”，签署齐全。

- 理解一（按内容认）：内容确实是零件基础信息，就算有这个内容块。（该例判通过）
- 理解二（按名称认）：内容块要以规定名称出现，名称不同就算缺。（该例判不通过）

反例复核：原文对标题写明按“含”判定，但对六个内容块只给了名称，没有说要按名称认还是按内容认。“零件信息”不含“零件基础信息”字样，但内容就是零件基础信息；两种理解都不违背原文，只有这一块的认定不同。

**请确认**：内容块的小标题和规定名称不完全相同、但内容确实是那一块时，算包含吗？

### 2. 部门专用章算不算受控印章

原文：「受控印章或公章」

例子：编制、审核、批准都已手写签字，签署区只有一处“××有限公司质量部专用章”，没有公章，也没有“受控”字样的印章；其余都满足。

- 理解一（公司管控的印章都算）：部门专用章是公司管控使用的印章，算受控印章。（该例判通过）
- 理解二（只认受控章和公章）：只有带“受控”标记的印章或公章才算，部门专用章不算。（该例判不通过）

反例复核：原文要求受控印章或公章，但没说受控印章是指公司管控的各类印章，还是指带“受控”标记的文件受控章。部门专用章不是公章，是否属于受控印章原文没有交代，签字、标题和内容块在两种理解下都满足。

**请确认**：签署区只盖了部门专用章（如“质量部专用章”）时，算“受控印章或公章”吗？

## 已排除的疑似问题（不进入问卷）

- **七项都满足但缺签字是否冲突**：“才通过”是必要条件，签署要求是同条的另一项必要条件，两者同时有效，不构成冲突。
- **客户审批栏空着是否算签署栏整栏全空**：原文明确客户审批栏留空不计缺项，“整栏全空”针对的是代表供应商的签署栏。
