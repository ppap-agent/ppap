# TRACE:1 条款语义检查报告

- **规则文件**：零件追溯说明（UAES 审核规则库 规范性条款 v1.0）：UAES-TRACE-区域内容-完整性（TRACE:1）
- **规则原文**：文件必须包含“供应商零件追溯”表；该表内“基本信息”“分供方追溯”“生产过程追溯”“交付追溯”“追溯状态总结”五个区域必须分别存在实质内容。表存在且五个区域均有内容才通过；缺少表或任一区域没有内容即不通过。 “实质内容”按占位词规则判：区域标题格、列头格、纯空白的合并格不计；区域内实质内容格数为 0 的，与“有内容但仍有整行/整列空洞”的，分属两种不同情形，不得合并陈述，结论也不同：前者按“区域整块缺失”判不通过（致命），后者按“局部空洞”判不通过（主要）；两者分别计数、分别表述，不合并为一条缺陷。占位词指下列写法：“见附表”“见附件”“待定”“TBD”“NA”“N/A”“—”“-”“/”“同上”“见上”“略”“*”“待补”“后续提供”“XX”“XXXX”“123456”，以及 Excel 公式报错码 #N/A、#REF!、#DIV/0!、#VALUE!、#NAME?、#NUM!、#NULL!；未填字的空心方框 □ 与黑色涂抹遮挡块同样按未填处理。不能仅凭单元格非空就认定具有实质内容。填占位词与单元格空白是两种不同问题，须分开陈述。 文件代表供应商的签署栏还须同时具备手写签字与供应商有效印章，缺一即不通过。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 末尾没用上的预留行算不算空洞

原文：「有内容但仍有整行/整列空洞」

例子：分供方追溯区域模板预留 5 行，供应商只有 3 家分供方，前 3 行填满，后 2 行整行空白；其他四个区域都填满，签署栏有手写签字和公司章。

- 理解一（整行空着就是空洞）：区域内只要有整行空白，就按局部空洞不通过。（该例判不通过）
- 理解二（空洞指内容中间缺失）：空洞是已有内容之间缺了一行或一列；末尾没用上的预留行不算。（该例判通过）

反例复核：原文把“整行/整列空洞”判为局部空洞，但没有说明没用上的预留行是否属于空洞。例子中五个区域都有实质内容、签署合格，只差这 2 行空白；两种理解都不违反原文其他要求。

**请确认**：区域里模板预留的行比实际要填的多，末尾几行整行空着，算“局部空洞”吗？

## 已排除的疑似问题（不进入问卷）

- **区域里单个格子空着或写占位词是否判不通过**：原文对有内容的区域只把整行或整列空洞判不通过，单个格子不属于这两种情形，按原文可以判定，不必提问。
