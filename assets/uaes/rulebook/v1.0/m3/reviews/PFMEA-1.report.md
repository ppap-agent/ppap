# PFMEA:1 条款语义检查报告

- **规则文件**：潜在过程失效模式及后果分析（PFMEA）（UAES 审核规则库 规范性条款 v1.0）：UAES-PFMEA-经验教训-引用（PFMEA:1）
- **规则原文**：PFMEA 必须体现“经验教训”作为输入，在表头、附录、变更履历或修订说明中引用历史问题、客户抱怨、过往失效案例或类似产品问题。完全没有相关引用时不通过。 相关栏位只填“/”“无”“首次发行”，或只写“参考以往经验”而无具体问题、批次、产品指向的，视为未构成引用；表述笼统到无法确定指向的，按无法辨识处理，不按“已引用”放行。 PFMEA 还须设有独立的修改记录或变更履历区域，可为独立工作表、末页表尾或表头履历块；其中至少一条记录须同时写明版本号、修改日期、修改内容描述与修改人，只有版本号与日期而无修改内容描述的，不构成有效记录。修改记录常位于多页文件的末页表尾或独立 Sheet，检索须覆盖全表，不得只扫前若干行；只扫前段而漏读表尾履历的，属未审，不得据此判“无修改记录”。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **只看前几行找不到履历是否足以否决**：须查至末页和独立工作表；没有查完是未审，不能断言履历不存在。
- **“首次发行”是否自带经验教训免查**：该词单独填写恰被明确排除，没有首次发行例外。
