# MSL:3 条款语义检查报告

- **规则文件**：材料产品及分供清单（UAES 审核规则库 规范性条款 v1.0）：UAES-MSL-图纸信息-一致性（MSL:3）
- **规则原文**：同批次必须提交与当前项目、物料编号一致的图纸独立文件；分供方清单中的“零件名称”“零件号”必须分别与该图纸中的“零件名称”“零件号”一致。同一项目与件号有两份均在用的图纸、零件名称不同的，分供清单的零件名称与任一份在用图纸相同就算一致。 缺少图纸或任一字段不一致即不通过。比对前先做同号校验：图纸与分供清单的零件号本身不一致的，属比对源错配，与“字段内容不一致”分开表述。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 图纸名称为中英双语时只写一种是否一致

原文：「必须分别与该图纸中的“零件名称”“零件号”一致」

例子：图纸标题栏零件名称为“壳体 Housing”，分供清单零件名称写“壳体”；零件号两边完全相同，同批已交图纸。

- 理解一（写其中一种即算一致）：清单名称与图纸名称中的某一种语言完全相同就算一致。（该例判通过）
- 理解二（须完整相同）：清单名称须与图纸名称栏的全部文字相同。（该例判不通过）

反例复核：原文只写“一致”，没有说明双语名称只写其中一种语言时如何比对。按逐字比对，两者文字不同；按名称本身比对，“壳体”就是图纸名称的中文部分。零件号相同、图纸已交，结论只取决于这一点，原文没有排除任何一种理解。

**请确认**：图纸的零件名称同时写了中文和英文，分供清单只写了其中的中文名称，算不算一致？

## 已排除的疑似问题（不进入问卷）

- **零件号错配时是否仍判不通过**：这句只规定怎么表述；零件号不同同时属于“任一字段不一致”，也不满足“与当前项目、物料编号一致的图纸”，按原文不通过。
- **零件号写法相近（多空格、少后缀）是否算一致**：原文要求零件号一致，没有给出放宽的写法，按原文逐字比对即可，不另设口径。
