# MSL:4 条款语义检查报告

- **规则文件**：材料产品及分供清单（UAES 审核规则库 规范性条款 v1.0）：UAES-MSL-PFD-双向溯源（MSL:4）
- **规则原文**：材料产品及分供清单须与过程流程图双向溯源： 1. 过程流程图中的外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）与核心原材料，须在分供清单中有对应记录； 2. 分供清单中的每一项外协工序与原材料，须在过程流程图中有对应节点。 任一方向存在缺失即不通过。核心原材料只指构成零件主体的材料，配方辅料不要求列入分供清单。对应关系按“工序名称／材料牌号的工程语义”认定，允许简称与别名，不要求逐字一致；分供方名称写法与流程图不同的，不判不通过。 过程流程图中标注为“自制”“厂内”“内制”的工序，不要求出现在分供清单中；分供清单标注“外购”“外协”“委外”的项，必须在流程图中有节点，缺失按“分供项未上流程图”判不通过。 同批次未提交过程流程图时本条记“不适用”并写明依据，不记作通过；缺件计数只在包级报一次。本条与规则 3 分属不同对象：规则 3 判与图纸的零件号、零件名称一致，本条判与过程流程图的双向溯源，两者同时适用。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 流程图未标自制或外协的热处理等工序

原文：「外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）」「过程流程图中标注为“自制”“厂内”“内制”的工序，不要求出现在分供清单中」

例子：流程图第 40 道工序为“热处理”，没有任何自制或外协标注；分供清单里没有热处理分供方或热处理记录；其余外协工序和核心原材料两边都对得上。

- 理解一（未标自制即按外协）：括号里列出的工序类型，除非标了自制、厂内、内制，都要在清单里有记录。（该例判不通过）
- 理解二（须标明外协才算）：只有流程图上看得出是外协的工序才要求在清单里有记录。（该例判通过）

反例复核：原文括号里把热处理列在外协工序里，又只豁免标注了“自制”“厂内”“内制”的工序；但括号也可能只是举例说明外协工序有哪些形式，并不表示这类工序一律是外协。未标注时，原文没有说按哪一种处理。其他对应关系都满足，结论只取决于这一点。

**请确认**：流程图上有“热处理”这类括号里列出的工序，但既没标“自制”也没标“外协”，它算不算要在清单里有记录的外协工序？

### 2.1. 多种材料组成的零件，哪些算“主体”

原文：「核心原材料只指构成零件主体的材料」

例子：注塑件由 PA66-GF30 塑料本体和黄铜螺纹嵌件组成；流程图有“PA66-GF30 进料”和“铜嵌件进料”两个节点，分供清单只列了 PA66-GF30 的供应商。

反例复核：原文用“构成零件主体”划定核心原材料，但没有说明零件由几种材料组成时怎样算主体。嵌件是零件的组成部分但体积占比小，此例结论取决于它是否属于主体。另需注意清单到流程图方向不受影响，这里只涉及流程图到清单方向。

**请确认**：零件由塑料本体和金属嵌件组成时，金属嵌件算不算构成零件主体的核心原材料？

## 已排除的疑似问题（不进入问卷）

- **清单里列了配方辅料但流程图没有节点，能否用“配方辅料不要求列入”豁免**：辅料豁免只说不要求列入清单；清单到流程图方向原文写的是“每一项……原材料”，没有豁免，按原文须有节点。
- **与规则 3 是否重复判定**：原文已写明两条对象不同、同时适用。
