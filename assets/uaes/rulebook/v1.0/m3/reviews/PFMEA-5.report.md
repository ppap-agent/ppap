# PFMEA:5 条款语义检查报告

- **规则文件**：潜在过程失效模式及后果分析（PFMEA）（UAES 审核规则库 规范性条款 v1.0）：UAES-PFMEA-PFD工序-覆盖（PFMEA:5）
- **规则原文**：过程流程图（PFD）中的全部主工序，均须在 PFMEA 中被覆盖并开展失效分析。正常路线中独立编号、但只负责转运、不改变产品状态的工序属辅助物流，不算主工序，不要求在 PFMEA 中有对应的失效分析；可在提醒项中提醒 PFD 中有转运工序未在 PFMEA 中体现。 覆盖按“工序号＋核心工艺语义”归并认定：一个 PFD 工序在 PFMEA 中拆成多个工序行，只要核心工艺语义一致，视为已覆盖；反过来一个 PFMEA 行聚合多个 PFD 工序的，只要逐工序均有对应失效模式，同样视为已覆盖。不得仅因两侧行数不等就判未覆盖。 缺少 PFMEA 与 PFD 的对应关系，或任一 PFD 主工序在 PFMEA 中无对应失效分析，即不通过。同批次未提交过程流程图时，本条记“不适用”并写明依据，不记作通过，也不得因缺 PFD 判本条不通过（缺件计数只在包级报一次）。 本条与过程流程图规则 2 的图形符号判据、控制计划规则 7“PFD 工序须在 CP 中出现”分属不同链路：本条只判 PFD→PFMEA 方向的工序覆盖，不判工序名称逐字一致，也不判特性覆盖（特性覆盖见规则 3、规则 4）。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 暂存、入库工序算不算主工序

原文：「只负责转运、不改变产品状态的工序属辅助物流，不算主工序」

例子：PFD 工序 60 为“半成品暂存（待检区）”，独立编号、不改变产品状态；PFMEA 中没有这道工序，其他主工序都已覆盖。

- 理解一（只排除转运）：只有转运工序不算主工序，暂存仍是主工序，需要失效分析。（该例判不通过）
- 理解二（暂存也属辅助物流）：不改变产品状态的暂存也属辅助物流，不算主工序。（该例判通过）

反例复核：原文只把“只负责转运、不改变产品状态”的工序排除在主工序之外，并称之为辅助物流；暂存同样不改变产品状态、也常被看作物流环节，但它不是转运。原文没有正面定义主工序，也没说辅助物流是否只限转运，两种理解都不违背原文。

**请确认**：PFD 中独立编号的“暂存”“入库”这类不改变产品状态、但也不是转运的工序，算主工序吗？

### 2. 工序号不同能否认定覆盖

原文：「覆盖按“工序号＋核心工艺语义”归并认定」

例子：PFD 工序编号为 10、20、30（下料、冲压、焊接），PFMEA 编号为 OP100、OP200、OP300，内容依次为下料、冲压、焊接，各有失效分析；其余都满足。

- 理解一（工艺内容对上即可）：编号只作参考，工艺内容一致就算覆盖。（该例判通过）
- 理解二（工序号也要对上）：工序号和工艺内容都要对应，编号对不上就是缺少对应关系。（该例判不通过）

反例复核：原文用“工序号＋核心工艺语义”归并认定，没说两者都要对上，还是工序号只作参考；也没说工序号写法不同时怎么对应。这个例子工艺内容完全对得上，只有编号不同，两种理解结论不同。

**请确认**：PFMEA 与 PFD 工序编号完全不同、但工艺内容逐一对得上时，算已覆盖吗？

## 已排除的疑似问题（不进入问卷）

- **PFMEA 行数少于 PFD 工序数是否未覆盖**：原文明确不能只凭行数判，须逐工序看失效分析，结论唯一。
