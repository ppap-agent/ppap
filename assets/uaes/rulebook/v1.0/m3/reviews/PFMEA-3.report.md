# PFMEA:3 条款语义检查报告

- **规则文件**：潜在过程失效模式及后果分析（PFMEA）（UAES 审核规则库 规范性条款 v1.0）：UAES-PFMEA-特殊特性-标识与覆盖（PFMEA:3）
- **规则原文**：PFMEA 须同时满足： 1. “特殊特性”列或“分类”列对关键、重要或特殊特性有符号标识（CC／SC／YC／YS／★ 等，含同批特殊特性清单图例定义的符号），已知关键特性不得漏标； 2. 同批次须提交同项目、同物料编号的独立特殊特性清单； 3. 清单内所有产品特性均须在 PFMEA 功能/要求/产品特性中体现并分析，或在失效模式中体现相关失效模式，且特性标识一致； 4. 清单内所有过程特性均须在 PFMEA 功能/要求/过程特性中体现并分析，或在失效模式/失效原因中体现相关失效模式，且特性标识一致。 任一项缺失或不一致即不通过。 第 3、4 项所称“特性标识一致”含特性名称、公差/规格与符号三项，任一项不一致即按标识不一致判。 符号位为无字图形（只有框、圈、菱形而无任何字符）且全表无图例解释其含义的，按“未标识”判，不得按“有内容”放行；出现规则与清单图例均未登记的符号时，按“待确认”处理并请供应商说明，不直接判不通过。 清单与 PFMEA 配对照“公差值＋特性名”，不按特性编号——两边编号体系可能不同且偏移量不固定。清单和 PFMEA 的定性过程特性都没有数值公差，而名称、文字规格、工序与类别均相同的，可用相同的文字规格代替数值公差完成配对。公差值归一后精确相等为第一键，特性名剥离序号与类别码后相同为第二键；两者对上即为同一特性，再比类别码。配对成功而类别码不同判不通过；配对不上的按缺项判不通过，不得因编号不同就认定“找不到”，也不得因编号相同就认定“是同一特性”。标识写法按以下等价写法认定。跨文件比对特性标识时，下列写法视为同一等级：安全／关键级为 CC、SC/1、1、S、★、安全、关键；重要／主要级为 SC、SC/2、2、D、F、重要、主要、跑道框。裸写 SC 与 SC/1 分属两级、不可互换：带序号的 SC/1 归安全／关键级，裸写的 SC 归重要／主要级。上游写 SC/1、下游简写 1（或上游写 SC/2、下游填对应等级代号），且特性名称与公差完全一致的，按同级处理、仅提示书写格式。客户图纸另用 3、5 作为类别代号，两者均不在上述两级之内，属独立类别——上述等价写法不收录、也不得据此反推其等级；对它们只判“两侧是否一致”，不判其对应哪一级。等级代号 3 与 5 是两个不同类别，不可互换：两侧均写 3 为一致，一侧 3 一侧 5 为标识不一致。并列书写的分隔符不同（半角逗号、全角逗号、空格）视为同一标记，判一致并留痕。代号的确切等级含义文件中未载明时，向客户索取定义并按移交处理；但语义未知不影响“是否一致”的判定——一致性照常二值判，不得以“语义不明”为由改为待裁决。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 空心跑道框算不算标识

原文：「重要／主要级为 SC、SC/2、2、D、F、重要、主要、跑道框」「符号位为无字图形（只有框、圈、菱形而无任何字符）且全表无图例解释其含义的，按“未标识”判」

例子：清单某特性标 SC，名称、公差与 PFMEA 一致；PFMEA 该特性的符号位只有一个不含任何字的跑道形框，全表和清单都没有图例；其余各项都满足。

- 理解一（按等价写法）：跑道框已登记为重要主要级，与清单 SC 同级，标识一致。（该例判通过）
- 理解二（按无字图形）：跑道框里没有字、全表无图例，按未标识判。（该例判不通过）

反例复核：原文把“跑道框”列为重要主要级的等价写法，又规定只有框、圈、菱形而无字、全表无图例的符号按未标识判。跑道框本身就是一种无字的框，原文没有说哪一句优先，两种理解都直接出自原文。

**请确认**：PFMEA 符号位只画了一个空心跑道框、全表没有图例时，算重要级标识，还是算未标识？

### C1. 两侧未登记代号不同

原文：「出现规则与清单图例均未登记的符号时，按“待确认”处理并请供应商说明，不直接判不通过」「配对成功而类别码不同判不通过」「一致性照常二值判，不得以“语义不明”为由改为待裁决」

例子：清单某特性类别写“4”，PFMEA 同名同公差的特性写“6”；4 和 6 都不在规则等价写法里，清单也没有图例说明；其余各项都满足。

原文对这个例子给出了相互冲突的结论。

反例复核：这个特性已配对成功，类别码不同，按配对规则和“一致性照常二值判”应判不通过；但这两个符号又都是规则与清单图例都没登记的，按未登记符号的规定应待确认、不直接判不通过。两句话作用在同一个特性的同一个符号上，结论互相排斥，原文没有说哪句优先。

**请确认**：清单和 PFMEA 对同一特性标了两个都未登记、又彼此不同的代号时，判不通过，还是先待确认？

## 已排除的疑似问题（不进入问卷）

- **只在失效模式中体现、没有写公差时是否算覆盖**：原文写明标识一致含名称、公差或规格与符号三项，缺公差即不一致；走失效模式这条路同样要满足，结论唯一。
- **只对上公差、名称略有差异时是配不上还是名称不一致**：按配不上是缺项不通过，按配上则名称不一致也不通过，两种理解结论相同。
- **两侧都写 3 时是通过还是移交待定**：原文紧接着写明一致性照常二值判、不得以语义不明改为待裁决，已排除待定的理解。
