# CP:8 条款语义检查报告

- **规则文件**：控制计划（CP）（UAES 审核规则库 规范性条款 v1.0）：UAES-CP-特殊特性-一致性（CP:8）
- **规则原文**：同批次必须提交同零件号的过程流程图、PFMEA、采购件质量计划三类独立文件；过程流程图中所有被标识的特性，均须在控制计划“产品”“过程”“产品/过程规格/公差”列中体现并分析；PFMEA“分类”或“特殊特性”列有内容的行，其“功能/要求”“产品特性”或“过程特性”列所列特性，均须在控制计划中体现并分析；采购件质量计划含 PGQP1 表时，PGQP1 中的全部重要特性也须在控制计划中体现并分析。 缺少必需文件或任何应覆盖特性即不通过。 跨文件特性配对按“公差值＋特性名”，不按特性编号；配对成功而标识不一致判不通过，配对不上的按缺项判不通过。两侧定性特性都没有数值公差，而名称、文字验收要求、工序和等级都相同的，可用相同的文字验收要求代替公差值完成配对。本批三类对端中，过程流程图与 PFMEA 为提交方应交件，缺则本条判不通过；采购件质量计划的 PGQP1 表同为提交方应交件，缺件计数只在包级报一次，不在本条重复计数。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 缺采购件质量计划时本条是否不通过

原文：「同批次必须提交同零件号的过程流程图、PFMEA、采购件质量计划三类独立文件」「缺件计数只在包级报一次，不在本条重复计数」

例子：同批提交了零件号相同的过程流程图和 PFMEA，两者被标识的特性都在控制计划中出现并分析，配对和标识都一致；同批没有采购件质量计划文件。

- 理解一（本条照样不通过）：缺采购件质量计划仍使本条不通过，只是缺件这条缺陷不在本条重复记。（该例判不通过）
- 理解二（本条不因此不通过）：缺采购件质量计划只在整批资料层面报，本条只看过程流程图与 PFMEA 的覆盖。（该例判通过）

反例复核：第一段把采购件质量计划列为必交，并写“缺少必需文件……即不通过”；最后一段又特意把它和过程流程图、PFMEA 分开，只说后两者“缺则本条判不通过”，对采购件质量计划只说缺件在包级报一次、本条不重复计数。“不重复计数”可以理解为本条不判不通过，也可以理解为照样不通过只是不重复记一条缺陷，原文没有排除任一种。

**请确认**：同批没有交采购件质量计划时，本条判不通过，还是只在整批资料层面报一次缺件、本条不因此不通过？

### 2. 过程流程图里哪些算“被标识的特性”

原文：「过程流程图中所有被标识的特性」

例子：过程流程图第 20 道工序列出“外径 Φ10±0.05”“长度 25±0.1”“硬度 HRC 30~35”三项产品特性，只有“外径”旁标了特殊特性符号；控制计划只写了外径一项。PFMEA 与 PGQP1 的应覆盖特性都已在控制计划中且一致。

- 理解一（带特殊特性符号的）：只有标了特殊特性符号的特性才要覆盖，此例只需外径。（该例判通过）
- 理解二（流程图列出的全部特性）：流程图上写出来的特性都算被标识，长度和硬度也要覆盖。（该例判不通过）

反例复核：原文对 PFMEA 写明以“分类”或“特殊特性”列有内容为准，对过程流程图只说“被标识的特性”，没有说是用什么标识；其他文件的覆盖在此例都满足，差别只在流程图上另两项要不要覆盖。

**请确认**：过程流程图中“被标识的特性”是指带特殊特性符号的特性，还是流程图上列出的全部特性？
