# CP:4 条款语义检查报告

- **规则文件**：控制计划（CP）（UAES 审核规则库 规范性条款 v1.0）：UAES-CP-特性类型-列与标记（CP:4）
- **规则原文**：控制计划中必须存在“特性类型”列或“特殊特性”列（至少一列），且该列下应有非空白的特性标记。没有相应列，或列下无特性标记，均不通过。 存在语义相近但不在允许同义写法范围内的列名时，按“列名近似但未登记”处理，交人工确认，不直接当作该列已具备。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **近似而未登记的列名是否自动认可？**：条款已指定人工确认的处理方式，不需要就单一近似列名再次发通用问卷。
