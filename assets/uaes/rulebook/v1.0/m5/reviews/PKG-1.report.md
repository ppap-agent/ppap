# PKG:1 条款语义检查报告

- **规则文件**：包装方案：内容块-完整性（PKG:1）
- **规则原文**：文件内容标题必须包含“包装方案”；文件还必须同时包含“零件基础信息”“供应商基础信息”“包装设计的基本要求”“针对该零件包装的特殊要求”“包装方案信息”“包装材料清单”六个内容块。以上七项全部满足才通过，否则不通过。内容块的小标题与规定名称不完全相同，但实际内容确属该块的，算包含该内容块。 标题按“含”判定，不按整字段等值判定。 代表供应商的编制、审核、批准签署栏还须同时具备手写签字与受控印章或公章；纯打印体姓名不构成签字，电子手写签名图层与电子签章图层分别视为签字与印章。要求的签字均已手签时，签署区有一处有效印章即可，不要求每栏都盖；印章盖在共用盖章处或仅盖在批准栏，均可。客户（UAES）审批栏在供应商提交阶段可以留空，不计缺项。签字与印章任一缺失，或签署栏整栏全空，不通过。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 2. 质量部专用章的效力

原文：「受控印章或公章」「签署区有一处有效印章即可」

例子：标题和六块内容齐全，供应商编制、审核、批准均已手签。共用盖章处仅盖“××有限公司质量部专用章”，可查到公司专人保管和用印登记；章面不写“受控”，也非公章。

- 理解一（按实际用印管理认定）：该部门章有受控管理证据，即使不印“受控”也算。（该例判通过）
- 理解二（按印章类别认定）：普通部门专用章不是公章，也不是带指定受控标识的章，不算。（该例判不通过）

反例复核：章的位置、章数、签字、文件内容都满足。正文未说明“受控”是实际管理状态，还是要求专用的印章类别或章面标记。登记事实明确，不是印章看不清。

**请确认**：仅盖由供应商登记管理的“质量部专用章”、章面没有“受控”字样且不是公章，这一处算有效印章吗？

## 已排除的疑似问题（不进入问卷）

- **“零件信息”小标题是否天然缺块**：不能因异名扣分；要看该块实质是否为零件基础信息。此规则不放宽文件标题。
- **七项齐全而缺供应商签字，原文既说通过又说不通过**：“才”是必要条件，不是充分条件；无签字不能通过。
- **客户空栏能否抵销供应商的缺签或缺章**：豁免只对提交阶段的客户栏有效。
