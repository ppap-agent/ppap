# PSW:3 条款语义检查报告

- **规则文件**：零件提交保证书（PSW）：签字盖章-校验（PSW:3）
- **规则原文**：零件提交保证书必须包含“供方代表签字”字段；该字段必须有手写签名，且文件中还必须有印章。嵌入文件的手写签名图片算手写签名。电子章图片算印章。三项全部满足才通过，否则不通过。 签署区还须填写打印姓名/职务（Title）、电话号码、电子邮箱与签署日期，任一项缺失或格式明显不合法的按联系信息不完整判。即使模板把打印姓名和职务合在一格，打印姓名和职务也都须出现；仅写职务的，即缺打印姓名。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 联系信息不完整时的结论

原文：「任一项缺失或格式明显不合法的按联系信息不完整判」「三项全部满足才通过，否则不通过」

例子：供方代表栏有手写签名，文件盖了公司章；签署区写了打印姓名、职务、电话和签署日期，没写电子邮箱。

- 理解一（联系信息不完整即不通过）：签署区缺电子邮箱违反“还须填写”的要求，按联系信息不完整判，本条不通过。（该例判不通过）
- 理解二（只记问题不否决）：联系信息不完整作为问题写明，本条结论仍由签字栏、手写签名、印章三项决定。（该例判通过）

反例复核：原文可能已有结论：签署区各项是“还须”填写的硬性要求，缺了就按联系信息不完整判，原文没有把它写成只提醒；“三项全部满足才通过”只说三项是通过的前提，不能反过来说三项满足就通过。但原文写明通过与不通过的只有签字栏、手写签名、印章三项那一句，联系信息这段只写按联系信息不完整判，没有写判不通过。签字栏、手写签名、印章在两种理解下都满足，差别只在缺电子邮箱是否让本条不通过。

**请确认**：签署区联系信息不完整（例如没写电子邮箱）时，本条判不通过吗？

## 已排除的疑似问题（不进入问卷）

- **把手写签名扫描成图片插入文件，算不算手写签名**：新写法已明确写出插入文件的手写签名图片算手写签名。
- **印章是否必须是供方公司章**：原文只要求文件中有印章，没有限定印章种类或盖章单位，要求公司章是在原文之外加条件。
