# CP:7 条款语义检查报告

- **规则文件**：控制计划（CP）：工艺流程-一致性（CP:7）
- **规则原文**：同批次必须提交与当前零件号一致的过程流程图、PFMEA、采购件质量计划三类独立文件；过程流程图中的全部工序必须在控制计划“工序名称/操作描述”中出现并分析；PFMEA 的“工序/功能/要求”或“过程项/过程步骤”中的全部工序必须在控制计划的相应列出现并分析；采购件质量计划包含 PGQP1 表时，其中全部工艺也必须在控制计划中出现并分析。 缺少必需文件或任一应覆盖工序即不通过。比对允许简称，不允许把两个不同工序当作同一项；工序归属按特性所属工序判定，不按行号所在块判定。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
