# SCL:3 条款语义检查报告

- **规则文件**：特殊特性清单：特殊特性三方-一致性（SCL:3）
- **规则原文**：本类目通用口径（规则 1、规则 2、规则 3 均适用） 本类清单常为多件号混装母版：判定前必须先按本件号过滤出行范围，只在过滤范围内统计与判定，跨件号的行不参与判定；依据须写明“按本件号 XX 过滤，参与判定 N 行”。件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在。未按件号过滤而按全表统计的，属未按范围执行，所得结论无效。 特殊特性清单须完整覆盖图纸与 PGQP1 中的全部特殊特性，且同一特性在三处的名称、规格公差、分类符号一致。 覆盖按双向认定：图纸或 PGQP1 中被标为特殊特性的每一项，清单中须有对应行；清单中的每一项特殊特性，也须能在图纸或 PGQP1 中找到对应特殊特性，仅作过程参考、在图纸和 PGQP1 中都不是特殊特性的普通行不参加覆盖比较。单向缺失即不通过，只核“清单有→图纸有”一个方向的属未审。 跨文件一致性先做同号校验（零件号、物料编号归一后相等），再取值比对；不同号属比对源错配，不逐格挑内容错。特殊特性清单为多件号混装、所交资料又不能确定本件号的，判比对源错配，并写明各文件所写的件号。 三方一致性按“公差值＋特性名”配对，不得按特性编号直接比对——不同文件对同一特性可能各用一套序号，偏移量不固定；配对顺序：公差值归一后精确相等，再特性名剥离序号与类别码后相同，仍多解时按图纸区域或工序位置确认，并在依据中写明配对方式；配对成功而类别符号不同判不通过；配对不上的按缺项判不通过，不得因编号不同就认定“找不到”，也不得反向按编号相同就认定“是同一特性”。符号写法按以下等价写法认定，SC 与 SC/1 分属两级不可互换。跨文件比对特性标识时，下列写法视为同一等级：安全／关键级为 CC、SC/1、1、S、★、安全、关键；重要／主要级为 SC、SC/2、2、D、F、重要、主要、跑道框。裸写 SC 与 SC/1 分属两级、不可互换：带序号的 SC/1 归安全／关键级，裸写的 SC 归重要／主要级。上游写 SC/1、下游简写 1（或上游写 SC/2、下游填对应等级代号），且特性名称与公差完全一致的，按同级处理、仅提示书写格式。客户图纸另用 3、5 作为类别代号，两者均不在上述两级之内，属独立类别——上述等价写法不收录、也不得据此反推其等级；对它们只判“两侧是否一致”，不判其对应哪一级。等级代号 3 与 5 是两个不同类别，不可互换：两侧均写 3 为一致，一侧 3 一侧 5 为标识不一致。并列书写的分隔符不同（半角逗号、全角逗号、空格）视为同一标记，判一致并留痕。代号的确切等级含义文件中未载明时，向客户索取定义并按移交处理；但语义未知不影响“是否一致”的判定——一致性照常二值判，不得以“语义不明”为由改为待裁决。 PGQP1 未随批提交时，以图纸为唯一基准，并在依据中写明缺 PGQP1；图纸亦未提交时，本条记“不适用”并写明依据，不记作通过。缺件计数只在包级报一次，不在本条重复计数。 本条与规则 1、规则 2 分属不同对象：规则 1 判物料字段、表头与签署，规则 2 判四类列与行内必填，本条判特性集合的跨表覆盖，三者同时适用。
- **结论**：5 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. PGQP1 里没有图纸上的某项特殊特性

原文：「清单中的每一项特殊特性，也须能在图纸或 PGQP1 中找到对应特殊特性」「且同一特性在三处的名称、规格公差、分类符号一致」「配对不上的按缺项判不通过」

例子：同批交了图纸、PGQP1 和特殊特性清单，三者零件号相同。图纸标“孔径 Φ8±0.02 SC”，清单有一行名称、公差、符号完全相同；PGQP1 中没有这一项。其余特殊特性在三处都能配对且一致，清单没有多出的特殊特性。

- 理解一（出现在哪里就比哪里）：按图纸或 PGQP1 认定的覆盖已经成立，只在出现该特性的文件之间比是否一致，PGQP1 没有这一项不影响本条。（该例判通过）
- 理解二（三处都要配上）：同一特性要在三处都能配对，PGQP1 中配不上就按缺项判。（该例判不通过）

反例复核：覆盖按“图纸或 PGQP1”认定，此例两个方向都覆盖了；但原文又要求同一特性在三处一致，按三方配对，配对不上的按缺项判不通过。原文没有说一项只出现在图纸和清单两处时，PGQP1 中配不上算不算缺项；两种理解都没有违背其他明确要求。

**请确认**：某项特殊特性图纸和清单都有且一致、同批已交的 PGQP1 里却没有这一项时，本条判不通过吗？

### 2. 清单自标特殊特性的过程特性行

原文：「清单中的每一项特殊特性，也须能在图纸或 PGQP1 中找到对应特殊特性」「仅作过程参考、在图纸和 PGQP1 中都不是特殊特性的普通行不参加覆盖比较」

例子：同批图纸、PGQP1 和清单零件号相同。清单中有一行过程特性“焊接电流 200±10 A”，清单给它标了 SC；图纸和 PGQP1 中都没有这一项。其余特殊特性两个方向都覆盖且三处一致。

- 理解一（清单标了就要比）：清单标了 SC 就是清单中的特殊特性，须在图纸或 PGQP1 中找到对应项，找不到即单向缺失。（该例判不通过）
- 理解二（过程参考行不比）：这一行是过程特性，在图纸和 PGQP1 中都不是特殊特性，属于不参加覆盖比较的行。（该例判通过）

反例复核：原文一方面要求清单中的每一项特殊特性都须能在图纸或 PGQP1 中找到对应特殊特性、单向缺失即不通过，另一方面规定仅作过程参考、在图纸和 PGQP1 中都不是特殊特性的普通行不参加覆盖比较。此例这一行在图纸和 PGQP1 中都不是特殊特性，但清单给它标了 SC；原文没有说这种行算“清单中的特殊特性”，还是算只作过程参考的普通行。

**请确认**：清单自己标了特殊特性符号、而图纸和 PGQP1 中都没有的过程特性行，要参加覆盖比较吗？

### 3. 没有数值公差的特殊特性怎样配对

原文：「三方一致性按“公差值＋特性名”配对」「配对顺序：公差值归一后精确相等，再特性名剥离序号与类别码后相同」

例子：同批图纸、PGQP1 和清单零件号相同。图纸把“材料：PA66-GF30”标为 SC，PGQP1 和清单都有同名、同写法的一行并标 SC，三处都没有数值公差；其余特殊特性都已配对且一致，两个方向都覆盖。

- 理解一（文字规格可代替）：没有数值公差时以相同的文字规格代替公差值，此项三处配对成功且一致。（该例判通过）
- 理解二（须有公差值）：配对第一步要求公差值精确相等，三处都没有公差值，配不上，按缺项判。（该例判不通过）

反例复核：原文要求同一特性在三处的名称、规格公差、分类符号一致，配对却规定先比公差值归一后是否精确相等，没有写只有文字规格、没有公差值的特性怎么配。此例三处名称、规格、符号完全相同，判定差别只在能否配上，配不上即按缺项判不通过。

**请确认**：图纸、PGQP1 和清单中都只有文字规格、没有数值公差的特殊特性，能否以相同的文字规格代替公差值完成配对？

### G1. 交了 PGQP1 而没交图纸

原文：「PGQP1 未随批提交时，以图纸为唯一基准」「图纸亦未提交时，本条记“不适用”并写明依据，不记作通过」

例子：本批提交了特殊特性清单和 PGQP1，没有提交图纸；清单与 PGQP1 零件号相同，双方的特殊特性两个方向都能配对，名称、规格公差、符号都一致。

原文没有明确规定这个例子的判定结论。

反例复核：原文只写了缺 PGQP1 时以图纸为唯一基准、图纸也没交（两者都没交）时记不适用，没有写 PGQP1 已交而只缺图纸的情形。覆盖按“图纸或 PGQP1”认定，看似可以只用 PGQP1；但首句要求完整覆盖图纸与 PGQP1 中的全部特殊特性，原文又只指定图纸可以作唯一基准，不能据此推出 PGQP1 也可以单独作基准。

**请确认**：本批交了 PGQP1、没交图纸时，本条以 PGQP1 为唯一基准照常判定，还是记“不适用”？

### G2. 比错文件时本条的结论

原文：「不同号属比对源错配，不逐格挑内容错」「判比对源错配，并写明各文件所写的件号」

例子：本批特殊特性清单写零件号 F01R10Y776，同批图纸和 PGQP1 都写 F01RD0Y776，归一后不相等；按名称和公差看，清单各行与图纸、PGQP1 的特殊特性都能对上且写法一致。

原文没有明确规定这个例子的判定结论。

反例复核：原文规定零件号不同属比对源错配、不逐格挑内容错，并要求写明各文件所写的件号，但没有给出比对源错配时本条的结论：可能判不通过，可能交人工审核，也可能视同图纸、PGQP1 没有随批提交而记不适用。此例内容本身都能对上，结论只取决于错配怎么判。

**请确认**：特殊特性清单与同批图纸、PGQP1 的零件号归一后不相等、属比对源错配时，本条应判什么？

## 已排除的疑似问题（不进入问卷）

- **图纸与 PGQP1 对同一特性的符号本身不同（如图纸 SC、PGQP1 CC），清单只与图纸相同时，是否算本条不通过**：原文要求同一特性在三处的名称、规格公差、分类符号一致，并写明配对成功而类别符号不同判不通过；三处符号不一致就不满足本条，原文已给出结论。
