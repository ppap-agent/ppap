# ORD:1 条款语义检查报告

- **规则文件**：订货规范：受控章-存在性（ORD:1）
- **规则原文**：订货规范（BV）文件中必须包含受控章；没有受控章即不通过。存在疑似印章图形但章内文字或受控标识无法辨认的，按不通过处理并提示人工复核。 供应商签署栏加盖合同章的，与受控公章同等认定。供需双方的责任签署栏均须有对应负责人签字，存在空白未签栏位的按签署不闭环判。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
