# PFMEA:5 条款语义检查报告

- **规则文件**：潜在过程失效模式及后果分析（PFMEA）：PFD工序-覆盖（PFMEA:5）
- **规则原文**：过程流程图（PFD）中的全部主工序，均须在 PFMEA 中被覆盖并开展失效分析。正常路线中独立编号、但只负责转运、不改变产品状态的工序属辅助物流，不算主工序，不要求在 PFMEA 中有对应的失效分析；可在提醒项中提醒 PFD 中有转运工序未在 PFMEA 中体现。 覆盖按“工序号＋核心工艺语义”归并认定：一个 PFD 工序在 PFMEA 中拆成多个工序行，只要核心工艺语义一致，视为已覆盖；反过来一个 PFMEA 行聚合多个 PFD 工序的，只要逐工序均有对应失效模式，同样视为已覆盖。不得仅因两侧行数不等就判未覆盖。“原材料检验”与“原材料入库检验”、“冲压”与“模具冲压”、“产品存储”与“产品存放”认作同一道工序。 缺少 PFMEA 与 PFD 的对应关系，或任一 PFD 主工序在 PFMEA 中无对应失效分析，即不通过。同批次未提交过程流程图时，本条记“不适用”并写明依据，不记作通过，也不得因缺 PFD 判本条不通过（缺件计数只在包级报一次）。 本条与过程流程图规则 2 的图形符号判据、控制计划规则 7“PFD 工序须在 CP 中出现”分属不同链路：本条只判 PFD→PFMEA 方向的工序覆盖，不判工序名称逐字一致，也不判特性覆盖（特性覆盖见规则 3、规则 4）。
- **结论**：3 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 暂存工序是否算主工序

原文：「过程流程图（PFD）中的全部主工序，均须在 PFMEA 中被覆盖并开展失效分析」「正常路线中独立编号、但只负责转运、不改变产品状态的工序属辅助物流，不算主工序」

例子：PFD 正常路线上的第 60 道为“半成品暂存（待检区）”，独立编号，不改变产品状态，也不负责转运；PFMEA 中没有这道工序，PFD 其他工序在 PFMEA 中都有对应失效分析。

- 理解一（只排除转运）：只有转运工序不算主工序，暂存仍是主工序，要有失效分析。（该例判不通过）
- 理解二（暂存也不算主工序）：不改变产品状态的暂存和转运一样不算主工序，不要求失效分析。（该例判通过）

反例复核：两表对应关系清楚，其他工序都已覆盖，只有暂存工序是否算主工序有分歧。原文只把只负责转运、不改变产品状态的工序排除在主工序之外，没有正面说明什么是主工序；原文把“产品存储”与“产品存放”认作同一道工序，只说明两种名称怎样对应，没有说暂存必须做失效分析。两种理解都不违反原文其他要求。

**请确认**：PFD 正常路线上独立编号、不改变产品状态、也不是转运的暂存工序，算主工序吗？

### 2. 返工支线工序是否算主工序

原文：「过程流程图（PFD）中的全部主工序」「正常路线中独立编号」

例子：PFD 正常路线为第 10～90 道；第 50 道检验后另画一条不合格品支线“55 返工”，独立编号；PFMEA 覆盖了第 10～90 道全部工序并有失效分析，但没有返工工序。

- 理解一（除转运外都算）：PFD 中除转运外的编号工序都是主工序，返工也要有失效分析。（该例判不通过）
- 理解二（只指正常路线上的工序）：主工序是正常路线上的工序，返工支线不算主工序。（该例判通过）

反例复核：正常路线上的工序都已覆盖，两表对应关系清楚，只有返工工序是否算主工序有分歧。原文只说正常路线上的转运工序不算主工序，没有说明不在正常路线上的工序算不算主工序；返工既不是转运，也不在正常路线上，两种理解都不违反原文其他要求。

**请确认**：PFD 中不在正常路线上、独立编号的返工工序，算主工序吗？

### 3. 工序编号完全不同时是否算覆盖

原文：「覆盖按“工序号＋核心工艺语义”归并认定」「缺少 PFMEA 与 PFD 的对应关系」

例子：PFD 工序编号为 10、20、30，依次为下料、冲压、焊接；PFMEA 编号为 OP100、OP200、OP300，内容依次为下料、冲压、焊接，每道都有失效分析；PFD 没有其他工序。

- 理解一（工艺内容对上即可）：编号只作参考，工艺内容逐一一致就算覆盖，两表有对应关系。（该例判通过）
- 理解二（工序号也要对上）：工序号和工艺内容都要对应；编号对不上，就是缺少两表的对应关系。（该例判不通过）

反例复核：三道工序的工艺内容一一对得上，各有失效分析，两边行数也相同，只有编号不同。原文写明覆盖按工序号加核心工艺内容认定，这可以理解为工序号也要对上，原文可能已经有结论；但原文没有写两边编号方式完全不同时怎样处理，拆成多行、合并成一行两种情形又只要求工艺内容一致或逐工序有失效模式，也不要求名称逐字一致，所以只看工艺内容的理解也没有被原文明确排除。

**请确认**：PFMEA 与 PFD 工序编号完全不同、但工艺内容逐一对得上时，算已覆盖吗？

## 已排除的疑似问题（不进入问卷）

- **PFMEA 是否要另设一栏写明对应的 PFD 工序**：原文已说明对应关系按工序号和核心工艺内容认定，没有要求另设对应栏或引用说明；要求另设栏目是在原文之外加字段。
