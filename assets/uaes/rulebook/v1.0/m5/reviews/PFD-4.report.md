# PFD:4 条款语义检查报告

- **规则文件**：过程流程图（PFD）：核心控制节点-完备性（PFD:4）
- **规则原文**：过程流程图须包含四类核心控制节点： 1. 来料控制（进货检验／来料接收／原材料入库检验）； 2. 发运控制（出货检验／GP12／发运前确认）； 3. 异常处理（不合格品处理／返工返修／隔离／报废／偏差处理之一）； 4. 成品仓储与交付（成品入库、仓储、包装、发运）。 四类节点各须至少有一处对应工序或标注，缺任一类即不通过。节点名称允许同义写法，按工程语义认定，不按字面逐字匹配。第 3 类“异常处理”为四选一即可（不合格品处理、返工返修、隔离、报废、偏差处理中命中任一项），不要求四者同时具备；第 1、2、4 类同样为“该类节点存在即可”，不要求同名节点全覆盖。 来料或发运以“免检”“顾客免检”“直送上线”“供方自检”等声明替代的，该声明本身即构成对应节点的存在证据，不因无检验工序判缺节点。四类节点分散在不同页、不同泳道或不同分表中的，按全表合并统计，不按页判缺。 若产品工艺客观上不具备某类节点（如单件试制无成品仓储、整批直发无独立仓储段），须在流程图或提交说明中书面写明；未写明的按缺节点判不通过；已在流程图或提交说明中书面写明的，判通过并在依据中照录该说明（该说明是否成立由工程确认，不影响本条结论）。 本条与规则 2 分属不同对象：规则 2 判符号体系是否规范、检验活动是否用检验符号表达，本条判四类控制节点是否齐备，两者同时适用，不可互替。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **缺仓储已有书面说明能否免查异常处理**：该说明只覆盖客观不具备的那一类。例如已解释单件试制无仓储但漏异常处理且无对应说明，整条仍不通过。
- **来料免检声明是否也能判符号体系通过**：它能证明来料控制节点存在，但不能判定流程图图例齐全。规则2即使失败，也不能反向抹去已成立的节点。
- **“四选一”与括内列五项是否需要客户选判**：枚举数量的写法不准，但括内明确列五项并明说命中任一项。只有“偏差处理”也已被明文接纳，不存在相反的可用判定。
