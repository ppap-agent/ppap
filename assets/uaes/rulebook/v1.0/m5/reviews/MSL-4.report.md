# MSL:4 条款语义检查报告

- **规则文件**：材料产品及分供清单：PFD-双向溯源（MSL:4）
- **规则原文**：材料产品及分供清单须与过程流程图双向溯源： 1. 过程流程图中的外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）与核心原材料，须在分供清单中有对应记录； 2. 分供清单中的每一项外协工序与原材料，须在过程流程图中有对应节点。 任一方向存在缺失即不通过。核心原材料只指构成零件主体的材料，配方辅料不要求列入分供清单。对应关系按“工序名称／材料牌号的工程语义”认定，允许简称与别名，不要求逐字一致；分供方名称写法与流程图不同的，不判不通过。过程流程图中不写材料名称的“进料检验”节点，算核心原材料的对应节点。 过程流程图中标注为“自制”“厂内”“内制”的工序，不要求出现在分供清单中；分供清单标注“外购”“外协”“委外”的项，必须在流程图中有节点，缺失按“分供项未上流程图”判不通过。 同批次未提交过程流程图时本条记“不适用”并写明依据，不记作通过；缺件计数只在包级报一次。本条与规则 3 分属不同对象：规则 3 判与图纸的零件号、零件名称一致，本条判与过程流程图的双向溯源，两者同时适用。
- **结论**：3 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 括号里列出的工序没有标自制或外协

原文：「过程流程图中的外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）与核心原材料，须在分供清单中有对应记录」「过程流程图中标注为“自制”“厂内”“内制”的工序，不要求出现在分供清单中」

例子：过程流程图第 40 道工序为“热处理”，没有任何自制、厂内、内制或外协标注；分供清单里没有热处理的分供方或记录；其余外协工序和核心原材料两个方向都对得上。

- 理解一（没标自制就按外协）：括号里列出的工序类型，除非标了自制、厂内、内制，都要在分供清单里有记录；本例缺热处理记录。（该例判不通过）
- 理解二（看得出外协才要求）：只有流程图上看得出是外协的工序才要求在分供清单里有记录；本例热处理没有外协标注，不要求记录。（该例判通过）

反例复核：原文把热处理列在外协工序后面的括号里，又只免除了标注自制、厂内、内制的工序，可以读成没有这些标注就按外协要求；但括号也可以读成外协工序的举例，只有确实外协的热处理才算，原文没有说没标注的工序算不算外协。其余对应关系在两种理解下都满足，差别只在这一道工序要不要在清单里有记录。

**请确认**：流程图上的热处理这类括号里列出的工序，既没标自制也没标外协时，要不要在分供清单里有记录？

### 2. 金属嵌件算不算核心原材料

原文：「核心原材料只指构成零件主体的材料，配方辅料不要求列入分供清单」

例子：注塑件由 PA66-GF30 塑料本体和黄铜螺纹嵌件组成；过程流程图有“PA66-GF30 进料”和“铜嵌件进料”两个节点；分供清单只列了 PA66-GF30 及其供应商，没有铜嵌件；分供清单上的每一项在流程图上都有节点。

- 理解一（嵌件也算主体材料）：铜嵌件是零件实体的组成部分，属于核心原材料，分供清单里缺它的记录。（该例判不通过）
- 理解二（主体只指塑料本体）：零件主体指塑料本体，铜嵌件是嵌在其中的部分，不算核心原材料，不要求列入分供清单。（该例判通过）

反例复核：原文只把配方辅料排除在外，铜嵌件不是配方辅料，但原文也没有说一个零件由两种材料组成时，“零件主体”指哪一部分。分供清单到流程图的方向在两种理解下都满足，差别只在铜嵌件要不要在分供清单里有记录。

**请确认**：零件由塑料本体和金属嵌件组成时，金属嵌件算不算构成零件主体的核心原材料？

### 3. 分供清单里列了配方辅料

原文：「分供清单中的每一项外协工序与原材料，须在过程流程图中有对应节点」「配方辅料不要求列入分供清单」

例子：分供清单列了 PA66-GF30 和黑色色母两项及各自供应商，两项都没有外购、外协、委外标注；过程流程图只有“PA66-GF30 进料检验”节点，没有色母节点，也没有不写材料名称的进料检验节点；其余外协工序两个方向都对得上。

- 理解一（列入的辅料也要上图）：配方辅料也是原材料，列进分供清单就属于“每一项原材料”，流程图上要有节点；本例色母没有节点。（该例判不通过）
- 理解二（辅料不在溯源范围）：配方辅料不属于要求溯源的原材料，列不列、流程图上有没有节点都不影响本条。（该例判通过）

反例复核：原文说配方辅料不要求列入分供清单，但没有说已经列入的配方辅料在分供清单到流程图的方向上算不算“原材料”；本例色母没有外购、外协、委外标注，标注项必须上流程图的那句也用不上。PA66-GF30 和其余工序两个方向都对得上，差别只在色母要不要有节点。

**请确认**：分供清单里列了色母这类配方辅料、又没标外购、外协、委外时，流程图上也必须有它的节点吗？
