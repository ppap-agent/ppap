# MSA:2 条款语义检查报告

- **规则文件**：测量系统分析评价：计划与报告-一致性（MSA:2）
- **规则原文**：文件内或同批次文件集中须有测量系统分析计划表，并有重复性及再现性（GR&R）报告或 Kappa 报告。计划表每一种量具须有匹配的报告：人工、目视、通止规、塞规、塞尺等计数型量具对应以评价者为对象的 Kappa 研究，其余量具对应 GR&R 报告。匹配键为零件号＋特性/量具名称，不比量具编号。同一零件的计划里只有一把该名称的量具时，报告也须同时写明所判特性，只写量具名称不能认定匹配。报告所判特性的测量参数或其公差没有写单位的，不按计划表的单位比对，记待确认。每份 GR&R 报告的结论须为“测量系统可以接受”或意思相同的表述（如“合格”“OK”），每份 Kappa 报告的结论须为“Acceptable”（含可接受、合格、Good、PASS 等等价写法）。 匹配键不含量具编号，规则也不要求报告与计划表的量具编号一一对应：Kappa 研究的对象是评价者（检验人员），报告内通常无量具编号可对应，若按量具编号去配对，会使全部计数型量具项恒判“无法对应”。量具编号只作辅助核对，不作匹配键，也不作为判不通过的理由。 任一项不满足即不通过。 结论合格还须底层指标达标，不只看结论栏：%GRR ≤ 10% 判合格；10% < %GRR ≤ 30% 须附客户批准或整改说明方可判合格；%GRR > 30%、ndc < 5 且无公差带豁免说明、Kappa < 0.75 的，即使结论栏写“可接受”，也按数据失真判不通过。报告同时有总体 Kappa 和各评价者相对标准的 Kappa 时，只核总体 Kappa，单个评价者的分项值不单独否决，在提醒项中说明单个评价者的分项值。Cgk 报告的阈值判定归规则 5，本条不判 Cgk，避免同一份 Cgk 报告被本条与规则 5 各判一次。 同一特性下同类量具的分析报告份数，不得少于计划表所列该类量具的台数：N 台不同编号的同类量具须有 N 份报告，不得用一份报告或重名的多份报告顶替。份数不足的按“同类量具报告份数不足”判不通过，与“报告缺失”分开表述，不计入同一缺陷。份数比对只核份数是否达到，仍不比编号；报告内评价者、样本编号、测量日期不同的多份报告，视为分别覆盖不同台同类量具。 判定对象限于本文件对应的量具。 报告型子文件只判该文件自身对应的那一行量具，不得拿套件计划表全集逐份复判；同一套件、同一缺陷只记一次，其余子件判通过并写明该缺陷不在本文件归属范围内。同批次没有测量系统分析计划表的，每份测量系统分析文件都判不通过。 份数判定（上一段）除外——数台数须以套件计划表全集的台数为基准，不受“限于本文件”约束；数完之后的具体判定仍回到本文件对应的量具，两者不冲突。 量具名称写法跨类、无法判定属计数型还是计量型的（如“通止塞规”既可读作通止规亦可读作综合检具、“卡尺+目视”混写），移交工程裁定并写明原写法，不得按缺报告硬判；量具名称为空或为占位词的，该判定项记“未审”。占位词指下列写法：“见附表”“见附件”“待定”“TBD”“NA”“N/A”“—”“-”“/”“同上”“见上”“略”“*”“待补”“后续提供”“XX”“XXXX”“123456”，以及 Excel 公式报错码 #N/A、#REF!、#DIV/0!、#VALUE!、#NAME?、#NUM!、#NULL!；未填字的空心方框 □ 与黑色涂抹遮挡块同样按未填处理。不能仅凭单元格非空就认定具有实质内容。填占位词与单元格空白是两种不同问题，须分开陈述。 Kappa 结论属“有条件接受／边界”类（Marginal／临界／Near／Conditional／有条件接受）的，既非合格也非不合格，须整改后复评，按不通过处理，不与“不合格”混记。
- **结论**：4 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. %GRR 取哪一个百分比

原文：「%GRR ≤ 10% 判合格」「10% < %GRR ≤ 30% 须附客户批准或整改说明方可判合格」

例子：计划表外径特性用一把卡尺；有一份同件号、同特性、写明卡尺的 GR&R 报告，结论“测量系统可以接受”，ndc 为 6；报告同时列出相对总变差的 %GRR 22% 和相对公差的 %GRR 8%；没有客户批准或整改说明。

- 理解一（用相对公差的 %GRR）：取 8%，不超过 10%，这项指标合格。（该例判通过）
- 理解二（用相对总变差的 %GRR）：取 22%，在 10% 到 30% 之间，要附客户批准或整改说明，本例两者都没有。（该例判不通过）

反例复核：原文只写 %GRR，没有说以总变差还是公差为基准，两种取法都不违反原文。匹配、结论和 ndc 在两种理解下都满足，差别只在取哪一个百分比与门槛比较。

**请确认**：一份 GR&R 报告同时列出相对总变差和相对公差两个 %GRR 时，应拿哪一个与 10%、30% 比较？

### 2. 报告里有两个总体 Kappa

原文：「报告同时有总体 Kappa 和各评价者相对标准的 Kappa 时，只核总体 Kappa」「Kappa < 0.75」

例子：计划表的外观目视检验和一份 Kappa 报告的件号、特性、评价对象都对得上，结论“Acceptable”；报告列出评价者之间的总体 Kappa 0.72、全体评价者与标准比较的总体 Kappa 0.78，以及甲、乙、丙各自与标准比较的 Kappa 0.80、0.70、0.85。

- 理解一（只核与标准比较的总体值）：总体 Kappa 指全体评价者与标准比较的值，取 0.78，不低于 0.75。（该例判通过）
- 理解二（两个总体值都核）：评价者之间的值也是总体 Kappa，0.72 低于 0.75。（该例判不通过）

反例复核：原文把总体 Kappa 和各评价者与标准比较的 Kappa 放在一起说，可以读成与标准比较的总体值；但原文没有把总体 Kappa 限定为与标准比较，评价者之间的一致性也是全体评价者的总体值。匹配和结论在两种理解下都满足，乙的 0.70 按原文只在提醒里说明，差别只在 0.72 要不要参与门槛。

**请确认**：Kappa 报告同时列出评价者之间的总体 Kappa 和全体评价者与标准比较的总体 Kappa 时，0.75 门槛核哪一个，还是两个都要核？

### 3. 名称相同但内容不同的报告

原文：「不得用一份报告或重名的多份报告顶替」「报告内评价者、样本编号、测量日期不同的多份报告，视为分别覆盖不同台同类量具」

例子：计划表外径特性列了两台不同编号的卡尺；同批次有两份 GR&R 报告，名称都是“外径卡尺 GR&R 分析报告”；一份评价者甲乙丙、样本 1～10、10 月 8 日测量，另一份评价者丁戊己、样本 11～20、10 月 15 日测量；两份结论都是“测量系统可以接受”，各只列一个 %GRR，分别为 7%、8%，ndc 都不小于 5。

- 理解一（名称相同只算一份）：重名指报告名称相同，两份同名报告不能分别计数，份数少于计划表的两台。（该例判不通过）
- 理解二（内容不同就分别计）：两份报告评价者、样本编号、测量日期都不同，当作分别覆盖两台，份数够。（该例判通过）

反例复核：原文一句不许用重名的多份报告充数，另一句又说评价者、样本编号、测量日期不同的报告当作分别覆盖不同台，没有说两句同时碰上时以哪句为准，也没有说重名指报告名称相同还是内容重复。匹配、结论和指标在两种理解下都满足，差别只在算一份还是两份。

**请确认**：两份报告名称相同，但评价者、样本编号、测量日期都不同，能分别算作两台同类量具的报告吗？

### 4. 报告只有各评价者的 Kappa

原文：「Kappa < 0.75」「报告同时有总体 Kappa 和各评价者相对标准的 Kappa 时，只核总体 Kappa，单个评价者的分项值不单独否决」

例子：套件有测量系统分析计划表，目视检验的件号、特性、评价对象和一份 Kappa 报告都对得上，结论“Acceptable”；原报告逐页确认只有甲 0.69、乙 0.89 两个各评价者与标准比较的 Kappa，没有列总体 Kappa，不是没读出来。

- 理解一（分项值照样核门槛）：没有总体值时，各评价者的值就是要核的 Kappa，甲 0.69 低于 0.75。（该例判不通过）
- 理解二（须有总体值才能判）：0.75 门槛只对总体 Kappa，报告缺总体值时不能用分项值代替，原文没有给出这时的结论。（该例判原文未定）

反例复核：原文可能已有结论：只在报告同时有总体 Kappa 时才不让单个评价者的值单独否决，本例没有总体值，这一免除用不上，各评价者的值也是 Kappa，可直接按“Kappa < 0.75”核对。但原文也可以读成 0.75 门槛本来就是对总体值说的，单个评价者的值不代表整个测量系统，原文没有说缺总体值时怎么判。匹配和结论在两种理解下都满足，差别只在甲的 0.69 能不能直接判不通过。

**请确认**：报告只有各评价者相对标准的 Kappa、没有总体值时，能否用分项值判断 0.75 门槛，还是要补总体值才能判？

## 已排除的疑似问题（不进入问卷）

- **整套缺计划表时，这一项只在套件记一次还是挂到某一份报告，两份报告各自怎么判**：新写法专门规定了同批次没有计划表时每份测量系统分析文件都判不通过，原文对这个例子已有结论；“同一缺陷只记一次、其余子件判通过”说的是归属某一份文件的缺陷，缺计划表时每份报告都找不到自己的计划行。
- **GR&R 报告 %GRR 在 10% 到 30% 之间并附客户批准，结论写“有条件接受”时，结论算不算可以接受**：原文要求结论是“测量系统可以接受”或意思相同的话，“有条件接受”带有条件，意思不同，本条对同类的 Kappa 结论也写明“有条件接受”既非合格也非不合格；客户批准是指标一项的要求，原文没有说它能代替结论的要求。
