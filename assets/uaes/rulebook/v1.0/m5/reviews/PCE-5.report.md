# PCE:5 条款语义检查报告

- **规则文件**：过程能力研究：过程特性目录-覆盖（PCE:5）
- **规则原文**：过程能力分析报告必须包含目录页；同批次必须有同零件号的独立《采购件质量计划》文件且其中包含 PGQP1 表；PGQP1 中的全部过程特性，必须出现在过程能力分析报告目录中。三项全部满足才通过，否则不通过。 同批未提交《采购件质量计划》，或其中无 PGQP1 表时，本条判不通过并标明“整份未交”，不记“不适用”；缺件计数只在包级报一次，不在本条重复计数。 目录页名称不限，“目录”“目次”“CONTENTS”等均算。同批同零件号、确为同一套过程能力分析报告的分册，且各有目录页时，合并各份目录核对是否覆盖 PGQP1 中的全部过程特性，不要求每份目录分别列全。 目录中有记录不等于已研究：每一条出现在目录中的过程特性，还须有对应的能力研究页并给出 Cpk 或 Ppk 实测值；目录有记录、报告内无对应研究页或研究页无可读能力值的，按“报告未齐套”判不通过，不得仅凭目录页命中就判通过。 本条判的是“是否实际做了研究”，规则 4 判的是“特殊特性是否在目录中”，两者不得合并：目录覆盖与报告齐套须分别成立，一项通过不能冲抵另一项不通过。定性过程特性（纯目视判定、无数值规格）只要求在目录中有记录，不要求能力研究页，不计入齐套缺项。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 只出现于关键工序说明的参数是否列入过程特性

原文：「PGQP1 中的全部过程特性」「合并各份目录核对是否覆盖 PGQP1 中的全部过程特性」

例子：同批有同号独立采购件质量计划，含 PGQP1。特性未分类；“关键工序”说明仅列“压铸：压射速度、模温”，另列有成品尺寸。同套两册均有目录，合看只列了尺寸，没有上述两个参数。各目录已列项目在本册均有对应研究页和可读实测 Cpk，没有其他缺项。

- 理解一（按参数所描述的工艺识别）：压射速度、模温直接描述制程，应列入目录，合看仍缺两项。（该例判不通过）
- 理解二（区分工序说明与被列为特性的项目）：若只在关键工序说明中提及，并未作为过程特性列示，就不纳入本条需覆盖的对象；本例未漏其他对象。（该例判通过）

反例复核：遗漏对象是两个工序参数，不是“压铸”这一工序名称。两册目录如何合算、现有研究是否齐套都没有争议。“过程特性”既可按参数实际描述的对象识别，也可按 PGQP1 是否把它作为须管理的特性列示来识别：关键工序的背景说明不必然是正式特性列表。本条未说明只在工序说明列名的参数如何取舍。

**请确认**：PGQP1 没分产品特性与过程特性，只在“关键工序”一节写了压铸的压射速度和模温。各册目录合看仍无这两个参数，是否算漏了必须覆盖的过程特性？

### 2. 目录条目与研究页分置于同套两册

原文：「确为同一套过程能力分析报告的分册」「合并各份目录核对是否覆盖 PGQP1 中的全部过程特性」「目录有记录、报告内无对应研究页或研究页无可读能力值的」

例子：同批同号独立质量计划有 PGQP1，明确将压射速度列为定量过程特性。能力报告甲、乙两册确属同套且各有目录，合计覆盖全部过程特性。甲册目录将压射速度定位到乙册第12页；该页特性编号、工序一致，有可读实测 Cpk 1.60；甲册内无此研究页。其他项目在本册的研究页和实测值都齐全。

- 理解一（以整套报告认定研究页所在范围）：同套乙册的研究页可以对应甲册目录，不需要在甲册复制同一页。（该例判通过）
- 理解二（以列出该条目的分册认定研究页所在范围）：合并仅用于目录覆盖；甲册列了该特性但册内没有研究页，报告未齐套。（该例判不通过）

反例复核：两种读法都要求存在同一特性的研究页和实测值；本例确实有，且对应关系无疑。争议仅在“报告内”的范围：条文明示合并的是目录，未明说研究页也合并，亦未要求目录引用的研究页与条目同册。这不是把仅有目录当作做过研究，也不是重问目录能否合并。

**请确认**：定量过程特性列在甲册目录，目录明确指向同套乙册的研究页，且页上有该特性的实测 Cpk。甲册没有重复放这页，算报告齐套吗？

## 已排除的疑似问题（不进入问卷）

- **目录合并后列全是否可以不查定量特性的研究页和实测值？**：不可以。目录覆盖与报告齐套是两个要求；不论研究页的分册范围如何，只要全套都没有对应研究页或可读值，便不能凭目录项通过。
- **纯目视无数值规格的特性可否连目录也不列？**：只免研究页，不免目录记录。
