# SCL:2 条款语义检查报告

- **规则文件**：特殊特性清单：必填列-校验（SCL:2）
- **规则原文**：本类目通用口径（规则 1、规则 2、规则 3 均适用） 本类清单常为多件号混装母版：判定前必须先按本件号过滤出行范围，只在过滤范围内统计与判定，跨件号的行不参与判定；依据须写明“按本件号 XX 过滤，参与判定 N 行”。件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在。未按件号过滤而按全表统计的，属未按范围执行，所得结论无效。 特殊特性清单必须包含“编号/序号”“产品特性/过程特性/特殊特性名称”“特性及公差/特性值”“特性类型/特性类别”四类列；每一条“编号/序号”有值的记录中，同行其余三类列的内容也必须非空。 缺少任何必需列或任何应填内容即不通过。清单有件号列、混有多个件号，而所交资料不能确定本件号时，本条记待审核（交人工），不按全表判定。四类列内部允许同义别名（如“特性名称”≒“产品特性”、“规格/公差”≒“特性及公差”、“分类”≒“特性类别”），按行判定，禁止跨行拼配。 仅作过程参考的普通行（普通工艺温度、普通非关键尺寸）不属管控对象，其“特性类型/特性类别”列留空或填“/”，视为该列对本行无意义、已按规填写，不构成缺项、按通过计并留痕，不作占位缺陷，这不是“不适用”声明，不得写成“记不适用”；此类行仍须有“编号/序号”与特性名称、特性及公差。属管控项（特殊特性清单或控制计划中的特殊特性）的行，三类列仍不得为空。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### G1. 已知是单件号清单，但表体没有件号列

原文：「判定前必须先按本件号过滤出行范围」「件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在」「清单有件号列、混有多个件号，而所交资料不能确定本件号时，本条记待审核（交人工），不按全表判定。」

例子：已确认送审件号为 A，清单表头标 A，全表仅用于 A，无合并的其他件号；表体八条记录，没有“零件号”“Part No.”或“Code”列，四类业务列均有，八行编号、名称、公差及类别均已填写。

原文没有明确规定这个例子的判定结论。

反例复核：八行的内容没有缺项，问题只在认可何种方式圈定本件号行。列的四项结构要求没有把件号列列为第五项；但前文要求先按本件号过滤，并未说明能否用表头确定整个单件表的行范围。混装且无法确定本件号的待审核规定不能直接用于此例。

**请确认**：表头件号已确定、整表只对应这一件，表体却没有件号列。可否将表体全部记录认作本件号行，再检查四类列及同行内容；如不能，应记什么结果？

## 已排除的疑似问题（不进入问卷）

- **混有 A、B 两件且本件号未知时能否按全表通过率给结论**：三个条件同时满足时本条明确记待审核、交人工，不看全表通过率。
- **一条普通参考行可以不填类别，表头是否也可以缺整个类别列**：例外针对一行中的类别格；四类列的结构义务不受影响。
- **普通参考行类别填 / 能否豁免空公差**：豁免只指类别格，公差仍须有实质内容。
