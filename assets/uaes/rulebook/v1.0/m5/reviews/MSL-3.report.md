# MSL:3 条款语义检查报告

- **规则文件**：材料产品及分供清单：图纸信息-一致性（MSL:3）
- **规则原文**：同批次必须提交与当前项目、物料编号一致的图纸独立文件；分供方清单中的“零件名称”“零件号”必须分别与该图纸中的“零件名称”“零件号”一致。同项目、同物料编号的图纸以中文和英文并列写出零件名称时，清单的零件名称与其中一种语言的完整名称完全相同，即按名称一致认定。同一项目与件号有两份均在用的图纸、零件名称不同的，分供清单的零件名称与任一份在用图纸相同就算一致。 缺少图纸或任一字段不一致即不通过。比对前先做同号校验：图纸与分供清单的零件号本身不一致的，属比对源错配，与“字段内容不一致”分开表述。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **双语图纸标“壳体 Housing”，清单只写“壳体”，是否必须再补英文**：“壳体”与图纸中文完整名称逐字相同，名称项成立；不要求两种语言一起写。此句不能用于认可简称、近义词或另译。
- **名称完全相同，能否盖过图纸与清单的件号不一致**：不能。件号不一致要标明比对源错配；这改变说明方式，不使错号文件通过。
- **两份名称不同的同项目同件号在用图纸，是否必须两份都匹配**：只有名称项的任选其一，已经写明，不与分别核对名称、件号的要求冲突。

未发现需要客户确认的条款表述问题。
