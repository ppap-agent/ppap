# IR:1 条款语义检查报告

- **规则文件**：初始样品检验报告：尺寸报告-列数校验（IR:1）
- **规则原文**：文件中必须存在尺寸报告，且尺寸报告中“实测值”的列数必须为 3 或 3 的倍数。列数按“有读数（非空）的列”计。 缺少尺寸报告或实测值列数不符合要求即不通过。 定量尺寸的任一实测值超出“名义值与上下公差”构成的区间，且同批次无覆盖该项的顾客工程批准/偏差许可的，无论单项结论写 OK 还是 NG，均按超差判不通过。顾客工程批准须具体指向该超差项才算覆盖；仅笼统认可尺寸合格或产品完全认可，不算覆盖该项。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 顾客工程师在超差行署名，未注明是否接受偏差

原文：「顾客工程批准须具体指向该超差项才算覆盖」「且同批次无覆盖该项的顾客工程批准/偏差许可的」

例子：同批尺寸报告有三列实测值，第 23 项 10.00±0.10 mm 实测 10.04、10.07、10.16 mm。该行明确标出超差 0.06 mm，顾客工程师本人在该行“顾客工程师”栏签名。表单无签名用途说明，未写接受或拒绝偏差，也无另份许可。其余尺寸都在范围内。

- 理解一（该项会签即代表认可）：在资料已明示超差量的该行，顾客工程师专栏会签就是对该项的工程认可，无须再写“同意”。（该例判通过）
- 理解二（签名还应能表明接受）：无用途说明的人员栏能证明工程师就此行签过名，不能单凭其姓名认定已准许该偏差。（该例判不通过）

反例复核：批次、签名真实性和所指超差项均无争议，区别在于这份表上的逐项会签是否表达了接受。具体指向是批准获得覆盖的必要条件，不是任意署名即准予放行的充分条件。本例也不是仅在收件栏或明确的见证栏签字，更不是旧题中的笼统整件认可。

**请确认**：顾客工程师在明列超差的那一行签名，但签名栏只写“顾客工程师”，没有批准、接受或见证字样。这一签名是否构成对该项超差的工程批准？

## 已排除的疑似问题（不进入问卷）

- **仅作整件完全认可的来函能抵消第 23 项超差吗？**：新文已明确否决这一解释。实际有对应许可时仍须据本批本项核验，不能仅因未写统一的编号格式就否定它。
- **没有任何许可，但超差行被供应商标 OK，是否应直接采用 OK？**：OK 与 NG 均不能覆盖无许可的实测超差。
