# CP:5 条款语义检查报告

- **规则文件**：控制计划（CP）：跑道尺寸-过程能力管控（CP:5）
- **规则原文**：控制计划中的跑道尺寸必须具有过程能力管控，方式为 X-R 图／SPC 控制等过程能力管控要求。 跑道尺寸行的识别：在加工／制造类工序中，“产品/过程特性”“特殊特性”“产品/过程规格/公差”三列均有内容、且特性名为尺寸、位置度等定量类的行。对每个跑道尺寸行，其“评价测量技术”“频率”“控制方法”三列中至少一列含 SPC／控制图／X-R／Cpk／Ppk 等过程能力管控要求即通过，不要求同时写控制图类型与能力指数。 逐行检索后未发现任何跑道尺寸行的，本条记“不适用”并写明依据（该零件确无定量尺寸特性），同时输出提示项核实，由供应商在控制计划或提交说明中书面确认；不因“未发现跑道尺寸行”判不通过，也不记作通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
