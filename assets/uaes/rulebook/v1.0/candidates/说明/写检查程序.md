# 写 UAES v1.0 修订 3 的候选检查程序

你为分到的文件类型写候选检查程序，让它按修订 3 的条文判真实文件。

## 先读

- 仓库根目录 `AGENTS.md` 里「受保护资产」一段，`docs/rules.md` 第 7 步「检查程序与澄清并行」，`assets/uaes/AGENTS.md`。
- `tests/corpus/contracts/src/corpus_contracts/candidate_run.py`（候选怎么跑）。
- 你那一类已安装的叶子 `packages/audit/src/audit/checkers/uaes/<Uxx>/`（rules.json、checker.py、resources.py），和它调用的实现 `packages/audit/src/audit/checker_lib/uaes/*.py`、`packages/audit/src/audit/checker_lib/agents.py`。

## 条文

- 修订 3 的条文在 `assets/uaes/rulebook/v1.0/m3/条文/<类型缩写>.json` 的 `rules[].rule_to_check`，条款编号如 `CP:6`。这是唯一依据。
- 候选叶子 `rules.json` 的 `rules[]` 换成修订 3 的条款：`id` 用修订 3 编号，`rule_to_check` 与上面文件**逐字一致**（规则页按条文摘要比对，差一个字就对不上）。`checker_binding` 相应改成新编号。其余字段照已安装叶子的样子填。

## 放在哪里

- `assets/uaes/rulebook/v1.0/candidates/uaes/<Uxx>/`，叶子名与已安装的相同（如控制计划是 `U08`），这样 `candidate_run` 才能替换它。
- 新的判定代码放在叶子目录自己的模块里（例如 `cp_r3.py`），可以继承 `audit.checker_lib.uaes` 里现有的读取类，复用它的读表、定位、取证；`resources.py` 的 `carriers` 指向你的模块，`methods` 把每个修订 3 条款编号映射到你的方法。
- **不得修改或删除** `packages/audit/src/audit/checkers/`、`packages/audit/src/audit/checker_lib/`、`assets/uaes/samples/`、`assets/corpus/` 下的任何文件。确实需要改共享代码时，停下来在汇报里说明，不要改。

## 规矩

- 判定必须是程序：读单元格、文字、勾选、印章等事实后用代码判。不把条款或文件内容交给模型去判通过不通过。模型只能用于读取（现有读取栈：表格 → 文本抽取 → 图片识别），读不出就 UNABLE。
- 条文模糊的地方照条文的模糊写法实现，选最贴近原文字面的做法，并在汇报里列出你在哪里做了取舍；不替客户做判断，不补条文没有的条件。
- 身份严格匹配：零件号、版本照原样比，不猜相似号。
- 扫描版 PDF（没有文字层）记 UNABLE。
- 跨文件条款按条文找同批关联文件；关联文件不在批里时，按条文写的处理（有的写不通过，有的写不适用、有的回退别的文件）。
- 不读 `assets/uaes/rulebook/v1.0/candidates/reference-judgments*`、`assets/corpus/` 的真值和评测集、`assets/uaes/clause-check-semantic-v2/`、任何旧修订的审查记录。

## 试跑

- 样本在 `assets/uaes/samples/<零件>/测试文件/<序号 类型>/`，缺陷样本在 `<零件>/缺陷样本(-test-)/`，比对文件在 `<零件>/比对文件/`。
- 对每个含你这类文件的零件运行
  `uv run --no-sync python -m corpus_contracts.candidate_run assets/uaes/rulebook/v1.0/candidates/uaes/<Uxx> --part <零件目录> --json`
  （缺陷样本用 `--file`，必要时加 `--reference` 指定关联文件），把每次的 JSON 输出存到 `assets/uaes/rulebook/v1.0/candidates/runs/<Uxx>/<零件或缺陷样本名>.json`。
- 读不出、报错的，在程序里修；条文判不出的，记进汇报，不改条文。
- 只跑相关测试，不跑全量；不提交、不推送。

## 汇报

用中文、不用黑话：每个叶子实现了哪些条款、哪些条款没有样本可试、每个样本每条的结论分布、你做了哪些取舍、哪些地方读不出或条文判不出。
