# PSW:7 条款语义检查报告

- **规则文件**：零件提交保证书（PSW）：CP表头-一致性（PSW:7）
- **规则原文**：PSW 表头的“客户零件号”须与同批次控制计划表头的“零件号”完全一致（归一后逐字符相等）；“零件名称”须与同批次控制计划表头一致，允许双语并列、简称扩展与全半角差异，不允许语义不同。 同批次未提交控制计划时，本条记“不适用”并写明依据，不记作通过，缺件计数只在包级报一次。零件号不一致的按比对源错配判不通过，不得以“客户零件号与供应商零件号体系不同”为由放宽——本条只比 PSW 的客户零件号与控制计划的零件号，两者须同为一套客户编号。 两项同时满足才通过，任一项不一致即不通过。 本条为“黄金锁”判据：PSW 是提交源头、控制计划是执行载体，两者表头不一致意味着沿整条链提交的不是同一个零件。同期只做单向比对（PSW→CP），不做 CP→PSW 的反向要求，反向差异不影响本条结论。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **同批无控制计划，要不要因通用缺件规则让 PSW 本条不通过**：原文给出更具体的条款落点：PSW 本条不适用、包级缺件单报。它不同于已交 CP 但客户件号错配。
- **能否把相差一位、但名称一样的客户编号擅作同号**：不能据名称或近似字符放宽；按通用说明使用客户件号等价口径，尚未裁定的等价争议登记交裁决，不自行改号。
