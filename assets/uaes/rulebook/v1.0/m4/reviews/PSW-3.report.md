# PSW:3 条款语义检查报告

- **规则文件**：零件提交保证书（PSW）：签字盖章-校验（PSW:3）
- **规则原文**：零件提交保证书必须包含“供方代表签字”字段；该字段必须有手写签名，且文件中还必须有印章。三项全部满足才通过，否则不通过。 签署区还须填写打印姓名/职务（Title）、电话号码、电子邮箱与签署日期，任一项缺失或格式明显不合法的按联系信息不完整判。即使模板把打印姓名和职务合在一格，打印姓名和职务也都须出现；仅写职务的，即缺打印姓名。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1.1. 联系信息不完整的结论

原文：「任一项缺失或格式明显不合法的按联系信息不完整判」「三项全部满足才通过，否则不通过」

例子：供方代表栏有手写签名，文件盖了公司章；签署区写了打印姓名、职务、电话和签署日期，没写电子邮箱。

反例复核：第一段对签字栏、签名、印章给了明确的通过与不通过；第二段用了“还须”，但结论只写“按联系信息不完整判”，没有像第一段那样写明不通过。例子中第一段三项都满足，只差邮箱，原文没有说明“联系信息不完整”是判不通过还是只记下问题。

**请确认**：签署区联系信息不完整（例如没写电子邮箱）时，本条判不通过吗？

### 2. 插入的手写签名图片算不算手写签名

原文：「该字段必须有手写签名」

例子：电子版 PSW 的供方代表签字栏插入了一张手写签名的扫描图片；文件盖了章，签署区姓名、职务、电话、邮箱、日期都齐全。

- 理解一（签名笔迹是手写的就算）：签名本身是手写笔迹，插入图片也算手写签名。（该例判通过）
- 理解二（须在本文件上亲笔签）：只有在这份文件上亲笔签的才算，插入的图片不算。（该例判不通过）

反例复核：原文只说“手写签名”，没说签名必须是在这份文件上亲笔签的，也没说插入的手写签名图片算不算。例子中签字栏、印章和联系信息都满足，结论只取决于这张图片算不算手写签名。

**请确认**：供方代表栏是把手写签名扫描成图片插入文件的，算“手写签名”吗？

## 已排除的疑似问题（不进入问卷）

- **“格式明显不合法”指什么程度**：这是原文有意留的宽泛说法，没有具体例子能证明原文无法判断；不替客户把宽泛说法定死。
