# MSA:2 条款语义检查报告

- **规则文件**：测量系统分析评价：计划与报告-一致性（MSA:2）
- **规则原文**：文件内或同批次文件集中须有测量系统分析计划表，并有重复性及再现性（GR&R）报告或 Kappa 报告。计划表每一种量具须有匹配的报告：人工、目视、通止规、塞规、塞尺等计数型量具对应以评价者为对象的 Kappa 研究，其余量具对应 GR&R 报告。匹配键为零件号＋特性/量具名称，不比量具编号。同一零件的计划里只有一把该名称的量具时，报告也须同时写明所判特性，只写量具名称不能认定匹配。每份 GR&R 报告的结论须为“测量系统可以接受”或意思相同的表述（如“合格”“OK”），每份 Kappa 报告的结论须为“Acceptable”（含可接受、合格、Good、PASS 等等价写法）。 匹配键不含量具编号，规则也不要求报告与计划表的量具编号一一对应：Kappa 研究的对象是评价者（检验人员），报告内通常无量具编号可对应，若按量具编号去配对，会使全部计数型量具项恒判“无法对应”。量具编号只作辅助核对，不作匹配键，也不作为判不通过的理由。 任一项不满足即不通过。 结论合格还须底层指标达标，不只看结论栏：%GRR ≤ 10% 判合格；10% < %GRR ≤ 30% 须附客户批准或整改说明方可判合格；%GRR > 30%、ndc < 5 且无公差带豁免说明、Kappa < 0.75 的，即使结论栏写“可接受”，也按数据失真判不通过。报告同时有总体 Kappa 和各评价者相对标准的 Kappa 时，只核总体 Kappa，单个评价者的分项值不单独否决，在提醒项中说明单个评价者的分项值。Cgk 报告的阈值判定归规则 5，本条不判 Cgk，避免同一份 Cgk 报告被本条与规则 5 各判一次。 同一特性下同类量具的分析报告份数，不得少于计划表所列该类量具的台数：N 台不同编号的同类量具须有 N 份报告，不得用一份报告或重名的多份报告顶替。份数不足的按“同类量具报告份数不足”判不通过，与“报告缺失”分开表述，不计入同一缺陷。份数比对只核份数是否达到，仍不比编号；报告内评价者、样本编号、测量日期不同的多份报告，视为分别覆盖不同台同类量具。 判定对象限于本文件对应的量具。 报告型子文件只判该文件自身对应的那一行量具，不得拿套件计划表全集逐份复判；同一套件、同一缺陷只记一次，其余子件判通过并写明该缺陷不在本文件归属范围内。 份数判定（上一段）除外——数台数须以套件计划表全集的台数为基准，不受“限于本文件”约束；数完之后的具体判定仍回到本文件对应的量具，两者不冲突。 量具名称写法跨类、无法判定属计数型还是计量型的（如“通止塞规”既可读作通止规亦可读作综合检具、“卡尺+目视”混写），移交工程裁定并写明原写法，不得按缺报告硬判；量具名称为空或为占位词的，该判定项记“未审”。占位词指下列写法：“见附表”“见附件”“待定”“TBD”“NA”“N/A”“—”“-”“/”“同上”“见上”“略”“*”“待补”“后续提供”“XX”“XXXX”“123456”，以及 Excel 公式报错码 #N/A、#REF!、#DIV/0!、#VALUE!、#NAME?、#NUM!、#NULL!；未填字的空心方框 □ 与黑色涂抹遮挡块同样按未填处理。不能仅凭单元格非空就认定具有实质内容。填占位词与单元格空白是两种不同问题，须分开陈述。 Kappa 结论属“有条件接受／边界”类（Marginal／临界／Near／Conditional／有条件接受）的，既非合格也非不合格，须整改后复评，按不通过处理，不与“不合格”混记。
- **结论**：3 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 同份报告的两个 %GRR

原文：「结论合格还须底层指标达标，不只看结论栏：%GRR ≤ 10% 判合格；10% < %GRR ≤ 30% 须附客户批准或整改说明方可判合格」

例子：一把卡尺、一个对应计划行和一份同件号同特性的 GR&R，报告名和所判特性均明确，结论“测量系统可以接受”，ndc=6。报告相对总变差为22%，相对公差为8%，无客户批准或整改说明。

- 理解一（用相对公差的 %GRR）：本例取8%，落在≤10%档。（该例判通过）
- 理解二（用相对总变差的 %GRR）：本例取22%，处在需附客户批准或整改说明的区间；两者都无。（该例判不通过）

反例复核：数据、用语、报告份数、匹配和 ndc 都已查明，可排除读错列值。原文指定数值档位，却没有在两项确实同时存在时指定分母。按22%和8%分别落入不同档，结论等义的澄清不解决分母。

**请确认**：一份 GR&R 报告同时列出相对总变差和相对公差的 %GRR，应以哪一列与 10%、30% 比较？

### 3.1. 整套缺计划表：缺陷记在哪一层、报告怎样显示

原文：「文件内或同批次文件集中须有测量系统分析计划表」「同一套件、同一缺陷只记一次，其余子件判通过并写明该缺陷不在本文件归属范围内」「报告型子文件只判该文件自身对应的那一行量具」

例子：同批全集已查清，只有卡尺 GR&R（结论“测量系统可以接受”，%GRR 6%，ndc 9）和目视 Kappa（结论“Acceptable”，总体0.88），两份均可正常阅读，整套确认没有计划表。报告本身指标达标；要说明同一缺表事实的承担层级，及两份报告各自的匹配项。

反例复核：只看到一份不含计划的报告，不能证明整组缺表；本例已查全集，缺表与指标未达标也不相同。“同一缺陷只记一次”未指定缺陷挂在套件还是其中一份。原先“记在其中一份、其余判通过”的做法不是“只记套件、不挂报告”；即使归属选定，仍要明确各报告如何呈现对计划行的匹配。不能提前给 Kappa 报告填通过、逐份不通过或其他结论。

**请确认**：整套缺一张计划表，这一项是只在套件记一次、不挂任何报告，还是应挂到某一份报告（如何指定）？两份报告各自的“与计划行匹配”应显示什么？

### 4.1. Kappa 报告只有评价者分项值

原文：「Kappa < 0.75」「报告同时有总体 Kappa 和各评价者相对标准的 Kappa 时，只核总体 Kappa，单个评价者的分项值不单独否决」

例子：套件有 MSA 计划，目视检验的件号、特性、评价对象和一份 Kappa 报告都匹配，结论“Acceptable”。原报告逐页确认只有甲0.69、乙0.89两个相对标准的 Kappa，没有列总体 Kappa，不是识别失败。

反例复核：若同时列总体0.84和这两个分项，只核总体、低分项只提示，正文已有答案。这里只有分项，前述条件不成立；单写“Kappa < 0.75”未说明此时可否用0.69否决，还是必须先取得总体值。也没有依据自行平均两个数。

**请确认**：报告只有各评价者相对标准的 Kappa、未给总体值时，能否用分项值判断 0.75 门槛，还是要补总体值才能判？

## 已排除的疑似问题（不进入问卷）

- **写“合格”是否还要因非逐字用语否决**：与计划匹配、%GRR 7%、ndc 8 的例子，用语满足；只把 %GRR 改为35%，仍由数据否决，不是都能通过。
- **合格 Cgk 报告是否能代替缺失的 GR&R 报告**：分别检查不同对象；没有应有的研究，不能以 Cg 或 Cgk 的数值充作已提交研究。
- **全套数台数是否与只审本件冲突**：统计基准与最后缺陷归属属于两个作用域。
- **总体与分项同时给出时能否用低分项单独否决**：有明确总体值且同时给出分项时只能核总体，仍需提示分项；不能把这种已定情形再发问。
