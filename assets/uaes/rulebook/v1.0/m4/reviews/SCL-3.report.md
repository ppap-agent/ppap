# SCL:3 条款语义检查报告

- **规则文件**：特殊特性清单：特殊特性三方-一致性（SCL:3）
- **规则原文**：本类目通用口径（规则 1、规则 2、规则 3 均适用） 本类清单常为多件号混装母版：判定前必须先按本件号过滤出行范围，只在过滤范围内统计与判定，跨件号的行不参与判定；依据须写明“按本件号 XX 过滤，参与判定 N 行”。件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在。未按件号过滤而按全表统计的，属未按范围执行，所得结论无效。 特殊特性清单须完整覆盖图纸与 PGQP1 中的全部特殊特性，且同一特性在三处的名称、规格公差、分类符号一致。 覆盖按双向认定：图纸或 PGQP1 中被标为特殊特性的每一项，清单中须有对应行；清单中的每一项特殊特性，也须能在图纸或 PGQP1 中找到对应特殊特性，仅作过程参考、在图纸和 PGQP1 中都不是特殊特性的普通行不参加覆盖比较。单向缺失即不通过，只核“清单有→图纸有”一个方向的属未审。 跨文件一致性先做同号校验（零件号、物料编号归一后相等），再取值比对；不同号属比对源错配，不逐格挑内容错。 三方一致性按“公差值＋特性名”配对，不得按特性编号直接比对——不同文件对同一特性可能各用一套序号，偏移量不固定；配对顺序：公差值归一后精确相等，再特性名剥离序号与类别码后相同，仍多解时按图纸区域或工序位置确认，并在依据中写明配对方式；配对成功而类别符号不同判不通过；配对不上的按缺项判不通过，不得因编号不同就认定“找不到”，也不得反向按编号相同就认定“是同一特性”。符号写法按以下等价写法认定，SC 与 SC/1 分属两级不可互换。跨文件比对特性标识时，下列写法视为同一等级：安全／关键级为 CC、SC/1、1、S、★、安全、关键；重要／主要级为 SC、SC/2、2、D、F、重要、主要、跑道框。裸写 SC 与 SC/1 分属两级、不可互换：带序号的 SC/1 归安全／关键级，裸写的 SC 归重要／主要级。上游写 SC/1、下游简写 1（或上游写 SC/2、下游填对应等级代号），且特性名称与公差完全一致的，按同级处理、仅提示书写格式。客户图纸另用 3、5 作为类别代号，两者均不在上述两级之内，属独立类别——上述等价写法不收录、也不得据此反推其等级；对它们只判“两侧是否一致”，不判其对应哪一级。等级代号 3 与 5 是两个不同类别，不可互换：两侧均写 3 为一致，一侧 3 一侧 5 为标识不一致。并列书写的分隔符不同（半角逗号、全角逗号、空格）视为同一标记，判一致并留痕。代号的确切等级含义文件中未载明时，向客户索取定义并按移交处理；但语义未知不影响“是否一致”的判定——一致性照常二值判，不得以“语义不明”为由改为待裁决。 PGQP1 未随批提交时，以图纸为唯一基准，并在依据中写明缺 PGQP1；图纸亦未提交时，本条记“不适用”并写明依据，不记作通过。缺件计数只在包级报一次，不在本条重复计数。 本条与规则 1、规则 2 分属不同对象：规则 1 判物料字段、表头与签署，规则 2 判四类列与行内必填，本条判特性集合的跨表覆盖，三者同时适用。
- **结论**：2 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 特性只在图纸上、PGQP1 没有时

原文：「同一特性在三处的名称、规格公差、分类符号一致」「清单中的每一项特殊特性，也须能在图纸或 PGQP1 中找到对应特殊特性」「配对不上的按缺项判不通过」

例子：图纸标“孔径 Φ8±0.02 SC”，清单有一行名称、公差、符号完全相同；同批 PGQP1 中没有这一项；其余特殊特性三处都能对上且一致。

- 理解一（出现在哪里就比哪里）：只要清单与图纸对上且一致即可，PGQP1 没有这一项不影响本条。（该例判通过）
- 理解二（三处都要对上）：同一特性必须在三处都能配对，PGQP1 里配不上就按缺项。（该例判不通过）

反例复核：覆盖要求两个方向都用了“图纸或 PGQP1”，例子中清单对图纸的覆盖已经满足；但一致性要求写的是“在三处”一致，又说“配对不上的按缺项判不通过”，没说只在两处出现的特性怎么算。两种理解都保留双向覆盖和符号一致的要求。

**请确认**：某项特殊特性图纸和清单都有且一致，但 PGQP1 里没有这一项，本条判不通过吗？

### G1. 交了 PGQP1 但没交图纸

原文：「PGQP1 未随批提交时，以图纸为唯一基准」「图纸亦未提交时，本条记“不适用”并写明依据，不记作通过」

例子：本批提交了特殊特性清单和 PGQP1，没有提交图纸；清单与 PGQP1 的特殊特性双向都能对上，名称、公差、符号一致。

原文没有明确规定这个例子的判定结论。

反例复核：原文只写了缺 PGQP1（以图纸为基准）和图纸、PGQP1 都缺（记不适用）两种情况，“亦”字说明后一种是两样都没交；只缺图纸的情况没有写。例子中清单与 PGQP1 完全一致，按 PGQP1 判是通过，按缺基准处理则是不适用，原文没有给出结论。

**请确认**：本批交了 PGQP1、没交图纸时，本条以 PGQP1 为唯一基准判定，还是记不适用？

## 已排除的疑似问题（不进入问卷）

- **公差相同但名称不同时算配上还是没配上**：配上了则名称不一致，没配上则按缺项，两种走法都是不通过，结论没有差别。
- **表体没有件号列时怎么过滤**：这是规则 1～3 共用的一段，已在 SCL:2 提出，不重复提问。
