# CP:1 条款语义检查报告

- **规则文件**：控制计划（CP）：生产资源-定义（CP:1）
- **规则原文**：控制计划必须满足以下两种方式之一： 1. 在“机器/装置/夹具/工装”列中逐工序写明对应的生产资源信息；或 2. 表格中设有专门描述生产资源信息的列（生产资源／生产设备／工装设备等），且在该列逐工序写明对应的生产资源信息。 两种方式均不满足则不通过。 第二种方式所指的列，不得是第一种方式已命中的那一列，否则“任一满足”会恒成立。 同一工序占多行时，设备信息填在该工序首行或跨行合并单元格的，视为该工序的所有子行均已继承，只核查每个工序主行是否非空。纯人工目视、手工去毛刺、自然冷却、手工包装等物理上不依赖设备的工序，填“手工”“工作台”“目视工位”或“/”“N/A”均属合规；清洗等确有设备的工序留空，不通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **专列只填一处可否使其他有设备工序也通过**：第二种方式现在明确逐工序填写；例如只填加工中心而清洗工序主行留空，两种方式均没有完整填写时不通过。
- **同工序的空白子行是否也必须单独补填**：首行或合并格已给出的设备信息由该工序子行继承。
- **无设备工序能否因此把主行留空**：允许的是特定填写，不是免填；主行非空要求仍在。
