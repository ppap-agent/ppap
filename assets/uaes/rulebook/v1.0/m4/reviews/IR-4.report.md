# IR:4 条款语义检查报告

- **规则文件**：初始样品检验报告：气泡图-存在性（IR:4）
- **规则原文**：同批次提交的审核文件中，必须存在与当前物料编号、物料名称均一致的气泡图；缺少气泡图即不通过。气泡图的载体可以是独立文件，也可以是下列替代形式。 允许的替代形式：ISIR 内嵌气泡图页（同文件后续工作表或同页图纸标注）且能按件号定位的，视为独立文件已提供并在依据中写明位置；仅有一句“见气泡图”而无图页的，不构成已提供。 气泡图须与 ISIR 双向 100% 对齐：ISIR 中每一个有编号的尺寸项，气泡图上须有同号气泡；气泡图上每一个气泡号，ISIR 中须有对应尺寸项。任一方向存在缺号即不通过，按“气泡图与 ISIR 未闭环”判，并按缺号数记缺陷计数；只核单向的，属未审。 每个气泡号对应项的名义尺寸、上公差、下公差、几何公差（形位公差）与基准，须与图纸对应气泡处完全一致；任一字段不一致即不通过。公差写法不同但数值等价的（±0.1 与 +0.1／-0.1、⌀10 与 10）按一致认定，须在依据中写明归一方式；只有对称公差拆写为非对称且和值相等、但单边限值不同的，不按等价处理。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **可以用特性名称和公差相同的另一号码弥补缺号吗**：不能。比特性标识等级时的通用配对办法并非本条气泡号闭环检查；本条明写双向同号，字段值一致也不能抵掉缺号。
- **允许等价写法是否等于只要求上下公差的总宽相等**：不是。比如 +0.15/-0.05 与 ±0.10 总宽虽同，两个边界不同，原文明确不等价。
