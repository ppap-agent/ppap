# PCE:4 条款语义检查报告

- **规则文件**：过程能力研究：特殊特性目录-覆盖（PCE:4）
- **规则原文**：过程能力分析报告必须包含目录页；同批次必须有同零件号的独立《采购件质量计划》文件且其中包含 PGQP1 表；PGQP1 中全部标记为特殊特性的特性，必须出现在过程能力分析报告目录中。三项全部满足才通过，否则不通过。 同批未提交《采购件质量计划》，或其中无 PGQP1 表时，本条判不通过并标明“整份未交”，不记“不适用”；缺件计数只在包级报一次，不在本条重复计数。 目录页名称不限，“目录”“目次”“CONTENTS”等均算。同批同零件号、确为同一套过程能力分析报告的分册，且各有目录页时，合并各份目录核对是否覆盖 PGQP1 中全部标记为特殊特性的特性，不要求每份目录分别列全。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 特殊特性栏能否标记整栏所列项目

原文：「PGQP1 中全部标记为特殊特性的特性」「合并各份目录核对是否覆盖 PGQP1 中全部标记为特殊特性的特性」

例子：同批同号的独立采购件质量计划含 PGQP1。表中十项规格直接填在“SC/特殊特性”栏下，没有逐行符号，也没有其他特殊特性标记。同套两册都有目录，合计只列了其中八项；其余两项在两册目录都找不到。

- 理解一（栏标题可标记所列项目）：十项均被列在特殊特性栏，缺两项即未全覆盖。（该例判不通过）
- 理解二（各行须有特性标记）：栏标题只是说明此栏的用途，行内规格不是标记；本例没有被单独标记而漏列的特性。（该例判通过）

反例复核：两份有目录的文件确定属于同套，合并后仍缺两项，因此不是在重问能否合并。明确的是“已标记”的对象必须全覆盖，未明确的是标记可由栏标题整体表达，还是必须落实到每一行。两项的资格会改变目录覆盖结论，研究页不是本条另设的门槛。

**请确认**：PGQP1 的“SC/特殊特性”栏中有十项规格，各行没有独立标记。同套分册的目录合起来仍缺其中两项。这两项是否也必须纳入目录？

## 已排除的疑似问题（不进入问卷）

- **同套目录已合计列全时，还必须每册逐一列全吗？**：符合组册前提时明确查目录并集；这没有规定如何识别特殊特性。
