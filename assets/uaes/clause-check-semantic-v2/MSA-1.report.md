# MSA:1 条款语义检查报告

- **规则文件**：测量系统分析评价（UAES 审核规则库 规范性条款 v1.0）：UAES-MSA-计划表必填-校验（MSA:1）
- **规则原文**：适用子件：含测量系统分析计划表的文件——计划表本体，或计划表与报告同簿的套件文件。Kappa／GR&R／Cgk／单量具专项报告不含计划表，本条对它们记“不适用”，不得以“计划表在别的文件里”判其通过。 此处的“不适用”指“本文件没有该判定对象”（本文件不含计划表），不指“判定对象落在别的文件里”。后者不属不适用：本文件自身仍须照常判定，缺陷属别的文件时在本文件判通过并写明归属范围。 “不适用”须写明依据，不占通过／不通过结论位，不计入通过率分母，也不得记作通过。同一套件的计划表存在与否只判一次，不在每份子文件上重复认定；需说明计划表由哪份文件承载时，写入依据附注，不改变本条结论。 文件须包含“测量系统分析计划”或“MSA 计划表”（表名不限，识别特征为同时含“量具名称/测量工具名称”类列头与“测量项目/测量参数/测量特性”类列头的清单表）；计划表中“序号/NO”列须有内容，且每一有效行的五类核心字段均不得为空： 1. 零件号／适用范围（项目名／机种名等同义写法）； 2. 特性名称（测量项目／测量参数）； 3. 测量设备／量具名称； 4. 量具编号／设备代码； 5. 计划分析类型（GR&R／Kappa／Cgk／稳定性／偏倚／线性）。 五类核心字段之外的其余列（资产号、校准周期、责任人、版本、备注等）空白时，只记提示项，不据此判不通过；这些列不承载“定位到哪把量具、判什么、怎么判”的判定语义，按全列非空判属过判。 “计划分析类型”为独立必判项，不得与“量具名称”或“特性名称”合并认定：该字段须明确写出 GR&R、Kappa、Cgk、稳定性、偏倚、线性等分析类型之一；空白、填占位词、或只写“见报告”的，即使其余四类核心字段齐全，本条也判不通过。同义写法按通用判定说明的语义等价认定。 此处“占位词”按通用判定说明的占位词表认定，/、N/A、—、无 均属之；本条不适用后文“不计为空”的宽松口径，填上述任一字样一律按占位处理。 本条同时约束覆盖范围：《控制计划》“测量技术/评价方法”列中涉及的可变数据量具与计数型专用检具，均须在计划表中有对应行；全自动设备的内部工艺监控参数与破坏性化学、金相试验设备不在覆盖范围内，缺其对应行不据此判不通过。 本条的覆盖面与规则 6 的覆盖率分属两侧，同一事实不在两处各记一次：“计划表缺行”落本条（规则 1）；“计划表有该量具行、但无对应报告或报告结论不合格”落规则 6。 全部满足才通过，否则不通过。 “/”“N/A”“—”“无”在第 1～4 项核心字段上视为已声明的不适用标记，不计为空；第 5 项“计划分析类型”不适用此宽松口径，该字段填上述任一字样，按前文“填占位词”判不通过。备注列未写理由的，记提示项，不改变本条结论。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **四个记号是否在五类字段上一律无效**：末段特意区分前四项和第五项：标记的宽免不能延伸到分析类型，反之也不能把第五项禁令扩大到前四项。行字段不算空，不等于已经满足整条的覆盖要求。
- **无计划表的报告和有对象但缺陷在别件，是否都算通过**：不含计划表的专项报告不适用；“其余子件通过”的归属规则只处理别件的缺陷，不能代替适用性识别。
- **能否把模板末尾的空白行算作五项全缺**：条款只查有效行，通用判定说明排除表尾的预留空行。
