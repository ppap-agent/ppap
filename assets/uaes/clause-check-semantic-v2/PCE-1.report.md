# PCE:1 条款语义检查报告

- **规则文件**：过程能力研究（UAES 审核规则库 规范性条款 v1.0）：UAES-PCE-样本量与Cpk-校验（PCE:1）
- **规则原文**：所有工艺能力认证报告须同时满足： 1. “读数次数”或“实测结果”区域的样本数量不少于 125（按有读数的单元格计）； 2. 报告中的 Process Capability（Cpk）值不低于 1.33（即 Cpk ≥ 1.33）。 任何一份报告不满足上述任一条件即不通过。 阈值统一取“不低于（≥）”，不取更严的“必须大于”：实测值恰为 1.33 判达标，不得卡在边界值上判不通过。规则 2、规则 3 与本条同口径，三处不得各设一套。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **样本数恰好125、Cpk恰好1.33是否不过**：两个下限均包含等号。这两个指标恰等于门槛时，不能以“不大于”否决。
- **125个预留格是否就等于125个样本**：只计实际有读数的格。若有125个预留格但只有120个读数，不满足样本量要求。
