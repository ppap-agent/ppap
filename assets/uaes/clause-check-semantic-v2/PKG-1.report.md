# PKG:1 条款语义检查报告

- **规则文件**：包装方案（UAES 审核规则库 规范性条款 v1.0）：UAES-PKG-内容块-完整性（PKG:1）
- **规则原文**：文件内容标题必须包含“包装方案”；文件还必须同时包含“零件基础信息”“供应商基础信息”“包装设计的基本要求”“针对该零件包装的特殊要求”“包装方案信息”“包装材料清单”六个内容块。以上七项全部满足才通过，否则不通过。 标题按“含”判定，不按整字段等值判定。 代表供应商的编制、审核、批准签署栏还须同时具备手写签字与受控印章或公章；纯打印体姓名不构成签字，电子手写签名图层与电子签章图层分别视为签字与印章。客户（UAES）审批栏在供应商提交阶段可以留空，不计缺项。签字与印章任一缺失，或签署栏整栏全空，不通过。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 2. 三栏分别签字后，能否共用一枚公章

原文：「代表供应商的编制、审核、批准签署栏还须同时具备手写签字与受控印章或公章」「签字与印章任一缺失，或签署栏整栏全空，不通过。」

例子：提交阶段的包装方案标题和六个内容块齐全。编制、审核、批准三栏都有本人的手写签字；三栏下方同一供应商签署区印有一个共用的“盖章处”，盖了一枚清晰有效的供应商公章，三个个人签字格内均未单独盖章。

- 理解一（供应商签署区共用章）：各人分别签字，再由供应商在共用位置盖章，即具备签与章。（该例判通过）
- 理解二（各职能栏各需一章）：编制、审核、批准三个栏位都要各自有签有章，共用位置的一章不满足逐栏盖章。（该例判不通过）

反例复核：三人均已签字，不涉及整栏空白、印章真伪、电子载体或客户栏。原文把三栏并列后要求签与章同时具备，但没有说明盖章单位是整组供应商签署还是每一个职能栏。一般版式差异可以注明，但不能由此确定一枚章是否可覆盖三次签署。

**请确认**：编制、审核、批准三人均在各自栏内手签时，供应商在三栏共用的盖章处盖一枚公章是否足够？

## 已排除的疑似问题（不进入问卷）

- **七项内容都齐，能否抵消供应商缺签或缺章**：“才通过”不等于“即通过”；即使七项全有，供应商只有签字没有印章也明确不通过。
- **客户审批栏可空是否也免除供应商签署**：例外只指提交阶段的客户栏，不改变供应商签章要求。
