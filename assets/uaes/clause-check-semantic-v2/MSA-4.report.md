# MSA:4 条款语义检查报告

- **规则文件**：测量系统分析评价（UAES 审核规则库 规范性条款 v1.0）：UAES-MSA-CP人工检测-kappa（MSA:4）
- **规则原文**：同批次必须提交《控制计划》。 若控制计划（CP）存在出货检验／GP12 类工序，且该工序的评价测量技术使用人工、目测等人为检测方法，则同批次必须有相同零件号、相同量具名称（或量具名称为“综合检具”）的 Kappa 独立文件；缺少时不通过。 量具名称按工序级语义匹配认定，不死抠字面：控制计划写“目视”“目测”“Visual”“感官检验”时，同批存在以该对应工序检验人员为分析对象的合格计数型 Kappa 报告即视为已覆盖；报告标题与分析对象名未与工序名逐字一致但能对应到该工序的，判通过并留痕提示，不判不通过。无法确认对应到哪个工序的，才按缺少处理。 若不存在出货检验／GP12 工序，或此类工序不存在人为检测方法，则该项要求判通过，同时输出一条提示项通知用户：本批次未发现出货检验／GP12 工序（或该类工序无人工检测方法）。该情形按客观无检测对象处理，不作缺项，提示项不改变结论、不进任何分母。 本条为本册经裁决保留的显式口径：与通用判定说明“不适用不能记作通过”的一般规定并存，仅本条这样处理——无该工序时不存在可评价的检测方法，属客观无对象而非漏检，故判通过并留痕提示，不按不适用处理。执行时不得反向把“已判通过”写成“不适用”，也不得因输出提示项就把结论改成不通过。 工序名称列缺失属文件结构问题，不等同于“没有出货检验工序”，两者不得混判。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **无人工出货工序是“不适用”还是通过**：此处是点名特例，确认客观无对象后结论为通过，同时向用户提示。缺控制计划或工序名称列都不能当成已确认无工序。
- **结论合格但标题不含“目视”就缺报告吗**：不按标题逐字匹配。需能对应到同件号对应工序的检验人员；能对应只提示，不能对应才按缺少。
