# PFMEA:5 条款语义检查报告

- **规则文件**：潜在过程失效模式及后果分析（PFMEA）（UAES 审核规则库 规范性条款 v1.0）：UAES-PFMEA-PFD工序-覆盖（PFMEA:5）
- **规则原文**：过程流程图（PFD）中的全部主工序，均须在 PFMEA 中被覆盖并开展失效分析。 覆盖按“工序号＋核心工艺语义”归并认定：一个 PFD 工序在 PFMEA 中拆成多个工序行，只要核心工艺语义一致，视为已覆盖；反过来一个 PFMEA 行聚合多个 PFD 工序的，只要逐工序均有对应失效模式，同样视为已覆盖。不得仅因两侧行数不等就判未覆盖。 缺少 PFMEA 与 PFD 的对应关系，或任一 PFD 主工序在 PFMEA 中无对应失效分析，即不通过。同批次未提交过程流程图时，本条记“不适用”并写明依据，不记作通过，也不得因缺 PFD 判本条不通过（缺件计数只在包级报一次）。 本条与过程流程图规则 2 的图形符号判据、控制计划规则 7“PFD 工序须在 CP 中出现”分属不同链路：本条只判 PFD→PFMEA 方向的工序覆盖，不判工序名称逐字一致，也不判特性覆盖（特性覆盖见规则 3、规则 4）。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 2.1. 单独编号的工序间转运是否属主工序

原文：「过程流程图（PFD）中的全部主工序，均须在 PFMEA 中被覆盖并开展失效分析。」「缺少 PFMEA 与 PFD 的对应关系，或任一 PFD 主工序在 PFMEA 中无对应失效分析，即不通过。」

例子：同号 PFD 正常路线列 OP10 车削、OP15 转运到清洗区、OP20 清洗。OP15 有独立工序号和转运符号，不改变产品状态，图中没有“主/辅”标记。PFMEA 对 OP10、OP20 及其余无争议的主工序均有对应分析，没有对转运的分析，也未将之归并进别行。

反例复核：两份文件、路线及编号均清楚，本例不是取证不全。若按正常路线中独立编号的作业计，OP15 漏分析；若辅助物流不属主工序，则不因 OP15 否决。工序号加核心语义解决已纳入工序如何配对，不能先行决定转运是否应纳入，PFD 的图例也不定义主辅。

**请确认**：正常生产路线中独立编号、但只负责转运的工序，是否属于必须单列或归并开展失效分析的主工序？

## 已排除的疑似问题（不进入问卷）

- **缺 PFD 时是否按通用缺件规则直接否决本条**：本条特指记不适用并写依据，与包级缺件计数分开。
- **一行 PFMEA 对三个工序是否必定漏项**：能逐一对应三道工序的失效模式即可，不得仅比较行数。
