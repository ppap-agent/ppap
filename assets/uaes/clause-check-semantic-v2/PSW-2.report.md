# PSW:2 条款语义检查报告

- **规则文件**：零件提交保证书（PSW）（UAES 审核规则库 规范性条款 v1.0）：UAES-PSW-制造信息区-校验（PSW:2）
- **规则原文**：PSW 必须同时满足： 1. 包含“供方制造厂资料”“买方资料”两个区域； 2. “供方制造厂资料”下有“公司名称”字段且有值； 3. “买方资料”下“采购方及部门”“采购方代码”“应用”三个字段均存在且有值； 4. “是否报告了受客户关注的材料信息”字段存在，且对应选项恰好勾选一项； 5. “以 IMDS 或者其它客户格式递交”字段存在且有值。 任一项不满足即不通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
