# PCE:5 条款语义检查报告

- **规则文件**：过程能力研究（UAES 审核规则库 规范性条款 v1.0）：UAES-PCE-过程特性目录-覆盖（PCE:5）
- **规则原文**：过程能力分析报告必须包含目录页；同批次必须有同零件号的独立《采购件质量计划》文件且其中包含 PGQP1 表；PGQP1 中的全部过程特性，必须出现在过程能力分析报告目录中。三项全部满足才通过，否则不通过。 同批未提交《采购件质量计划》，或其中无 PGQP1 表时，本条判不通过并标明“整份未交”，不记“不适用”；缺件计数只在包级报一次，不在本条重复计数。 目录页名称不限，“目录”“目次”“CONTENTS”等均算。 目录中有记录不等于已研究：每一条出现在目录中的过程特性，还须有对应的能力研究页并给出 Cpk 或 Ppk 实测值；目录有记录、报告内无对应研究页或研究页无可读能力值的，按“报告未齐套”判不通过，不得仅凭目录页命中就判通过。 本条判的是“是否实际做了研究”，规则 4 判的是“特殊特性是否在目录中”，两者不得合并：目录覆盖与报告齐套须分别成立，一项通过不能冲抵另一项不通过。定性过程特性（纯目视判定、无数值规格）只要求在目录中有记录，不要求能力研究页，不计入齐套缺项。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **目录三项齐全是否直接证实已做能力研究**：“才通过”并未取消后文明列的研究页要求。若定量过程特性只有目录没有对应研究页，仍判报告未齐套。
- **定性特性免研究页是否也能从目录中删去**：不能。例外仅免研究页，目录记录本身仍是必要条件。
- **普通尺寸的目录能力列可填斜线，是否等于免所有研究页**：合法留空有特定行、列和范围；目录能力列可留空不等于已经提供本条要求的定量过程特性研究页和实测值。

未发现需要客户确认的条款表述问题。
