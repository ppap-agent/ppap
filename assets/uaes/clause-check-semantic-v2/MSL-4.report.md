# MSL:4 条款语义检查报告

- **规则文件**：材料产品及分供清单（UAES 审核规则库 规范性条款 v1.0）：UAES-MSL-PFD-双向溯源（MSL:4）
- **规则原文**：材料产品及分供清单须与过程流程图双向溯源： 1. 过程流程图中的外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）与核心原材料，须在分供清单中有对应记录； 2. 分供清单中的每一项外协工序与原材料，须在过程流程图中有对应节点。 任一方向存在缺失即不通过。对应关系按“工序名称／材料牌号的工程语义”认定，允许简称与别名，不要求逐字一致；分供方名称写法与流程图不同的，不判不通过。 过程流程图中标注为“自制”“厂内”“内制”的工序，不要求出现在分供清单中；分供清单标注“外购”“外协”“委外”的项，必须在流程图中有节点，缺失按“分供项未上流程图”判不通过。 同批次未提交过程流程图时本条记“不适用”并写明依据，不记作通过；缺件计数只在包级报一次。本条与规则 3 分属不同对象：规则 3 判与图纸的零件号、零件名称一致，本条判与过程流程图的双向溯源，两者同时适用。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 4. 什么算流程图中的“核心原材料”

原文：「过程流程图中的外协工序（外协加工、表面处理、热处理、焊接外委、电镀等）与核心原材料，须在分供清单中有对应记录」

例子：同批配对的流程图有注塑树脂和专用于成品颜色的色母粒两个投料项，色母粒牌号已标识且留在成品中，没有核心性标记。清单列有树脂而没有色母粒；其余外协、材料及全部清单行均可双向对应。

- 理解一（留在成品中的配方辅料也算）：色母粒等留在成品中的投料都属核心原材料，须在分供清单中有对应记录。（该例判不通过）
- 理解二（只有主体材料算）：核心原材料只指构成零件主体的材料，配方辅料不要求列入。（该例判通过）

反例复核：这不是仅借用的工具或内制工序。若色母粒纳入“核心”，正向缺记录即失败；若只有主体树脂属于核心，正向不缺，反向也没有未上图的清单行。反向“每一项”不能替正向决定“核心”的范围。

**请确认**：成品中保留、但不是主体材料的配方辅料（例如注塑色母粒）是否属于必须列入分供清单的核心原材料？

## 已排除的疑似问题（不进入问卷）

- **同批未交过程流程图是整条失败或通过吗**：正文明确本条不适用并写依据，包级缺件另计。不能套用其他规则缺图纸即不通过。
- **只有简称或供应商写法不同，能否视为缺节点**：不能用字串差异代替工程语义核对。工程语义能对应时，仅写法不同不构成溯源缺失。
