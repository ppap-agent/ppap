# MSA:5 条款语义检查报告

- **规则文件**：测量系统分析评价（UAES 审核规则库 规范性条款 v1.0）：UAES-MSA-Cgk结论-可接受性（MSA:5）
- **规则原文**：适用子件：含 Cg／Cgk 评定区的测量能力报告（文件名或表头含“Cgk”“能力指数”“Capability Index”）。计划表、Kappa 报告、GR&R 报告不含该评定区，本条对它们记“不适用”，不得记作通过。 “不适用”须写明依据，不占通过／不通过结论位，不计入通过率分母；“本文件无评定区”与“评定区在别的文件里”是两件事，后者不得按不适用处理。 文件内须存在 Cg 与 Cgk 两个能力指数，且位于同一评定区块；两个指数均须 ≥ 1.33。 全部满足才通过，否则不通过。 文件自带“要求：Cg 和 Cgk 1.33”一类要求行时，以该行印的阈值为准；若该阈值与 1.33 不同，登记冲突交客户裁决，不得静默择一。评定区只有一个指数、或指数值只有标签而无实测值（空白、公式未算出）的，不通过。 文件自带“是否合适／判定”栏（是／否、OK／NG）时，该栏与实测值矛盾（栏标“是”而实测低于阈值，或栏标“否”而实测达标）的，以实测值为准并登记冲突，不得因判定栏标“是”就判通过，也不得因判定栏标“否”就不看实测值。 本条只判 Cg／Cgk 的结论可接受性。该结论不得用作“重复性与再现性报告是否存在”“Kappa 报告是否存在”等存在性判定的证据；反之，报告存在也不推出本条通过。 本条为我方补充判据，不取自客户规则原文（客户原文未评价 Cg／Cgk 结论）；1.33 的取值依据为测量系统分析手册第四版，并以文件自带要求行为准。对外表述须注明其为补充判据，不得称为客户条款。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1.1. 一份能力报告有多个评定区块时查哪些

原文：「文件内须存在 Cg 与 Cgk 两个能力指数，且位于同一评定区块；两个指数均须 ≥ 1.33。」「全部满足才通过，否则不通过。」

例子：同一文件中分别列出量具甲与量具乙的独立评定区，均为本次零件的测量能力报告。两个区的要求行都是 1.33，甲的 Cg/Cgk 为 1.48/1.42，乙为 1.40/1.20；无自报结论冲突。

反例复核：两个评定区的指数各自在本区内配对，不存在跨区取值、报告不适用或阈值争议。正文用‘文件内须存在’描述同一区块的一对指数，却未规定报告含多组时是存在一组即可，还是所有被提交的区块逐组判；两种范围分别会得出通过或不通过。

**请确认**：同一份报告有两组不同量具的完整 Cg/Cgk 评定，一组达标一组不达标；本条要查所有评定区块，还是一个区块中有一对达标即可？

## 已排除的疑似问题（不进入问卷）

- **模板阈值与 1.33 不同是否需要再问一套通用顺序**：正文已经规定登记差异交客户裁决；应处理实际文件，不再把这条转送程序当作规则没有结论。
- **合格勾选与实测不一致是不是条款自相矛盾**：这是文件里两个证据矛盾，条款给了取值顺序；按实测值判并登记。
- **两个指数恰为 1.33 算不算达标**：一般阈值用的是≥而非>；没有不同的文件阈值时，两个指数均为1.33即满足这一数值要求。
