# CP:1 条款语义检查报告

- **规则文件**：控制计划（CP）（UAES 审核规则库 规范性条款 v1.0）：UAES-CP-生产资源-定义（CP:1）
- **规则原文**：控制计划必须满足以下两种方式之一： 1. 在“机器/装置/夹具/工装”列中逐工序写明对应的生产资源信息；或 2. 表格中设有专门描述生产资源信息的列（生产资源／生产设备／工装设备等），且该列下有内容。 两种方式均不满足则不通过。 第二种方式所指的列，不得是第一种方式已命中的那一列，否则“任一满足”会恒成立。（本句为编译侧为防止“任一满足”恒真所加的限定，非客户原文。） 同一工序占多行时，设备信息填在该工序首行或跨行合并单元格的，视为该工序的所有子行均已继承，只核查每个工序主行是否非空。纯人工目视、手工去毛刺、自然冷却、手工包装等物理上不依赖设备的工序，填“手工”“工作台”“目视工位”或“/”“N/A”均属合规；清洗等确有设备的工序留空，不通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **另设设备列只填一行，能否盖过其他有设备工序漏填？**：不能。例如设备列写了车床，另一清洗工序主行无值且无继承，末句已判不通过。
