# PSW:3 条款语义检查报告

- **规则文件**：零件提交保证书（PSW）（UAES 审核规则库 规范性条款 v1.0）：UAES-PSW-签字盖章-校验（PSW:3）
- **规则原文**：零件提交保证书必须包含“供方代表签字”字段；该字段必须有手写签名，且文件中还必须有印章。三项全部满足才通过，否则不通过。 签署区还须填写打印姓名/职务（Title）、电话号码、电子邮箱与签署日期，任一项缺失或格式明显不合法的按联系信息不完整判。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 2. 合并栏里的姓名和职务是否都要写

原文：「打印姓名/职务（Title）、电话号码、电子邮箱与签署日期」「任一项缺失或格式明显不合法的按联系信息不完整判」

例子：供方代表签字栏有本人手写签名，文件有印章，电话、邮箱和签署日期均完整有效。模板只有一个“打印姓名/职务（Title）”栏，其中写了“质量经理”，没有打印姓名。

- 理解一（两种资料都要写）：即使模板把两项合在一格，打印姓名和职务也都须出现；仅写职务缺姓名。（该例判不通过）
- 理解二（合并栏允许二选一）：把逗号前的合并栏视为一项，打印姓名或职务有其一即可；本例已写职务。（该例判通过）

反例复核：签名与联系信息是两项独立要求，不能用手签代替应打印的姓名。疑点在更前一步：斜线将两个不同的信息放在同一处列举，“任一项缺失”并未交代它们是各占一项，还是一项中可选其一。其他栏目均已满足。

**请确认**：模板只有一格“打印姓名/职务（Title）”，仅填职务、不填打印姓名，这一格算完整吗？

## 已排除的疑似问题（不进入问卷）

- **签字栏、手签和印章齐全，但无电话，是否既要通过又要不通过**：“才”列的是必要条件，不是充分条件。联系信息要求仍独立适用；明确缺电话就不能通过。
