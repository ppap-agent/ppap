# SCL:2 条款语义检查报告

- **规则文件**：特殊特性清单（UAES 审核规则库 规范性条款 v1.0）：UAES-SCL-必填列-校验（SCL:2）
- **规则原文**：本类目通用口径（规则 1、规则 2、规则 3 均适用；源自本类目卡片执行前言“三·补 混装母版须先按件号过滤”，2026-11-20 第 38 轮 P2-2） 本类清单常为多件号混装母版：判定前必须先按本件号过滤出行范围，只在过滤范围内统计与判定，跨件号的行不参与判定；依据须写明“按本件号 XX 过滤，参与判定 N 行”。件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在。未按件号过滤而按全表统计的，属未按范围执行，所得结论无效。 特殊特性清单必须包含“编号/序号”“产品特性/过程特性/特殊特性名称”“特性及公差/特性值”“特性类型/特性类别”四类列；每一条“编号/序号”有值的记录中，同行其余三类列的内容也必须非空。 缺少任何必需列或任何应填内容即不通过。四类列内部允许同义别名（如“特性名称”≒“产品特性”、“规格/公差”≒“特性及公差”、“分类”≒“特性类别”），按行判定，禁止跨行拼配。 仅作过程参考的普通行（普通工艺温度、普通非关键尺寸）不属管控对象，其“特性类型/特性类别”列留空或填“/”，按通用判定说明·实质内容的第 1 处豁免处理，不判缺项；此类行仍须有“编号/序号”与特性名称、特性及公差。属管控项（特殊特性清单或控制计划中的特殊特性）的行，三类列仍不得为空。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
