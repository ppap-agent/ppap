# CP:2 条款语义检查报告

- **规则文件**：控制计划（CP）（UAES 审核规则库 规范性条款 v1.0）：UAES-CP-追溯与先进先出-完整性（CP:2）
- **规则原文**：控制计划中的零件生产过程应满足追溯性要求，同时满足过程先进先出要求。 追溯性：“产品/过程规格/公差”列中，进料、出入库、出货三类环节的对应行均须写明追溯标识方式（批次号／炉号／序列号／流转卡等），三段串成闭合追溯链。 先进先出：出入库、仓储、领用、发运类环节的行，须写明先进先出（FIFO）或等效的批次先后取用要求。 本节所称“发运”即追溯性一段所称“出货”，两者指同一环节，不因用词不同判缺项；“出入库”在两段中同义。一段用另一个词命名的行，不构成“该环节缺失”。 两项同时满足才通过。“库龄不超过 N 天”“库存天数”“保质期”“周转率”等时限或效率类要求不算先进先出；只写“可追溯”“按批次管理”而无具体标识载体的，不构成闭合追溯链。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
