# MSL:2 条款语义检查报告

- **规则文件**：材料产品及分供清单（UAES 审核规则库 规范性条款 v1.0）：UAES-MSL-三方签字-校验（MSL:2）
- **规则原文**：材料产品及分供清单的签署分两层判定，两层不得混为一谈。 第一层·必签三方（决定结论）：“供应商负责工程师”“UAES NE 工程师”“UAES SQD/SQE 工程师”三方均须签字；任一方未签字即不通过。UAES 终签按业务阶段尚未完成的，同按客观缺失判不通过并提示补签，不以“待会签”放行。 第二层·附加签署栏（按模板设置判定）：供应商侧的编制、审核、批准三栏，与 UAES 侧的项目采购会签栏——模板设该栏位的，须有手写签字，供应商侧还须加盖印章；设栏而空白、或只有签字而无印章的，按“签署不闭环”判不通过。模板未设该栏位的，不计缺项，也不得因缺该栏反推“三方签字不全”。 两层不重复计数：同一签署栏的空白只记一次，落“签署不闭环”，不再另记“三方签字缺失”。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 3. 供应商三栏是否各自需要印章

原文：「模板设该栏位的，须有手写签字，供应商侧还须加盖印章」「设栏而空白、或只有签字而无印章的，按“签署不闭环”判不通过。」

例子：必签三方均已签妥；另设的编制、审核、批准三栏和 UAES 项目采购会签栏均有手写签字。供应商公章清楚地盖在批准栏内，未跨入另两栏；表上没有专用盖章栏或盖章位置说明。

- 理解一（供应商侧合计一枚）：三栏均手签，供应商侧已有公章，盖章义务已履行。（该例判通过）
- 理解二（供应商侧逐栏盖章）：编制、审核两栏均只有签字没有盖章，不能认定这两栏闭环。（该例判不通过）

反例复核：没有缺签，没有要求 UAES 盖章，也不是印迹无法辨识。条款逐栏要求手签，但“供应商侧”可以指整组；紧接着的“只有签字而无印章”也可能延续逐栏检查。两种单位会改变同一份实物的结论。

**请确认**：编制、审核、批准三栏都已手签，只有批准栏盖了供应商公章，这一组签署是否闭环？

## 已排除的疑似问题（不进入问卷）

- **模板没有附加会签栏，是否连固定三方也可不签**：不能。未设栏的例外仅指第二层，固定三方任一未签仍不通过；流程尚未结束也不能放行。
- **UAES 项目采购只有手签没有盖章，是否也因缺章失败**：加盖印章限定在供应商侧；不能把随后“只有签字而无印章”的表述扩大到UAES侧。
