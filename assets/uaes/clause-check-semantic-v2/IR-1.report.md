# IR:1 条款语义检查报告

- **规则文件**：初始样品检验报告（UAES 审核规则库 规范性条款 v1.0）：UAES-IR-尺寸报告-列数校验（IR:1）
- **规则原文**：文件中必须存在尺寸报告，且尺寸报告中“实测值”的列数必须为 3 或 3 的倍数。列数按“有读数（非空）的列”计。 缺少尺寸报告或实测值列数不符合要求即不通过。 定量尺寸的任一实测值超出“名义值与上下公差”构成的区间，且同批次无覆盖该项的顾客工程批准/偏差许可的，无论单项结论写 OK 还是 NG，均按超差判不通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。
