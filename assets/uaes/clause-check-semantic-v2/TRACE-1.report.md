# TRACE:1 条款语义检查报告

- **规则文件**：零件追溯说明（UAES 审核规则库 规范性条款 v1.0）：UAES-TRACE-区域内容-完整性（TRACE:1）
- **规则原文**：文件必须包含“供应商零件追溯”表；该表内“基本信息”“分供方追溯”“生产过程追溯”“交付追溯”“追溯状态总结”五个区域必须分别存在实质内容。表存在且五个区域均有内容才通过；缺少表或任一区域没有内容即不通过。 “实质内容”按占位词规则判：区域标题格、列头格、纯空白的合并格不计；区域内实质内容格数为 0 的，与“有内容但仍有整行/整列空洞”的，分属两种不同情形，不得合并陈述，结论也不同：前者按“区域整块缺失”判不通过（致命），后者按“局部空洞”判不通过（主要）；两者分别计数、分别表述，不合并为一条缺陷。 文件代表供应商的签署栏还须同时具备手写签字与供应商有效印章，缺一即不通过。
- **结论**：0 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 已排除的疑似问题（不进入问卷）

- **五个区有内容能否抵消缺签章或整列空洞**：“才”说明必要而非充分；五区即使均有实质内容，仍要查整行/整列空洞及供应商签章。缺章单独导致不通过。
- **二者都是不通过是否构成矛盾**：通过与否相同，严重度、缺陷表述和计数有区别；不存在同一事实既通过又不通过。
- **有真实的质量专用章但未能证明其签署权限，是否必然需要客户重定章种**：章属该供应商和该章是否有权签本文件是两件事。用途证据不足时应核实权限，不能据此声称原文规定了两种结论；若已证实该章对本次签署有效，也没有依据再加一条“必须是公章”。

未发现需要客户确认的条款表述问题。
