# PCE:2 条款语义检查报告

- **规则文件**：过程能力研究（UAES 审核规则库 规范性条款 v1.0）：UAES-PCE-Ppk-校验（PCE:2）
- **规则原文**：所有工艺能力认证报告中的 Performance index（Ppk）值必须不低于 1.67（即 Ppk ≥ 1.67）；任一报告不满足即不通过。 样本量按规则 1 的 125 件口径判定，本条不另设一套计数；单值移动极差法的样本数以规定样本数为准。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 3. 单值移动极差法所指的规定样本数

原文：「样本量按规则 1 的 125 件口径判定，本条不另设一套计数；单值移动极差法的样本数以规定样本数为准。」

例子：同批仅一份认证报告，明确采用单值移动极差法。该报告方法栏载明规定样本数150，按规则1的方式核得130个有读数单元格，Cpk为1.50，Ppk为1.80。两个读法使用的都是同一批130个读数。

- 理解一（沿用统一125件下限）：“规定样本数”回指已引用的125件，本条证实有130个读数且Ppk达标。（该例判通过）
- 理解二（遵守该方法载明的规定数）：计数方式不变，但单值移动极差法的目标数量依方法栏规定为150；实际130不足。（该例判不通过）

反例复核：130已经达到规则1的125下限，Ppk也满足；分歧不在如何计数。第一分句将样本量指向统一的125件，第二分句又单点该方法的规定数，却未说指前述125还是本方法另载的规定数。例中150是该份文件的实际记载，不是另订统一阈值。

**请确认**：单值移动极差报告在“规定样本数”中载明150，但实际有130个读数，是否满足本条的样本量要求？

## 已排除的疑似问题（不进入问卷）

- **Ppk恰为1.67是否还得更高**：下限明示含等号；不因恰等门槛判低于目标。
- **可否因计算Ppk而把空格也算样本再数一次**：本条复用规则1的有读数单元格计数，不另列计数单位；这不回答单值移动极差法的规定数指哪一个数。
