# MSPEC:1 条款语义检查报告

- **规则文件**：材料规范（UAES 审核规则库 规范性条款 v1.0）：UAES-MSPEC-受控章-存在性（MSPEC:1）
- **规则原文**：材料规范文件中必须包含受控章；没有受控章即不通过。存在疑似印章图形但章内文字或受控标识无法辨认的，按不通过处理并提示人工复核。 文件所载材料牌号/标准号须与同批次图纸及 ISIR 材料报告中记载的牌号一致；不一致的按不通过判。 同批未提交图纸、或缺 ISIR 材料报告时，以已提交的一方为基准比对，并在依据中写明取值来源；两者均缺时，本条“牌号一致”一项记“不适用”并写明依据，不记作通过。受控章一项不受此影响，仍照常判定。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 牌号文字相同而执行标准不同

原文：「文件所载材料牌号/标准号须与同批次图纸及 ISIR 材料报告中记载的牌号一致；」「不一致的按不通过判。」

例子：同批同件号的三份文件牌号栏都写 M7。材料规范有清晰受控章，列执行标准 Q-A；图纸和 ISIR 均列执行标准 Q-B。包内资料明确 Q-A、Q-B 是两个不同标准，不是格式差异，两标准各自设有代号 M7。

- 理解一（只比牌号文字）：三份文件的牌号文字相同即一致，不比执行标准。（该例判通过）
- 理解二（执行标准也要一致）：牌号须在同一执行标准下才算同一材料，标准号不同即不一致。（该例判不通过）

反例复核：三处牌号文字相同，标准号确实不同，既非取证缺失也非文件错配。若只核对对端明写的“牌号”字段，三处相同；若须以标准号限定牌号，或标准号也必须单独一致，则这批不符。原文点出标准号却只点明对端牌号，通用跨文件规则未界定这两种材料标识的比较范围。

**请确认**：三份文件的牌号文字相同、执行标准不同，按牌号文字认定一致，还是须同时核对标准号？

## 已排除的疑似问题（不进入问卷）

- **图纸和材料报告都缺，是否不用查印章**：无需比牌号不等于整条不适用；受控章单独审，没有或不可辨仍按对应要求处理。
- **确认没有受控章与章印模糊是否可用同样的依据**：两者结论虽均不通过，模糊情形还须指出不可辨并提示人工复核，而不能声称无章。
