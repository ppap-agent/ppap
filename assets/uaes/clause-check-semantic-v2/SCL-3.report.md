# SCL:3 条款语义检查报告

- **规则文件**：特殊特性清单（UAES 审核规则库 规范性条款 v1.0）：UAES-SCL-特殊特性三方-一致性（SCL:3）
- **规则原文**：本类目通用口径（规则 1、规则 2、规则 3 均适用；源自本类目卡片执行前言“三·补 混装母版须先按件号过滤”，2026-11-20 第 38 轮 P2-2） 本类清单常为多件号混装母版：判定前必须先按本件号过滤出行范围，只在过滤范围内统计与判定，跨件号的行不参与判定；依据须写明“按本件号 XX 过滤，参与判定 N 行”。件号列可以是“零件号”“Part No.”或“Code”，有其一即视为件号列存在。未按件号过滤而按全表统计的，属未按范围执行，所得结论无效。 特殊特性清单须完整覆盖图纸与 PGQP1 中的全部特殊特性，且同一特性在三处的名称、规格公差、分类符号一致。 覆盖按双向认定：图纸或 PGQP1 中被标为特殊特性的每一项，清单中须有对应行；清单中的每一行，也须能在图纸或 PGQP1 中找到对应特殊特性。单向缺失即不通过，只核“清单有→图纸有”一个方向的属未审。 三方一致性按“公差值＋特性名”配对（配对方式见通用判定说明·跨文件比对），配对成功而类别符号不同判不通过；配对不上的按缺项判不通过。符号写法按通用判定说明的等价表认定，SC 与 SC/1 分属两级不可互换。 PGQP1 未随批提交时，以图纸为唯一基准，并在依据中写明缺 PGQP1；图纸亦未提交时，本条记“不适用”并写明依据，不记作通过。缺件计数只在包级报一次，不在本条重复计数。 本条与规则 1、规则 2 分属不同对象：规则 1 判物料字段、表头与签署，规则 2 判四类列与行内必填，本条判特性集合的跨表覆盖，三者同时适用。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 2. 明确标为普通参考的行是否还要反查为特殊特性

原文：「特殊特性清单须完整覆盖图纸与 PGQP1 中的全部特殊特性，且同一特性在三处的名称、规格公差、分类符号一致。」「清单中的每一行，也须能在图纸或 PGQP1 中找到对应特殊特性。」「本条与规则 1、规则 2 分属不同对象：规则 1 判物料字段、表头与签署，规则 2 判四类列与行内必填，本条判特性集合的跨表覆盖，三者同时适用。」

例子：本件号筛出两行：孔径 10±0.1（SC）和清洗水温 40±2℃（标明“普通、仅作过程参考”，类别填“/”）。已提交同号图纸、PGQP1 和控制计划。三份均未将水温列为特殊特性；孔径在三方同名、同公差、同级，且没有其他特殊特性。

- 理解一（反查所有本件行）：普通水温行也必须反查成上游特殊特性；没有就失败。（该例判不通过）
- 理解二（仅反查其中的特殊特性）：核查集合只含特殊特性；孔径两向均合，普通水温不参加覆盖比较。（该例判通过）

反例复核：通用说明准许普通参考行类别填“/”，只解决格值，不直接给本条的覆盖结论。若反查范围是本件清单的每一行，水温找不到上游特殊特性；若范围是本条开头限定的特殊特性集合，则水温在范围外。已双向核完，争点不是件号筛选或漏查。

**请确认**：本件号下仅作过程参考的普通行，在图纸和 PGQP1 都不是特殊特性，是否会导致规则 3 不通过？

## 已排除的疑似问题（不进入问卷）

- **缺 PGQP1 是否无条件否决**：本条是四种处理中的图纸回退路径；若图纸亦缺才记不适用。
- **特殊特性只在一份上游文件标为特殊是否必须从清单删掉**：上游到清单明写“或”，任一来源已标即须覆盖；也不能只检查反向。
