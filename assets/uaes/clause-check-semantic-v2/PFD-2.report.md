# PFD:2 条款语义检查报告

- **规则文件**：过程流程图（PFD）（UAES 审核规则库 规范性条款 v1.0）：UAES-PFD-图形符号-规范性（PFD:2）
- **规则原文**：过程流程图必须同时满足： 1. 工序活动以标准化图形符号表达，不能仅用纯文字框或文字列表； 2. 图内有图例，且图例覆盖所有已使用的符号； 3. 同一活动类型在全图使用同一符号； 4. 进货、过程、最终、巡检、自检等检验类活动以检验符号表达。 任一项不满足即不通过。 每一个有效工序行都须标注其过程分类符号，图形勾选、连线与代码列三种形式均可。使用了图例未定义的符号，或有工序行漏标，按不通过判。 图形无法辨识的，须先完成视觉层取证（图形解析或目视识读）并写明取证方式，仍不可辨的记“未审”，不判不通过。此为第 39 轮修订后的现行口径：卡片该项标准的字面为“图中无法识别则不通过”，该轮已把“图形符号无法辨识”整类情形移出失败形态、改记未审并提示人工复核，本条按修订后口径执行，判定依据仍须提示人工复核。该例外已回填通用判定说明·无法辨识的小节，两处须同源。全图检索不到任何检验类活动的，属“是否应设检验工序”的工程有效性判断，移交客户裁定，不判不通过。 集成式测试工位（气密测试、测漏、在线打标、视觉防错）以加工符号或加工兼检验的复合符号表达，不视为“未用检验符号”：只要该工序在过程流程图、PFMEA、控制计划三表中工序号与工序名称完全对应，且控制计划已配测试参数与控制方法，即判通过；该工位归加工还是检验本身有歧义的，留痕并建议客户书面确认，不据此判不通过。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1.1. 供应商自己的受控图形体系算不算标准化

原文：「工序活动以标准化图形符号表达」「图内有图例，且图例覆盖所有已使用的符号」「同一活动类型在全图使用同一符号」

例子：同一张图按供应商随件的受控制图标准，用空心月牙表示搬运。所有搬运均标月牙；各道检验均用已定义的检验符号，其余工序均用通行图形。所有行都有标注，图例逐类说明且图形清晰。月牙只见于该供应商标准。

反例复核：不是纯文字、不是临场自创画法或漏标，图例覆盖和同类一致也都成立。若企业的正式图形标准可以作为依据，整条通过；若须采用客户或行业认可的标准符号，搬运图形不符合，整条不通过。条款另列了图例与一致性，却未给出“标准化”承认哪一层标准，通用说明也没有指定符号表。

**请确认**：符号已按供应商正式发布的制图标准统一使用、也有完整图例，但有一个并非行业通行图形，这样是否满足“标准化”？

## 已排除的疑似问题（不进入问卷）

- **一处集成测试符合条件，能否冲掉另一工序漏标**：局部通过仅针对该测试工位的符号类别。即使三表及控制方法齐全，另一有效行漏标或图例缺已用符号仍判整条不通过。
- **没有检验活动是否等于整图其余符号不用查**：交客户裁定的是是否应设检验工序。别行漏标等已证实缺陷照判；规则4的控制节点仍要另查。
- **旧卡片与现行条文是否冲突**：原文已明示修订优先且通用说明同源。完成视觉取证仍不可辨时记未审并提示复核；可辨且确定缺符号则是另一事实。
