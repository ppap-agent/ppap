# MSA:3 条款语义检查报告

- **规则文件**：测量系统分析评价（UAES 审核规则库 规范性条款 v1.0）：UAES-MSA-PGQP1项-落实（MSA:3）
- **规则原文**：同批次必须提交包含 PGQP1 表的《采购件质量计划》文件。对于 PGQP1 重要特性中使用通止规、塞规、塞尺等计数型量具的项目，须有同批次提交、与零件号匹配、且载明覆盖该量具所判特性的 Kappa 独立文件（以评价者为对象，不比量具编号）；有此类量具而缺少对应 Kappa 文件时不通过。 非计数型测量设备项（卡尺、千分尺、高度规等）不在本条判定对象内，本条不因其不产生缺陷；此类量具的报告覆盖与结论由规则 6 判定，不得在本条重复计入。测量设备写法模糊、无法判定是否属计数型的，移交工程裁定。 同批未提供独立的测量系统分析文件时，本条不因缺该文件判不通过，仅以本文件内已有内容判定（该对端为提示性依赖，不是本条的通过必要条件）。反之，《采购件质量计划》或其中的 PGQP1 表未随批提交时本条判不通过，缺件计数只在包级报一次。
- **结论**：1 处候选问题；结构与原文引用已校验，语义仍须人工审阅。

## 逐条发现

### 1. 同簿 Kappa 与“独立测量系统分析文件”免缺件的边界

原文：「须有同批次提交、与零件号匹配、且载明覆盖该量具所判特性的 Kappa 独立文件」「同批未提供独立的测量系统分析文件时，本条不因缺该文件判不通过，仅以本文件内已有内容判定」

例子：本批用一份合并工作簿交采购件质量计划、PGQP1 及测量分析内容。PGQP1 中 P20 重要特性“孔径”使用塞规；同簿另页完整载明 P20、孔径、塞规和评价者的 Kappa 研究，结论合格。批内没有独立的测量系统分析文件，也没有单列的 Kappa 文件。

- 理解一（仍须有独立的 Kappa 文件）：末段的例外只指一般的测量系统分析文件；计数型项目的 Kappa 必须是独立文件，同簿另页不算。（该例判不通过）
- 理解二（同簿内的 Kappa 研究可以）：批内没有独立分析文件时，以本文件内已有内容判定，同簿另页的完整 Kappa 研究算已覆盖。（该例判通过）

反例复核：首段及规则6都强调计数型项目的独立 Kappa；一般版式宽免不能自行取消这个要求。但末段又在缺独立分析文件时要求只看本件已有内容，未说明此处的提示性对端是否包含 Kappa。若仅免一般分析对端，仍因缺独立 Kappa 失败；若末段涵盖此情形，则同簿已有对应研究。不涉及非计数型项目或缺 PGQP1。

**请确认**：计数型项目的 Kappa 研究完整但只在当前工作簿内，批内没有独立分析文件时，末段的例外是否包含这份 Kappa？

## 已排除的疑似问题（不进入问卷）

- **一个 Kappa 文件能否因量具编号不同而被判缺失**：不能以编号为匹配条件；需确认同批、同件号且覆盖所判特性，并以评价者为对象。
- **缺 PGQP1 能否援引规则6回退**：不能；本条把 PGQP1 列为必交，缺件时保留本条不通过，包级只记一次。
