## 1. 目的与边界

**题目与本分则的关系**：本类目的判定对象是**年度试验要求表的结构与取值口径**——试验项目有没有列、频率写没写、写法是否符合理想的两档口径、样本量有没有给出数字、供应商名称与车型是否填了。

**不是**判定试验方案是否充分。试验项目该不该包含某一项、标准引的是不是最新版，全部是正式审核的工程结论。

**边界三条**：

1. 本类目**不判实测值**、不判试验结果，故不产生 `B06`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅理想一家），客户差异层为预留位。

## 4. 判定项（7 项）

> 判据文本以 `00-A §2.2` 为准，本节只把它落成可执行判定。

| # | 判定内容 | 判定方式 | 不满足时 | 来源条款 |
| --- | --- | --- | --- | --- |
| S1 | 含字段「质量等级」，取值 ∈ {关键件、重要件、一般件} | 字段匹配 + 取值集合 | 缺 → **`B05`**；越界 → `W03` | 1 |
| S2 | 「试验项目」为 **ELV 试验 / 禁限用 / EMC 试验** 时，「测试频率」= **每两年** | 逐行条件判定 | 不符 → `W03`（写法 / 取值口径） | 2 |
| S3 | 其他试验项目时，「测试频率」∈ {每年, 每半年} | 逐行条件判定 | 不符 → `W03` | 2 |
| S4 | 供应商名称必填，格式为「供应商代码-供应商全称」（如 `3DA-宁波均胜汽车安全系统有限公司`） | 字段匹配 + 格式正则 | 缺 / 空 → `W02`；格式不符 → `W03` | 3 |
| S5 | 含列「样本数量」，内容含阿拉伯数字（如 `3`、`3pcs`、`3件/次`） | 列匹配 + 数字正则 | 缺列 → **`B05`**；无数字 → `W03` | 4 |
| S6 | 「试验要求栏」含三列：试验项目、试验要求、试验标准/方法，且均非空 | 三列匹配 + 非空 | 缺 → **`B05`**；空 → `W02` | 5 |
| S7 | 含字段「车型」且非空 | 字段匹配 + 非空 | 缺 → **`B05`**；空 → `W02` | 6 |

**S2 / S3 为何只判 `W03`**：试验频率是**取值口径**问题——写错频率意味着这份试验要求的具体条款与理想口径不符，但表结构完整、内容可读、规则可定位。这属「写法不规范 / 取值越界」，由供应商改正后重提，不构成「无法审核」。真正不可审的是 S5（无样本量列）与 S6（试验要求栏缺列）——那时规则连「试验什么」都无法定位。

**S2 与 S3 是互斥分支**：同一行只能落入其中一个。判定顺序为先判 S2 的试验项目集合，命中则按 S2 判，否则按 S3 判。

## 5. 判定细则

**5.1 字段与列名近义通过**

| 应有项 | 可接受的写法（示例，非穷举） |
| --- | --- |
| 质量等级 | 零件质量等级 / 质量级别 / 等级 |
| 试验项目 | 试验项 / 试验名称 / 检测项目 |
| 测试频率 | 试验频率 / 频次 / 周期 / 试验周期 |
| 供应商名称 | 供方名称 / 供应商 / 制造商 |
| 样本数量 | 样本量 / 样品数量 / 抽样数量 / 样本数 |
| 试验要求 | 要求 / 技术要求 / 试验要求栏 |
| 试验标准/方法 | 试验标准 / 试验方法 / 标准或方法 / 依据标准 |
| 车型 | 项目车型 / 车型代号 / 适用车型 |

近义**只用于确认存在**。取值另按 S1~S4 判定。

**5.2 S1 质量等级取值集合**

| 取值 | 判定 |
| --- | --- |
| `关键件` | 通过 |
| `重要件` | 通过 |
| `一般件` | 通过 |
| `关键` / `重要` / `一般` | `W03`（越界，须写全「件」字，按模板口径） |
| `A` / `B` / `C` | `W03` |
| 空 | `W02`（缺值优先于越界） |

**5.3 S2 / S3 的频率口径**

**S2 适用的试验项目**（判定为集合成员即按 S2 判）：

| 试验项目（含近义） | 要求频率 |
| --- | --- |
| ELV 试验 / ELV / 报废车辆指令试验 | **每两年** |
| 禁限用 / 禁限用物质 / RoHS / REACH | **每两年** |
| EMC 试验 / EMC / 电磁兼容 | **每两年** |

**S3 适用的试验项目**：除上述三类之外的**全部**其它试验项目（如盐雾、振动、耐久、材料性能、尺寸全检等）。

| 频率取值 | S2 行 | S3 行 |
| --- | --- | --- |
| `每两年` | 通过 | `W03`（非 S2 项目却写了两年） |
| `每年` | `W03` | 通过 |
| `每半年` | `W03` | 通过 |
| `每季度` / `每月` | `W03` | `W03` |
| 空 | `W03` | `W03` |

**频率为空记 `W03` 而非 `W02`**：本类目的判据原文是「测试频率 = 某个值」，空值同样构成「不等于该值」，故落在取值口径项里，记 `W03`。

**5.4 S5「含阿拉伯数字」的判定**

| 取值 | 判定 |
| --- | --- |
| `3` | 通过 |
| `3pcs` / `3 pcs` / `3件` / `3件/次` / `3 sets` | 通过 |
| `5×3` / `3~5` | 通过（含数字即通过） |
| `三件` / `三个` | `W03`（无阿拉伯数字，须改为数字写法） |
| `见试验标准` / `按标准` / `-` | `W03` |
| 空 | `W02` |

**只判「有没有阿拉伯数字」，不判数量是否够**——样本量是否充分属 `S03`。

**5.5 S4 供应商名称格式**

格式为「**供应商代码-供应商全称**」，分隔符可为 `-`、`－`（全角）、`—`。

| 取值 | 判定 |
| --- | --- |
| `3DA-宁波均胜汽车安全系统有限公司` | 通过 |
| `3DA－宁波均胜汽车安全系统有限公司` | 通过（全角分隔符） |
| `3DA - 宁波均胜汽车安全系统有限公司` | 通过（含空格） |
| `宁波均胜汽车安全系统有限公司` | `W03`（缺代码） |
| `3DA` | `W03`（缺全称） |
| `3DA宁波均胜` | `W03`（无分隔符） |
| 空 | `W02` |

**代码与全称是否真实对应，不判**——属 `S03`（预检不掌握供应商主数据）。

**5.6 S6 三列非空的行范围**

1. 行范围 = 「试验项目」列有非空值的**全部行**。
2. 三条列（试验项目 / 试验要求 / 试验标准或方法）任一为空即记 `W02`，**一行只记一次**。
3. 「试验项目」为空的行跳过，不判——空行不是缺陷。
4. 剔除标题行、小计行、合计行：整行仅 1~2 个单元格有值且首列含「合计」「小计」「说明」等字样。

**5.7 客户差异层为空时的兜底**

本期 `T16` 只有理想一条路由。若将来出现其它客户的年度试验要求规则（例如不同客户的频率口径不同），**不得**套用本分则的 7 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。**频率口径是客户专属的，绝不可跨客户套用。**

## 6. 执行流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（理想, 零部件年度试验要求），置信度 ≥ 中 | 路由 = `L16` / L2 |
| 2 | 定位字段与三列（§5.1），判 S1、S4、S6、S7 | `B05` / `W02` / `W03` |
| 3 | 判 S5 样本数量列（存在性 → 数字判定） | `B05` / `W03` |
| 4 | 圈定试验项目非空行，逐行判 S2 或 S3（互斥分支，§5.3） | `W03` |
| 5 | 按 §4 表定级，汇总问题清单 | `B05` / `W02` / `W03` |
| 6 | 按总纲第 11 节十章模板出报告；频率配对结果挂 10.1 | 报告 |

**第 4 步须逐行、不可整列比对**：同一份表里 ELV 行写「每两年」是对的，耐久行写「每两年」就是错的。整列统一比对必然误判。

## 10. 不要做

1. 不要判试验项目是否选全、标准是否现行有效、样本量是否充分——那是 `S03`。
2. 不要整列比对测试频率——必须逐行按试验项目分支判定（§5.3、§6 末段）。
3. 不要把「每两年」当成所有项目的通用要求——只有 ELV / 禁限用 / EMC 三类适用（§5.3）。
4. 不要判供应商代码与全称是否真实对应——那是 `S03`（§5.5 末段）。
5. 不要因样本量是「三件」就判通过——须有阿拉伯数字（§5.4）。
6. 不要把频率为空记成 `W02`——本类目落 `W03`（§5.3 末段）。
7. 不要把质量等级为空记成 `W03`——空值优先记 `W02`（§5.2）。
8. 不要把一行的多个空列记成多条 `W02`——一行只记一次（§5.6 第 2 项）。
9. 不要用其它客户的频率口径套本类目（§7 预留位说明）。
10. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
11. 不要在报告里出现「疑似」「可能」类未定级表述。
12. 不要新增章、调整章序或自定义报告字段。
13. 不要修改 `00-A §2.2` 的判据文本；判据有误应先改 00-A，再同步本分则。

| 置信度门槛 | 可配置（不低于「中」） | **低于中 → `B03` 识别失败（总纲 4.8）**；**不得返回「未执行」**——其成因已由总纲 5.1 收窄为唯一一种 |
| 深度档 | **不适用** | 深度档只对 L3 试探（总纲 7.7）；本条目为 L2 |
