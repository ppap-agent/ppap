## 1. 目的与边界

**目的**：判定这份《检具验收报告》**是否具备可被理想审核的检具台账与认可结构**——即「检具清单」表与「检具认可报告」表是否都在、认可报告是否填了实质内容、清单行是否填全、标题是否带车型代号前缀。

**不是**判定检具能不能用。检具的重复性、再现性、Cg/Cgk 指标、验收结论是否合理，全部是正式审核的工程结论，预检不碰。

**边界三条**：

1. 本类目**不判实测值**、不做测量数据复算，故不产生 `B06`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅理想一家），客户差异层为预留位。

## 4. 判定项（6 项）

> 判据文本以 `00-A §2.2` 为准，本节只把它落成可执行判定。

| # | 判定内容 | 判定方式 | 不满足时 | 来源条款 |
| --- | --- | --- | --- | --- |
| S1 | 含「检具清单」表 | 表标题近义匹配 | **`B05`** | 1 |
| S2 | 含「检具认可报告」表 | 同上 | **`B05`** | 1 |
| S3 | 检具认可报告中「除备注外」内容非空 | 该表除备注列外的单元格存在非空值 | **`B05`**（整块不可用） | 1 |
| S4 | 检具清单「零件号」列有值时，同行「除备注外」其余列非空 | 逐行判定 | `W02` | 1 |
| S5 | 检具清单**标题前缀为车型代号**（如「W04项目检具清单」） | 表标题正则匹配车型代号前缀 | `W03`（写法不规范） | 2 |
| S6 | 「所附文件」区若有「不合格」「非完成」勾选，则「结论」区必须非空 | 勾选区状态 + 结论区非空判定 | `W02` | 3 |

**S3 为何判 `B05` 而非 `W02`**：认可报告表在、但除备注外**全部为空**——这意味着这份文件没有任何可审核的认可内容，规则虽能定位表，但**得不出任何结论**，属总纲 7.2 的「结构存在但不可用」。这与「个别行没填」（`W02`）有量级差别：前者整块不可用，后者是局部缺值。

**S5 为何判 `W03` 而非阻断**：车型代号前缀是**写法规范**要求，不影响能否审核——没有前缀，规则仍能定位到这张检具清单、仍能判认可内容。写法不规范是整改项，不是不可审项。

## 5. 判定细则

**5.1 表标题近义通过**

| 应有表 | 可接受的标题写法（示例，非穷举） |
| --- | --- |
| 检具清单 | 检具一览表 / 检具台账 / 工装检具清单 / 检具明细 |
| 检具认可报告 | 检具验收报告 / 检具认可记录 / 检具验收记录 |

近义**只用于确认表存在**。表内取值另按 S3~S5 判定，不得因「标题近义通过」而放行内容。

**5.2 S5 车型代号前缀的判定**

理想模板的车型代号形如 `W01` / `W02` / `W04` / `X01`。判定规则：

| 表标题形态 | 判定 | 说明 |
| --- | --- | --- |
| 「W04项目检具清单」 | 通过 | 代号 + 「项目」+ 表名 |
| 「W04-检具清单」 | 通过 | 分隔符可有可无 |
| 「检具清单（W04）」 | 通过 | 代号位置不限，只要出现在标题中 |
| 「检具清单」 | `W03` | 无代号 → 写法不规范 |
| 「XX 项目检具清单」 | `W03` | 代号位置是文字而非车型代码 |
| 「W04项目检具清单」但全文识别客户代号为 `X01` | 通过 | 只判**有无**代号，不判代号与项目是否匹配（属 `S03`） |

**只判「有无代号」，不判「代号是否正确」**——代号与项目的对应关系属工程信息，预检不掌握项目台账，不得推定。

**5.3 S3 与 S4 的关系（必须分清，否则会重复计问题）**

| 情形 | S3 | S4 |
| --- | --- | --- |
| 认可报告表整表除备注外全空 | **`B05`** | **不再判**（表无内容，逐行判定无意义） |
| 认可报告表部分行有值、部分行为空 | 通过 | 空行按 `W02` |
| 认可报告表全部行有值 | 通过 | 通过 |

**S3 命中时不再判 S4**：一处问题不得记成「1 条 `B05` + N 条 `W02`」。这是本分则的执行顺序约束（§6）。

**5.4 S4「同行其余列非空」的判定范围**

1. 先定位「零件号」列与「备注」列。
2. 判定范围 = 该行**除「零件号」与「备注」外的全部列**。
3. 任一列为空即记 `W02`，**一行只记一次**（不按列数累计）。
4. 「零件号」为空的行**跳过**，不判——空行不是缺陷。

**标题行、小计行、合计行不参与判定**：须先从数据行中剔除。剔除规则：整行仅 1~2 个单元格有值、且首列含「合计」「小计」「备注」「说明」等字样。

**5.5 S6 勾选联动的判定**

「所附文件」区出现以下任一情形时，S6 触发：

| 触发条件 | 说明 |
| --- | --- |
| 勾选「不合格」 | 明确的不合格项 |
| 勾选「非完成」「未完成」 | 明确的不完整项 |
| 勾选「有条件接受」 | 视同非完全合格，触发结论必填 |

触发后，「结论」区（理想模板通常在表的末尾或独立区域）**必须非空**；为空记 `W02`。

**未触发时不判 S6**：所附文件全部为合格 / 已完成时，结论区留空不构成缺陷——记「本项不适用」。

**5.6 客户差异层为空时的兜底**

本期 `T05` 只有理想一条路由。若将来出现其它客户的检具验收规则，**不得**套用本分则的 6 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

## 6. 执行流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（理想, 检具验收报告），置信度 ≥ 中 | 路由 = `L09` / L2 |
| 2 | 定位两张表（§5.1） | `B05` 或表对象 |
| 3 | 判 S3（认可报告是否整块为空） | `B05` 或通过 |
| 4 | **S3 通过后**再判 S4（逐行）；同时判 S5（标题前缀） | `W02` / `W03` |
| 5 | 判 S6（所附文件勾选联动） | `W02` 或「不适用」 |
| 6 | 按 §4 表定级，汇总问题清单 | `B05` / `W02` / `W03` |
| 7 | 按总纲第 11 节十章模板出报告；两表识别结果挂 10.1 | 报告 |

**第 4 步依赖第 3 步**：S3 命中时跳过 S4（§5.3）。顺序颠倒会重复计问题。

级别定义与原因码含义见总纲 5.2 / 8.1，本节只列本类目的典型情形。

| 原因码 | 本类目典型情形 | 责任侧 |

## 9. 报告与输出

按总纲第 11 节「统一报告模板 v1.0」十章输出，本分则不再另行定义章序。

| 挂载位置 | 内容 |
| --- | --- |
| 第二章 | 文件级结论列填「路由 `L09` / L2」；本类目无同批组，该列填 `—` |
| 第四章 | 阻断项：S1、S2 缺失，S3 整块为空 |
| 第五章 | 警告项：S4 行内缺值、S5 无代号、S6 结论未填 |
| 第九章 | 6 项结构判据逐项结果（`RS-L09-S1`~`S6`），S3 命中时须注明「S4 不再判定」 |
| 10.1 | 两表识别结果：实际表标题、命中方式、数据行数、剔除的合计行 / 标题行 |
| 10.2 | 解析说明：备注列定位方式、所附文件勾选状态、表格线是否完整 |

**结论口径**：任一 `B` 码 → 不通过；仅 `W` 码 → 通过。

**识别置信度低不等于「未执行」**：低置信度按总纲 4.8 记 `B03`（识别失败 · 身份不可归属），出路为 4.9 人工指定。总纲 5.1 已把「未执行」收窄为**单一成因**（该条目既无分则也无 `required_structure`），识别置信度不在此列——把它记成「未执行」等于让一份认不出是谁的文件**免检放行**。

## 10. 不要做

1. 不要判检具精度、重复性再现性、Cg/Cgk 是否达标——那是 `S03`。
2. 不要判车型代号与项目是否对应——只判有无代号（§5.2 末段）。
3. 不要在 S3 命中后继续判 S4（§5.3）。
4. 不要把一行的多个空列记成多条 `W02`——一行只记一次（§5.4 第 3 项）。
5. 不要对「零件号」为空的行判 S4——空行不是缺陷。
6. 不要把标题行 / 合计行当数据行判（§5.4 末段）。
7. 不要在所附文件全部合格时判 S6——记「不适用」（§5.5 末段）。
8. 不要用模具验收报告（`T06`）的判定项套本类目（§2）。
9. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
10. 不要因本批次缺其它文件记任何问题——本类目无同批依赖。
11. 不要在报告里出现「疑似」「可能」类未定级表述。
12. 不要新增章、调整章序或自定义报告字段。
13. 不要修改 `00-A §2.2` 的判据文本；判据有误应先改 00-A，再同步本分则。
