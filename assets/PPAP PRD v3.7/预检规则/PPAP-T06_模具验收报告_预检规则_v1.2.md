## 1. 目的与边界

**目的**：判定这份《模具验收报告》**是否具备可被理想审核的模具台账与验收结构**——即 2 个表头字段、11 个必备列、1 个尺寸格式、1 个照片列、1 个签署字段、1 个确认列是否齐备。

**不是**判定模具能不能投产。模具尺寸精度、型腔数、量产性能评估、维保方案，全部是正式审核的工程结论，预检只判**这些内容有没有被承载在结构里**。

**边界三条**：

1. 本类目**不判实测值**、不做尺寸复算（长×宽×高只判格式，不判合理性），故不产生 `B06`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅理想一家），客户差异层为预留位。

## 5. 判定细则

**5.1 列名近义通过**

| 必备列 | 可接受的列名写法（示例，非穷举） |
| --- | --- |
| 工艺类型 | 工序类型 / 工艺类别 / 制造工艺 |
| 一级分总成零件名称 | 一级分总成名称 / 分总成零件名 / 一级件名称 |
| 分总成组件或分序模具名称 | 分序模具名称 / 组件模具名称 / 模具名称 |
| 模具制造供应商 | 模具供应商 / 制造厂 / 模具承制方 |
| 模具存放地点 | 存放位置 / 存放地 / 仓储地点 |
| 零件质量评估 | 零件质量评价 / 质量评估 / 零件评估 |
| 模具分供方及实物 VS 数据&标准验收 | 分供方验收 / 实物与数据验收 / 实物VS数据验收 |
| 模具量产性能评估 | 量产性能评价 / 量产评估 / 量产能力评估 |
| 模具维保评估 | 维保评估 / 维护保养评估 / 保养评价 |
| 模具设计尺寸 | 设计尺寸 / 模具尺寸 / 外形尺寸 |
| 实物照片 | 照片 / 实物图 / 模具照片 |
| 实物确认 | 实物核对 / 实物确认结果 / 确认 |

近义**只用于确认列存在**。列内取值另按 `W02` / `W03` 判定，不得因「列名近义通过」而放行取值。

**5.2 S12「长×宽×高」格式的判定**

| 取值形态 | 判定 | 说明 |
| --- | --- | --- |
| `1200×800×600` | 通过 | 标准形态 |
| `1200*800*600` | 通过 | `*` 等同 `×` |
| `1200 x 800 x 600` | 通过 | `x` 等同 |
| `1200*800*600mm` | 通过 | 允许带单位后缀 |
| `1200×800` | `W03` | 只有两维 |
| `1200×800×600×400` | `W03` | 超出三维 |
| `见图纸` / `见附件` / `—` | `W03` | 非数值描述 |
| 空 | `W02` | 缺值（不记 `W03`） |

**只判格式，不判数值是否合理**：模具 1200×800×600 是否与零件匹配，属 `S03`。

**5.3 S13 图片列的识别**

1. 先按 §5.1 定位「实物照片」列。
2. 逐行判定该列单元格是否含图元（图片对象 / 嵌入图 / 图片占位符被填充）。
3. **至少一行含图** → S13 通过。
4. **有列、全列无图** → `W01`，报告写明「实物照片列为空」。
5. **不得**判照片清晰度、角度、是否为本模具（那是 `S03`）。

**5.4 S14 签署字段与 S1/S2 的差别**

S1、S2、S14 三组字段的判定路径相同（缺 → `B05`、空 → `W02`），但**必须分别记录**：

- S1「零件供应商名称」、S2「提交日期」属**文件身份信息**。
- S14「编制」「审核」属**签署要件**。

报告 10.1 须分组呈现，不得合并为「表头字段齐全」一句。

**5.5 S15 取值集合校验**

| 取值 | 判定 |
| --- | --- |
| `有` | 通过 |
| `无` | 通过 |
| `是` / `否` | `W03`（越界，须按模板口径写「有 / 无」） |
| `Y` / `N` | `W03` |
| 空 | `W02` |
| 其它文字 | `W03` |

**空值优先级**：单元格为空时记 `W02`，不记 `W03`——空是缺值，不是越界。

**5.6 多级表头的还原**

理想模板含一级分组列（如「模具分供方及实物 VS 数据&标准验收」下挂多个子列）。判定规则：

1. S9 按**一级列名**判定。
2. 一级列存在即视为 S9 通过，**不要求**其下子列齐全（本分则未从规则原文抽到子列要求，不得自行加严）。
3. 若多级表头结构丢失（合并单元格变成单行文本），记 `W05`，按文字位置重建，并在 10.2 说明重建结果。

**5.7 客户差异层为空时的兜底**

本期 `T06` 只有理想一条路由。若将来出现其它客户的模具验收规则，**不得**套用本分则的 15 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

## 6. 执行流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（理想, 模具验收报告），置信度 ≥ 中 | 路由 = `L10` / L2 |
| 2 | 还原表头层级（§5.6），取出一级列名与二级列名 | 列清单 |
| 3 | 判 S1、S2、S14 三组字段（存在性 + 非空） | `B05` / `W02` |
| 4 | 判 S3~S11 九个列的存在性（§5.1） | `B05` |
| 5 | 判 S12 尺寸格式、S13 照片列、S15 实物确认取值 | `W02` / `W03` / `W01` |
| 6 | 按 §4 表定级，汇总问题清单 | `B05` / `W01` / `W02` / `W03` |
| 7 | 按总纲第 11 节十章模板出报告；列匹配结果挂 10.1 | 报告 |

**执行顺序不可调换**：先还原表头，再判列。表头层级未还原时判列会把「一级列存在、子列被拆平」误判为缺失。

## 10. 不要做

1. 不要判模具质量、尺寸精度、型腔数、量产性能、维保方案是否合理——那是 `S03`。
2. 不要判「长×宽×高」的数值是否与零件匹配——只判格式（§5.2 末段）。
3. 不要判实物照片的清晰度、角度、是否为本模具（§5.3 第 5 项）。
4. 不要要求 S9 一级列下的子列齐全——规则原文未抽到子列要求（§5.6 第 2 项）。
5. 不要把 S1/S2（身份信息）与 S14（签署要件）合并成一句「表头齐全」（§5.4）。
6. 不要把空值记成 `W03`——空是 `W02`（§5.5 末段）。
7. 不要在表头层级未还原时判列缺失（§6 末段）。
8. 不要用检具验收报告（`T05`）或设备清单（`T13`）的判定项套本类目（§2）。
9. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
10. 不要因本批次缺其它文件记任何问题——本类目无同批依赖。
11. 不要在报告里出现「疑似」「可能」类未定级表述。
12. 不要新增章、调整章序或自定义报告字段。
13. 不要修改 `00-A §2.2` 的判据文本；判据有误应先改 00-A，再同步本分则。

| 置信度门槛 | 可配置（不低于「中」） | **低于中 → `B03` 识别失败（总纲 4.8）**；**不得返回「未执行」**——其成因已由总纲 5.1 收窄为唯一一种 |
| 深度档 | **不适用** | 深度档只对 L3 试探（总纲 7.7）；本条目为 L2 |
