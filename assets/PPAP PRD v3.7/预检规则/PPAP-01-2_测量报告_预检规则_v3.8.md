# 尺寸测量报告 — 数据标准化预检规则

> 版本：v3.8
> 类目：PPAP 01-2 测量报告 —— **尺寸测量报告**（含测量比较报告、尺寸测量报告、尺寸检验报告三种形态）
> 定位：正式业务规则审核前的输入质量门禁。
> 核心原则：**预检只判定「这批提交能否被可靠审核」，不判定「这份报告是否合规」。无阻断项即通过；警告不拦截，仅记录并随报告移交正式审核。** 每次调用独立判定，仅检查、判定和报告，不执行修复。
> 上位框架：《PPAP-00_数据标准化预检总纲_v0.14.md》，配套《PPAP-00-A 覆盖矩阵 · 路由表 v1.7》。本文件为其分则，二者冲突时以总纲为准。
> **路由前提**：先按总纲 4.5 定（客户 × 文件类型），再加载本分则。本分则只承载 **UAES × 测量比较报告（`E02`）** 与 **蔚来 × 测量报告（`T01`）** 两条条目；**模板族定「字段在哪儿」，客户定「用哪套规则」——两者是独立线索，不得互相替代**（6.2、7.12）。
> 全文只回答两个问题：**① 这份文件是不是测量报告？**（第 2 章 D1～D4）**② 若是，够不够格进入深度审核？**（8.2 A1～A6）

## 1. 目的与定位

### 1.1 两级判定主线

| 阶段 | 回答的问题 | 判据 | 产出 | 不满足时 |
| --- | --- | --- | --- | --- |
| **第一级 · 识别** | 这份**文件**是什么？是不是测量报告？属哪种形态、哪一族、单方还是双边？ | 2.1 D1～D4；2.4 三种形态；6.2 族签名；6.3 业务类型 | 逐文件**三值识别结论** + 五个标签（报告 10.1） | 「不是」→ `S01` 范围外，不出判定（5.4）；「判不出」→ **阻断 `B03`**（M-01） |
| **第二级 · 准入** | 这份**测量报告**够不够格进深度审核？ | 8.2 A1～A6 | 通过 / 不通过 + 原因码 | A3～A6 不满足 → **不通过**；A2 不满足 → `W01` 警告（不阻断） |

**第一级不过，第二级不启动**。两级与结论的映射：

| 第一级结论 | 第二级 | 最终结论 |
| --- | --- | --- |
| 是测量报告 | 启动 | 通过 / 不通过（8.3） |
| 不是（属其他类目） | **不启动** | 该件记 `S01` 范围外，不出质量判定；本批无任何测量报告 → **未执行** |
| 判不出（缺 D1 或结构不可读） | **不启动** | **不通过**（M-01 阻断 `B03`） |

**规则编号与两级门的对应**（详见 7.1）：

- 识别级：`M-01`（是不是测量报告 / 族可否识别）、`M-14`（业务类型）、`M-15`（双边两侧齐备）、`M-04`（要求的列是否存在）。
- 准入级：其余 `C-*`、`M-*`、`S-*`。

### 1.2 与正式审核的分工

| | 数据标准化预检（本规则） | 正式业务规则审核 |
| --- | --- | --- |
| 回答的问题 | 这一批**能不能审** | 这份报告**合不合规** |
| 对「偏差 0.55 > 公差 0.50」 | 只确认实测值、上下公差、基准值三者可读且可复算 → 移交 | 判超差 |
| 对「Centering 0.70」 | 只确认该列可读、能被复算 | 判超阈值 |
| 对「签字栏为空」 | 只判签字区是否存在、是否可定位 | 判未签署 |
| 判定词 | 通过 / 不通过 / 未执行 | 满足 / 不满足 / 无对象 |
| 不通过的处置 | 打回补数据、修模板、换文件 | 打回改产品 / 改报告 |

- 报告**禁用**「合格 / 超差 / 达标 / 不合规」等业务判定词；业务疑点只写「移交预判」栏并注明"不构成审核结论"。
- 预检结论写「通过预检」，**不得**写「合格」「无问题」（总纲第 9 节话术纪律）。

### 1.3 定位边界与运行位置

本规则不判零件是否合格、不判报告是否通过审核、不判提交范围是否完整、不生成整改后文件。

| 环节 | 发生位置 | 本规则是否参与 | 产出 |
| --- | --- | --- | --- |
| **待审文件提交（本批）** | 项目 → 审核入口 | **是，本批输入** | 可全量（`ALL`）也可部分（`PARTIAL`） |
| **数据标准化预检** | 审核入口前置 | **是（本规则）** | 只回答"能不能审" |
| 正式规则审核 | 下游审核方 | 否 | 回答"合不合规" |

四条硬约束：

1. **规则是常量，不是本批输入**。不得要求调用方提交规则文档，不得在规则集不全时"临时解析原文顶替"（总纲 2.3）。
2. **规则侧问题一律不评、不记、不影响结论**。规则集实际不可用时返回「未执行」，**不得降级为「不通过」，也不得打回供应商**（总纲 2.3 第 3 条）。
3. **单一版本、内置只读**：同一时刻只生效一个版本；不得自选版本、不得按客户等级降级运行、不得因文件"像另一族"而换用别族规则链。
4. **判定只用本批文件内的自证证据**（4.2）。不判"该交没交"，只判"交上来的能不能审"。

## 2. 什么是测量报告（第一级）

### 2.1 定义性要件 D1～D4

**测量报告**指：以零件的几何/尺寸特性为对象，按件记录实测值，并以图纸公差为参照判定该批零件是否满足公差要求的文件。

四项要件独立判定，但**只有 D1 与 D3 决定归属**：

| 要件 | 内容 | 判定方式（看什么） | 不成立时 |
| --- | --- | --- | --- |
| **D1 对象** | 记载**零件的几何/尺寸特性**：长度、孔径、位置度、轮廓度、平面度、间隙与面差 | 有无测点号 / 特性描述 / 图纸标注号；特性是否指向零件具体位置 | → **不是本类目**，按 2.6 指出属哪一类 |
| **D2 记录形态** | 实测值**按件或按样本分列**（`#1～#10`、`Part1～5`、`UAES 1-5`/`供应商 1-5`），每件可回溯到测点 | 是否存在成组样本列，列头可区分为不同件 | 不改变归属；进准入门后按 M-07 / M-08 记问题 |
| **D3 参照** | 每个特性有**名义值与公差限**，实测值与之比对 | 有无名义值（基准值 / 理论值）列，以及上、下公差列或公差带 | → **不是测量报告，是检验记录** |
| **D4 用途** | 用于判定**该批零件是否满足公差**，并有测量主体与确认主体 | 有无零件标识、测量日期、测量员 / 检验员、签署区 | 仍属测量报告，准入拦（M-03、M-10） |

> **D3 是"测量报告"与"检验记录"的分界线**：一份文件名叫"××检验报告"、有表头有签字有零件号，但整表只有 ✓/✗ 或"合格/不合格"，无名义值、无公差、无实测数值——**它不是测量报告**。

### 2.2 识别规则 R1～R5（按序执行，命中即停）

| 步 | 判定 | 识别结论 | 后续 |
| --- | --- | --- | --- |
| R1 | 结构不可读（打不开、空白到无任何特性行、内容与文件名无关、扫描件无法确认 D1） | **判不出** | **阻断 `B03`/`B01`**（M-01） |
| R2 | D1 不成立（对象是测量系统 / 过程 / 器具 / 材料性能） | **不是（属 XX）** | `S01` 范围外，不出判定 |
| R3 | D1 成立、D3 不成立（无名义值或无公差限） | **不是（检验记录）** | `S01` 范围外，注明应交"检验记录 / 属性检验"类目 |
| R4 | D1 + D3 成立 | **是测量报告** | 进入第二级；D2/D4 缺失不改变归属，按对应规则记问题 |
| R5 | 同上，且能落到文档形态、模板族、业务类型 | **是测量报告** + 五个标签 | 写入报告 10.1 |

**识别结论只有三个取值**，报告 10.1 须逐文件给出，不得留空、不得写"疑似"：

| 识别结论 | 报告写法 | 后续处置 |
| --- | --- | --- |
| 是测量报告 | `是 / 测量报告` + 文档形态 + 模板族 + 业务类型 | 启动第二级 |
| 不是 | `不是 / 检验记录`、`不是 / MSA`、`不是 / SPC`、`不是 / 校准证书`，须写明属哪一类 | `S01` 范围外，**不出任何质量判定** |
| 判不出 | `判不出 / 结构不可读`、`判不出 / 无特性行`，须写明缺哪项要件 | **阻断（M-01）**，要求重新提交可读文件 |

### 2.3 模板族签名不是识别判据

族签名（6.2）回答"**按哪一套规则审**"，属路由问题；识别只看 D1～D4。两档**不合并计分**：

| 情形 | 结论 | 级别 | 原因码 | 责任侧 |
| --- | --- | --- | --- | --- |
| D1～D4 判不出（**是不是**都不确定） | 识别结论「判不出」 | **阻断（M-01）** | `B03`（结构不可读时 `B01`） | 提交方 / 解析侧 |
| D1+D3 成立、但族签名不足（**是**测量报告，族未定） | 识别结论「是 + 族未定」 | **警告（M-01 降级档）** | `W01` | 材料侧 |

> **族未定不是规则侧问题**：模板族由**文件内容签名**唯一决定，签不够是文件自身的特征不足，属材料侧。族未定的连带后果是「族特定审核规则项无可判定对象」，该情形在报告第九章「检查项全量结果」中标注，**不另立问题、不再计一次**。

### 2.4 三种文档形态

确认"是测量报告"后按形态细分——形态决定"字段在哪儿"，不决定"是不是"。

| 形态 | 典型来源 | 结构特征 | 处理方式 |
| --- | --- | --- | --- |
| 测量比较报告 | UAES 模板 F-PU-166 | 单页四栏（零件 / 供应商 / UAES / 尺寸区）+ 双方各 5 件对比 + 四方签字 + 说明页 + 变更页 | UAES_MCR 族（U-00、U-14） |
| 尺寸测量报告 | NIO、理想汽车模板 | 封面 + 数据页（Datum / Gap&Flush 或单页表）+ 逐件实测 + 统计列 + 测点图 + 签核 | 按族绑定规则链 |
| 尺寸检验报告 | 客户自定义 / 供应商自制 | 单页表格 + 逐件实测 + 判定列 | 先落族，再按族判定；落不了族按 2.3 警告档 |

三种形态共同的判断对象只有一件事：**这份文件是否把"测什么、允许多少、实测多少、谁测的、谁认的"记录在可读、可复算、可追溯的位置上**。

与之正交的是**报告业务类型**：测量比较报告＝`Measurement_Comparison`（双边）；尺寸测量报告 / 尺寸检验报告＝`Gage_Inspection`（单方），除非同表内确含双方实测区块（6.3）。

### 2.5 易混淆文档的归属判定

| 文档 | 识别结论 | 判据 | 处置 |
| --- | --- | --- | --- |
| 尺寸检验记录表（只有 ✓/✗，无实测值） | **不是（检验记录）** | D3 不成立 | `S01` 范围外；注明应交"检验记录 / 属性检验" |
| 首件检验单（只测 1 件） | **是**（单方） | D1～D4 成立，样本数 = 1 | 进入第二级；M-07 警告 |
| CMM 原始点云 / 测点导出文件 | **不是（原始数据）** | D3、D4 不成立 | `S01` 范围外；它是报告的数据源，不是报告 |
| 全尺寸检验报告（图纸气泡编号 + 实测） | **是** | D1～D4 成立 | 按内容签名落族后判定 |
| 空白模板（结构齐全、无任何数据） | **是**（但无数据） | D1～D4 结构上成立 | 进入第二级；**M-06 阻断 `B04`** |
| MSA GR&R / SPC 控制图 / 校准证书 / 材料性能报告 | **不是** | D1 不成立 | 见 2.6 |
| 扫描件 / 图片（结构不可读） | **判不出** | 无法确认 D1 | **M-01 阻断 `B01`**；要求提供可读文件 |

### 2.6 与 MSA / SPC 的边界

| 类别 | 典型文档 / 指标 | 在范围内 | 说明 |
| --- | --- | --- | --- |
| **MSA 测量系统分析** | GR&R、偏倚、线性、稳定性、NDC、Kappa | **否** | 属测量系统能力文件，另见 PPAP-06 |
| **SPC 统计过程控制** | 控制图（Xbar-R / P / NP / C / U）、Cp / Cpk / Pp / Ppk、判异准则 | **否** | 不判过程是否受控、不判能力指数是否达标（另见 PPAP-07） |
| **计量管理** | 检具校准证书、量具台账、校准有效期 | **否** | 属计量管理范畴 |
| **尺寸测量报告** | 测点号、坐标、基准值、上下公差、逐件实测、均值、极差、测点图、签署 | **是** | 本规则的唯一对象 |

三条必须写清的边界：

1. **报告内的 Centering / Range 是记录字段，不是 SPC 能力指标**。只判"是否存在、能否独立复算、差异是否在容差内"，不作能力评价、不推断 Cpk。
2. **"逐件实测 ≥5 件"是模板规定的逐件件数，不是 MSA 的重复测量次数**。二者数值可能同为 5，含义不同。
3. **"检具号 / 测量设备 / 测量方法"字段只判存在与一致，不判是否合格**（不判校准有效期）。

> 本批混入 MSA / SPC / 检具类文件：记 `S01` 范围外，**不计分、不判定**，不得对其实施任何 C/M/S 检查。

### 2.7 非目标与硬性禁止项

**非目标**

- 不解析、不评审、不维护规则原文（属上游规则入口职责）。
- 不对本项目未提交的文件出具任何结论，也不推定其状态。
- 不做跨批次累积重审，仅做跨批识别（S-15）。
- 不进入 MSA / SPC 判定；不进入正式业务合规审核（不判超差、阈值、签字、类型值域）。
- 不修复、不补全、不转换原始文件；不执行整改后复检。
- 不承担字段落库与布局探针实现；字典的工程准则只取**判定含义**。
- 不依赖特定模型、平台或 Agent 框架。

**硬性禁止项（摘要，完整版见 12.4）**

- 不得跨模板族套用规则链。
- 不得把「测点级别 A/B」映射为「类型 CC/SC/AC」。
- 不得把「极差 Rng（绝对值）」当作「Range（极差 ÷ 公差带）」。
- 不得用「字段非空」代替「字段有效」。
- 不得混用「实测绝对尺寸」与「实测偏差值」。
- 不得因无适用行而判不通过。
- 不得把「未提交」当作「缺失」计入问题；不判缺件（4.2、7.9）。
- 不得把「本批无本类目文件」表述为「通过」或「不通过」（结论为「未执行」）。
- 不得用族签名代替"是不是测量报告"的判据；不得把「检验记录」当测量报告审。
- 不得输出任何关于规则集、数据字典、判定口径的问题（总纲 2.3）。
- 不得把本批结论表述为项目全量结论；不得对 MSA / SPC 文档实施本规则任何检查项。
- 不得修改原始文件。

## 3. 术语

| 术语 | 说明 |
| --- | --- |
| 证据封闭性 | 判定证据必须落在**可及证据集**之内（`SRC-1` 提交件 ∪ `SRC-2` 受控提供源 = 客户图纸 / 技术规范 / 客户台账，总纲 3.2.1 / 4.4）。需集合之外的事实才能成立的结论，只能陈述或提醒（4.2） |
| 项目上下文 / 提交范围声明 / 必备清单 | 均属**不确定信息**：可写入报告署名与陈述，**不作判定依据**（4.2） |
| 比对规则 | 必须同时读取本文件与另一份材料才能判定的审核规则；仅当规则条目**声明了所需对端角色**时才成立（7.10） |
| 本批构成陈述 | 报告 10.1 对「本批收到了哪些文件」的陈述；**不判定提交范围是否完整**（7.9） |
| 能力缺口 | 仅指执行方侧数据限制导致**无法校验**的项（当前仅一类：测点图锚点与标注不可解析）。不记级别，须显式声明「未执行」 |
| 模板族 | 由客户模板体系决定的字段结构、命名与统计口径集合。已知 3 族：UAES_MCR、NIO_DMR、LIXIANG_DMR（12.1） |
| 规则链 | 与模板族一一绑定的**正式审核规则**子集：UAES → U-00、U-14；NIO → U-00～U-13；理想 → 空 |
| 族级判定参数 | 同族所有判定共用、随本分则内置的六项常量：实测列语义、方向码集、样本列数、最小样本数、是否要求测点图、签字方数（7.6.1） |
| 测点号 | 唯一标识一个测量点的编号（如 H001U、MGP5、A1） |
| 派生行 | 测点号由其他测点组合而成的一致性行（如 `para_MGP1_MGP5`）；不参与"测点图一一对应"判定 |
| 名义值 / 基准值 | 图纸理论尺寸。不同模板命名不同：Nominal / 基准值 / 特性值 |
| 公差带 | 上公差 − 下公差 |
| 实测列语义 | 样本列存放的是**绝对实测尺寸**还是**相对名义值的偏差值**。NIO＝偏差值；理想/UAES＝绝对实测 |
| 方向编码 | 「主要控制方向」取值体系。NIO：X/Y/Z/ND/Gap/Flush/ND-/Gap-/Flush-；理想：D/N/L/W/G/F；UAES 无 |
| Centering | 中性值 =（−名义值 + 实测均值）÷ 公差带；偏差值语义下名义项为 0 |
| Range | 极差比率 =（实测最大 − 实测最小）÷ 公差带 |
| 极差 Rng | 实测最大 − 最小的**绝对值**，与 Range 不是同一量 |
| 占位符 | 格式合法但不承载真实信息的值：`0`、`XX`、`W0XX`、`pp`、`ABC`、`待填`（12.2） |
| 同源文件 | 同一份报告的两种形态（Excel 及其打印 PDF），视为一份审核对象 |
| 可审 | 存在承载该规则的原始数据位置，且值可被读取、可被判定（包括可判定为"空"） |
| 预判 | 对移交正式审核事项的"若进入审核可能得到的结果"，记 `S03`，不构成审核结论 |
| 定义性要件 D1～D4 | 判定"是不是测量报告"的四项判据：对象 / 记录形态 / 参照 / 用途；D3 是与"检验记录"的分界线（2.1） |
| 识别结论 | 逐文件三值结论：`是` / `不是（属 XX）` / `判不出（缺 D?）`（2.2） |
| 准入要件 A1～A6 | 判定"能否进入深度审核"的六项正面条件（8.2） |
| 检验记录 | 只给合格/不合格结论、无名义值与公差限、无逐件实测值的文件 → **不属测量报告**（2.1、2.5） |
| 派生字段 | 按定义重算、不接受人工录入：公差带、均值、极差、Centering、Range、差异率、状态（7.6.4） |
| 伪定量 | 属性型特性（通止规、Go/No-Go）被填成数值（多为 `1`/`0`），看似定量实则定性（C-14） |
| 结构性空 | 因垂直合并单元格而下方留空，并非漏填（M-17） |
| 锁定行 | 以底色标记为不可编辑的行，属示例行或模板行，不是数据行（M-16） |
| `S01` / `S02` / `S03` / `S04` | 四种**状态**（不是级别，不参与通过判定）：范围外 / 对端未到 / 规则不适配 / 移交正式审核（5.4） |

## 4. 输入契约

### 4.1 必选输入

**唯一确定的输入是用户提交的待审文件**（L1）；规则集、族级参数与字典是内置常量（L2）；其余一切只作陈述与提醒（L3）。

| 输入 | 要求 | 缺失时处理 |
| --- | --- | --- |
| 本批待审文件（1～N） | 内容、页签、单元格、图片锚点、文件名 | 无任何文件 → 结论「未执行」 |
| 提交范围声明（可选） | `ALL` / `PARTIAL` | 未声明 → 按部分提交推定并记 `W01`；**不得据此判缺件阻断**（总纲 4.2） |
| 项目上下文（可选） | 项目、阶段、供应商、工厂、车间 | 仅署名陈述，不作判定依据 |

| 层级 | 输入 | 确定性 | 可用于判定 |
| --- | --- | --- | --- |
| **L1 确定** | 本批提交文件 | **确定** | **是**——全部文件级判定的唯一证据来源 |
| **L2 常量** | 内置规则集（族绑定、族级参数）、数据属性字典（12.5） | **确定** | **是**——判定口径来源 |
| L3 不确定 | 项目上下文、提交范围声明、必备类目清单、上一批次结果引用 | 不确定 | **否**——仅署名与陈述 |
| 排除 | 规则集原文（U-00～U-14 / E01～E23） | — | **否**——本规则不接收（总纲 2.3） |

### 4.2 证据封闭性（不确定信息的使用边界）

**规则**：任何判定的证据必须能落在**本批提交的文件集合**之内。凡需"文件之外的事实"才能成立的结论，一律降为**陈述或提醒**。

| 外部信息 | 若允许它判定会出的错 | 本规则的处理 |
| --- | --- | --- |
| `scope` 声明 | 漏勾 → 被判缺件；虚报 `ALL` → 被判大量缺件 | **不接收为判据**。10.1 只写"本批收到什么"，不写"覆盖成立 / 缺件" |
| 项目必备类目清单 | 清单未维护或过期 → 正常提交被判缺件 | **不比对**。缺件判定移交审核入口 / 项目管理（7.9） |
| `project_id` | 归属写错 → 整批被判挂错项目，用户无法自证 | **不作阻断**。仅署名；缺失只写"未提供" |
| 项目主数据（零件号 / 项目 / 阶段） | 主数据过期 → 正确文件被判不符 | **不比对**。改为批内自证：多份文件互斥才判（S-14） |
| 上一批次结果 | 他批被改过或未归档 → 版本倒挂判错 | **仅在两批都在本批内时判**（S-15） |
| 对端文件（图纸 / 控制计划） | 缺件不等于本批文件有问题 | **记 `W01` 警告**，不阻断（7.10） |
| "项目配置声明的族" | 配置写错 → 族冲突阻断用户，而用户改不动配置 | **不作期望族**。族由内容签名唯一决定（6.2） |

三条硬约束（总纲 4.4 的本地化）：① 不判「该交没交」；② 不确定信息可以写、不可以判，出现时标注「未核实」；③ 报告不得出现「因项目信息不符而拦截」的表述，需要提示的写入报告 10.3 待确认清单。

### 4.3 同源配对与可判定证据

- 接收 Excel（xls / xlsx / xlsm）、PDF、扫描件。
- **同源配对**：文件名主体、零件号、版本、日期一致，且一份为 Excel、一份为 PDF → 视为同一份报告的两个形态，按 S-08 逐项比对，**不重复计算问题**。
- 配对不成立时不得强行配对；无法判定同源关系 → 记 `W04` 警告并说明依据。
- 表格抽取、图文理解的具体方式不属本规则内容；**无法获得可判定证据时 → 记为「文件无法解析」类问题（`B01`），不得跳过检查、不得默认为通过**。

### 4.4 解析责任与能力前提

- OCR、表格抽取、图文理解由外部系统或模型层负责，本规则不规定实现方式。
- **执行方不具备视觉能力时**：扫描件、测点图、印章、签名类检查标注为「未执行」，在报告「未进行的检查」栏逐项声明。此类情形**不产生任何级别、不判提交方**——它不是文件缺陷，而是本次预检未覆盖的部分。
- **“未执行”不等于通过**：未执行的检查项在报告第九章标「未执行」，不得填「满足」。

## 5. 输出契约

### 5.1 总体结论（仅两级 + 一个非结论返回值）

| 结论 | 判定条件 | 后续处理 |
| --- | --- | --- |
| 通过 | **无阻断项**（警告项可以存在） | 可进入正式审核；警告项全部随报告移交 |
| 不通过 | 存在任一阻断项 | 按责任分派：材料侧打回整改、提交方补正、解析侧转技术支持 |
| **未执行**（非结论） | 本批**不含本类目任何文件**（判据为 D1+D3，仅凭本批文件本身） | 本规则**未对本批出具判定**；不放行、不打回、不记任何问题 |

**多文件混合时的严格度序**：只要有一个文件存在阻断，总体结论就是「不通过」；其余文件的警告单列披露。**不得因"部分文件属其他类目"就整体改判**，也不得因"有文件判不了"放过已知阻断。

**「未执行」与「通过」的区别**：未执行为"未检查（无检查对象）"，不可作放行或打回依据，报告中**不得出现"通过/不通过"字样**。

**「未执行」时的必写声明**："本批未提交测量报告类文件，本规则未对任何文件出具判定。此结论不表示文件合格，也不表示文件不合格。"

**「未执行」时的报告输出范围**：按总纲 11.2 十章只输出 **4 章**——第一章结论摘要（含固定声明）／第二章提交范围与文件集（含运行前提声明）／第六章状态登记（本类目整体标「**未执行**」；本批中属其他类目的文件逐份记 `S01` 范围外——二者分列，不得互相代替）／第十章 10.1（本批构成陈述与文件识别结论）；**第三、四、五、七、八、九章及 10.2 以下一律省略**。

**规则集实际不可用时**（上游告知规则集未装配 / 未生效，属罕见的运行前提失效）：同样返回「未执行」，并在报告第一章与第二章声明"运行前提未成立"，**不得产出通过 / 不通过，不得打回供应商**（总纲 2.3）。本规则**不自行检测**规则集状态（总纲 2.3 排除规则侧）。

### 5.2 判定顺序

1. **门① 有无本类目文件**：判据是 **D1+D3**（对象是零件几何特性、且有名义值与公差限），**不是模板族命中**。
   - **无** → 结论＝**未执行**，终态，不再执行任何检查，按 5.1 输出 5 节。
2. **文件级定级**（仅对识别为「是」的文件），取第一命中项：

| 序 | 情形 | 总体结论 | 对应要件 |
| --- | --- | --- | --- |
| 1 | 存在任一**阻断项** | **不通过**（拦截打回） | A1 的「判不出」分支；A3/A4/A5/A6 任一不满足 |
| 2 | 无阻断项（无论有无警告） | **通过** | 六项中不满足者仅剩 A2（族未定 → `W01` 警告） |

> **警告不拦截**：只要有警告、无阻断，结论就是「通过」，但警告必须 100% 列报并移交（5.5）。

### 5.3 原因码

结论为「不通过」时必须给出原因码；警告项同样须标码。**一项一码，不得合并**。

**阻断原因码（`B` 系列）**

码的含义见总纲 5.2，下表只列本类目典型情形。

| 码 | 本分则典型形态 |
| --- | --- |
| `B01` | 扫描件无文本层、文件损坏、加密、无法确认 D1 |
| `B02` | 同零件多份报告元信息互斥且无法指定唯一有效版本（S-14） |
| `B03` | 识别结论「判不出」（M-01①）；零件号位置填零件名（C-12）；同页测点号重复（C-05）；业务类型无法落位（M-14 的结构特征不足侧） |
| `B04` | 空白模板（M-06）；示例行 / 锁定行混入数据区（M-16）；单方与双边结构无法落位（M-14） |
| `B05` | 关键列不存在（M-04）；判定依据列写成 `/`（C-01）；公差方向颠倒（C-02）；公差带整表不可算（C-03）；表内值与复算值不可信以致无法取值（C-10 / C-11）；测点图 / 签字区结构性缺失（M-09 / M-10）；只有统计列无逐件值（M-08）；双边缺任一侧（M-15）；状态仅靠底色承载（S-17） |
| `B06` | 封面 ↔ 明细冲突（S-01）；同源 Excel/PDF 冲突（S-08）；图文标注悬空（S-04）；公差带表内值 ≠ 上−下（C-13）；Centering/Range 量级或符号错（S-06）；列映射不唯一（S-19）；批内跨文件互斥（S-14）；版本倒挂（S-15） |

**警告原因码（`W` 系列）**

码的含义见总纲 5.2，下表只列本类目典型情形。

| 码 | 本分则典型形态 |
| --- | --- |
| `W01` | 族未定（M-01②）；变更记录缺失（M-11）；判定栏缺失（M-12）；样本数不足（M-07）；声明列数多于实填列数（S-10）；对端文件未提交（7.10） |
| `W02` | 个别行伪定量填 `0`/`1`（C-14）；逐行必填为空（M-05） |
| `W03` | 参考列脏值（C-16）；定性值写法不一（C-15）；分类个别越界（C-06）；空白与 `0` 混用（S-12）；车型与阶段不可拆（S-16）；前导零丢失 / 日期格式（S-18） |
| `W04` | 表内 ↔ 文件名不一致（S-03）；版本号 ↔ 变更记录（S-09）；同零件同版本重复（S-14） |
| `W05` | 派生列 `#DIV/0!` / `#N/A`（C-17）；合并单元格结构性空不可还原（M-17） |
| `W06` | 均值 / 极差复算超容差（S-05）；Centering/Range 漏算（S-06）；页签索引不符（S-02） |

**`B05` 的适用边界（必读）**：本分则沿用 PPAP-03 v3.0 已确立的口径——`B05` 指**判定所需的值不可取得**，包含两种情形：

| 情形 | 记法 |
| --- | --- |
| 文件结构上根本没有该列 / 该栏 / 该区块 | `B05` 阻断 |
| 列存在，但值读不成可判定值（`/`、文本、量级错、不可算） | `B05` 阻断 |
| 列存在，值为**空**（可确定为空） | `W02` 警告——空值是可确定的事实，规则能据此计算 |

> 该边界已在总纲 v0.6 的 7.6 与 5.2 边界表中统一规定（整列空 → `B05`，个别单元格空 → `W02`），本分则不再另行解释。

### 5.4 状态登记（`S01` / `S02` / `S03` / `S04`）

四种状态**不是级别**，不参与通过判定，但**必须逐条登记，不得略去不记**。

| 状态 | 代码 | 本分则适用情形 |
| --- | --- | --- |
| 范围外 | `S01` | ① 文件经 D1/D3 判定**本就不属**本类目（检验记录、MSA、SPC、校准证书、原始点云）；② 类目内份数差异（仅陈述）。**判据与「交没交」无关** |
| 对端未到 | `S04` | ① 声明应有测量报告而整批未交；② 双边配对一侧未交、同源配对缺另一端。**前置**：对端须在**可及证据集**内不存在（`SRC-1` ∪ `SRC-2`，总纲 3.2.1）——集内已有的**必须正常比对、不记 `S04`**。**分两子型**：`src=SUB` → `W01` + **`S04-S`**；`src=CUS`（客户图纸 / 规范 / 模板）→ 仅 **`S04-C`**、**不配 `W01`**、不进缺件数 |
| 规则不适配 | `S02` | ① 命中族的**正式审核规则链为空**（理想族），该族 U-xx 无判定对象；② 族未定导致族特定规则项无可判定对象。**仅用于规则侧成因，不得用它兜住"文件里没有这个字段"**（总纲 3.1） |

### 6.2 模板族与绑定校验

**只在识别结论为「是测量报告」时执行。族的唯一可信来源是文件内容签名。**

| 优先级 | 来源 | 作用 | 能否定族 |
| --- | --- | --- | --- |
| ① | 文件内容签名（≥2 项命中，或页签结构 1 项 + 表头特征 1 项） | **实际族，唯一判据** | **是** |
| ② | 文件名 / 目录 / 零件号推断 | 仅作辅助佐证 | **否**（与①不一致时以①为准并披露） |
| — | 项目配置声明的族 | **不作期望族**（4.2）；若提供且与①不一致，只在报告 10.1 并列披露"声明 X / 内容判定 Y"，不判冲突 | 否 |

判定规则：

- 命中某族 → 按该族规则链执行（UAES → U-00、U-14；NIO → U-00～U-13；理想 → 链为空）。
- 签名不足（<2 项且无"页签 + 表头"组合）但可判属测量报告 → **警告 `W01`**：族未定，族特定规则项标「不可审」，**通用预检规则照判**。
- 签名与结构均无法判断是不是测量报告 → **阻断（M-01）**。

签名与绑定表：

| 判定特征 | 模板族 | 绑定审核规则链 | 族级口径 |
| --- | --- | --- | --- |
| 标题含「测量比较报告 / Measure Comparison Report」；或含 `F-PU-166`；含双方各 5 件对比区；含四方签字栏 | UAES_MCR | U-00、U-14 | 实测列＝绝对实测；无方向码；无 Centering/Range；无测点图 |
| 存在 `CoverSheet` 页签 + `Datum-` / `Gap&Flush-` 页签；列头含 `Measure data Part1～5`；含 Centering / Range 列 | NIO_DMR | U-00～U-13 | 实测列＝**偏差值**；方向码见 12.1（9 值）；类型 CC/SC/AC；最小样本 5 |

- 模板族必须写入报告，并说明**判定来源**与原文依据；同批含多族属正常，不得强行统一。
- **命中理想族（链为空）→ 非阻断**：该族 U-xx 记 `S02`（规则不适配），通用预检规则照判；**不得**判用户不通过，也**不得**默认为通过。

**族与客户的关系（v3.2 明确，最易混淆处）**：

模板族是**载体形态**，由文件内容签名判定；客户是**路由键**，由客户标识判定。两者是**两条独立线索**，本分则的三族当前与客户一一对应，但这一对应关系是**登记结果，不是判定依据**：

| 模板族（载体形态） | 对应客户条目 | 关系性质 |
| --- | --- | --- |
| UAES_MCR | UAES × `E02` 测量比较报告 | L1 命中，走 U-00 / U-14 链 |
| NIO_DMR | 蔚来 × `T01` 测量报告 | L1 命中，走 U-00~U-13 链 |
| LIXIANG_DMR | **无**（理想 `T01` 是全功能检验报告，归 01-1） | 族存在、条目缺位 → 族特定项 `S02` |
| UNKNOWN | — | 族未定，族特定项标「未执行」 |

**因此不得做的事**：

1. **不得由族反推客户**。签名为 LIXIANG_DMR 的文件不等于「客户是理想」——也可能是供应商借用了理想版式的自建模板。
2. **不得由客户反推族**。确定了客户是 UAES，仍需按 6.2 用内容签名定族；定不出族则族特定项标「未执行」，不得默认按 UAES_MCR 判。
3. **族与客户条目不一致时**，以**客户条目**为准确定判定源，以**族**为准确定字段位置，并在报告第十章并列披露「声明 X / 内容判定 Y」。

### 6.4 族级判定参数（内置常量）

### 6.5 检查需求映射

**6.5.1 列头容错**

列头识别判的是「**这一列是不是那个要素**」，不是「字面是否与字典一致」。真实模板的列头普遍存在三类偏差，**归一回字典即视为可识别**：

| 类型 | 例（实测） | 归一方式 |
| --- | --- | --- |
| 中英并列 / 桥接 | `名文值 Nominal`、`上公差 Upper Tol` | 剥离一侧语言后与字典比对，任一侧命中即算 |
| 明显笔误 | `测量伸差值`（应为「测量延伸差值」）、`Lewer Tol`（应为 `Lower Tol`） | 编辑距离 ≤1 且词长 ≥4，或命中形近字对照表 |
| 常规简写 | `NT` / `NOM` / `TOL` / `UCL` | 简写表归一 |

**判定口径**：

1. 归一后命中 → **列头可识别**，判据正常执行；同时记 **`W03`（写法不规范）**，写清「列头写法偏差，已按归一后语义判定」。
2. **不得因笔误判「列头不可识别」**——那是**取证方式错**，不是文件缺陷。把 `Lewer Tol` 判成 `B05` 列缺失，会让每一份用该模板的测量报告都阻断。
3. 同一列头在文件内出现 ≥2 种不同写法（如封面写 `Lewer Tol`、数据页写 `Lower Tol`）→ 另记 **`W03`（多写法并存）**，按 8.6 与第 1 条合并为一条，不重复计级。
4. 容错**不覆盖**语义错位：`实测值` 列被填成 `名义值`、`上公差` 列存 `下公差` 取值，属**取值层**问题，按原判据判（`B06` / `W03`），不得用「列头容错」放过。

> **实例**：页头写作 `名文值 Nominal`、`测量伸差值`、`Lewer Tol` 属明显笔误，归一后语义清晰（名义值 / 延伸差值 / 下公差），按本节记为**可识别 + `W03`**，不得判 `B05`。

### 6.6 第二级：三维度准入检查

**对识别结论为「是测量报告」的文件执行**；族未定或规则链为空只使族特定规则项不可审，**通用规则仍照判**。三个维度并列：

- **正确性**（7.3，C-01～C-17）：单个值本身是否科学、合理、符合基本逻辑（含伪定量、公差带派生、`0` 的合法性）。
- **完整性**（7.4，M-01～M-17）：规则所需信息是否存在、是否具备可追溯来源（含业务类型、双边双侧、示例行剔除）。
- **一致性**（7.5，S-01～S-19）：不同数据之间的关联关系是否成立（含复合字段拆分、状态承载、列映射唯一）。

**三维度并列，任一维度存在阻断即不通过。** 齐套不构成独立维度（7.10）。

### 6.7 汇总判定

1. 汇总所有发现：按 5.4 把范围外 / 规则不适配 / 移交事项移入状态登记；按 5.5 把能力缺口、份数差异移出计分。
2. 标注检查项编号、原因码、要素码、位置、证据链、影响、级别、责任侧、置信度。
3. 给出八层结论（5.8）。
4. 按 8.3 给出两级结论，并**限定在本批范围内**。
5. 不通过时列出阻断项与警告项，单列状态登记与能力缺口。
6. 按 7.10 逐条输出比对缺项警告；无此类规则则本节填"无"。
7. 输出本批构成陈述（7.9）：本批 N 件 / 其中属本类目 N 件 / 类目内应交 N 实交 M（仅陈述）/ 调用方声明是否提供（标注未核实）。**不输出「类目覆盖成立」或「缺件」**。

### 6.8 输出报告

按第 9 节模板输出。报告须明确：项目与批次（标注未核实）、本批构成陈述、运行前提、两级结论与原因码、拦截原因、模板族与判定来源、问题清单、状态登记、整改分派、局限性声明。结论为「未执行」时按 5.1 输出 5 节并附固定声明。

#### 7.6.2 复算式与容差

| 量 | 定义 | 容差 | 空值 / `0` 处理 |
| --- | --- | --- | --- |
| Centering | （−名义值 + 实测均值）÷ 公差带；偏差值语义下名义项为 0 | `1e-6` | 空样本排除；`0` 计入；名义值空按 0 |
| Range | （实测最大 − 实测最小）÷ 公差带 | `1e-6` | 同上 |
| 实测均值 | 逐件样本算术平均 | `5e-3` | 空样本排除；`0` 计入（须输出排除 0 的对照值） |
| 极差 Rng | 实测最大 − 实测最小（绝对值） | `5e-3` | 同上 |
| 公差带 | 上公差 − 下公差 | — | 任一为空或 NA 则不可算（C-03）；为 `0` 则该行无对象 |
| 合格率 | 合格行 ÷ 总行 | `1e-3` | 无阈值，仅判存在性（M-12） |

复算差异在容差内 → 不记问题；超出 → `W06` 警告；若导致无法比对（表内该格为空）→ `W05` 警告；若量级错误（符号相反、差 1000 倍）→ `B06` 阻断。

#### 7.6.3 空值与 `0` 的统计口径

- 空白样本：**不计入**均值 / 极差（沿用"空不计入"）。
- `0` 样本：**计入**均值 / 极差（与表内公式现状一致）。
- **风险必须量化输出**：凡检测到"以 `0` 填充空缺样本"的行，须同时输出「计入 0」与「排除 0」两个复算值及差异，作为 `W02` 警告（口径风险），**不判不通过**。

> 实例：样本 `[0.17, 0.17, 0, 0, 0]`、上公差 0.5 / 下公差 0 → 计入 0 时 Centering = 0.136（绿区）；排除 0 时 0.34（黄区）。口径选择直接改变业务结论，故须双值并列。

#### 7.6.4 派生字段的重算口径

派生字段一律按定义重算，**不采信表内值、不采信模板说明**（模板说明与表内公式都可能写错，只有定义可信）：

| 派生字段 | 定义 | 采信表内值 | 预检动作 |
| --- | --- | --- | --- |
| 公差带 `tol_band` | 上公差 − 下公差 | **否** | C-13 复算比对；为 `0` 时按 C-03 该行不判 |
| 均值 `stat_avg` | 逐件样本算术平均 | 否 | S-05 比对（`5e-3`） |
| 极差 `stat_range` | 逐件最大 − 最小（绝对值） | 否 | S-05 比对 |
| Centering | （−名义值 + 均值）÷ 公差带 | 否 | S-06 比对（`1e-6`） |
| Range | （最大 − 最小）÷ 公差带 | 否 | S-06 比对 |
| 差异率 `diff_pct` | （甲方实测 − 乙方实测）÷ 公差带 × 100% | 否 | 公差带 `0` 时该格应为空；有数值 → C-13；`#DIV/0!` → C-17 |
| 状态 `eval_status` | 由实测 vs 公差（单方）/ 差异率（双边）推出 | 否 | S-17：仅底色承载 → 阻断；与重算不符 → `S03` 移交 |

### 7.7 空值与占位符的分级判定

| 情形 | 级别 | 原因码 | 理由 |
| --- | --- | --- | --- |
| 承载位置不存在（无该页签 / 列 / 测点图 / 签字栏） | 阻断 | `B05` | 规则无承载位置 |
| 位置存在，整列 / 整页为空，且规则依赖该列逐行取值 | 阻断 | `B05` | 规则无法产出任何结论 |
| 位置存在，值为**占位符**（`0` 占位 / `XX` / `W0XX` / `pp` / `ABC` / `待填`） | 阻断 | `B05` | 值不可取得，等同未填 |
| 占位符但可由本批证据**唯一推断**真实值 | 警告 | `W02` | 可审，须标推断依据与置信度 |
| 位置存在，**判定依据列**值类型错误（`/`、`-`、文本） | 阻断 | `B05` | 该行不可计算 |
| 位置存在，**参考列**（坐标 / 方向）为脏值 | 警告 | `W03` | 可清洗为 NULL，不影响公差判定（C-16） |
| 合并单元格导致的**结构性空** | 不记 | — | 合并关系可还原即不算缺失（M-17） |
| 部分行为空，且规则能对空值给出明确结论（签字栏空白、类型列全空） | `S03` 移交 | — | 属审核结论 |
| 无适用行（方向码不含 ND/Gap/Flush **及其负向形式 ND-/Gap-/Flush-**） | 不记 | — | 无检查对象 |

- **`0` 与空白必须区别对待**：空白可能触发"排除该样本"；`0` 会被计入统计并拉偏均值。同文件内混用按 S-12 记 `W03`。
- **`0` 的合法性依赖字段类型**：元信息文本列的 `0` 多为占位；公差、偏差、**坐标、名义值**的 `0` 合法（车身坐标系中 `0` 是真实坐标，功能孔名义值常为 `0`），不得一刀切判占位。

### 7.10 比对规则识别与对端缺项提醒

**比对规则**指判定必须同时读取本文件与另一份材料才能给出结论的审核规则；唯一识别依据是该规则**声明了所需对端角色**（`compare_with[]` 非空），不由预检推断、不由文件名猜测。

| `compare_with[]` | 含义 | 预检行为 |
| --- | --- | --- |
| 空数组 | 单文件内即可判定 | 与齐套无关，**不检查、不提醒** |

常见对端角色（供规则集编写参考，取值以规则集为准）：同零件另一子类型报告、控制计划、图纸 / 数模、同零件历史批次报告——缺项后果均为"该比对规则本批不可执行"，级别为**警告**。

2. **没有 `compare_with[]` 依据的齐套缺失一律不得记警告**（含"三种报告只交了一种"），最多写入 10.1 份数陈述。

4. 对端件存在但不可用（如扫描件不可解析）→ 仍按对端缺项记 `W01`，同时按 5.5 记能力缺口，两者并存不重复计分。

| 3 | 缺报告单号视为元信息缺失 | 原表缺失时由系统生成唯一编号 | **不判**（S-18） |
| 4 | 测点号下空视为逐行必填缺失 | 同一测点测 X/Y/Z 时测点号垂直合并 | **不判缺失**，不可还原才警告（M-17） |

| 6 | 底色绿/黄/红即合格性结论 | 颜色与数值解耦；双边蓝/白/灰代表读写权限 | **不作判据**；仅底色承载 → 阻断（S-17）；蓝底行按锁定行剔除（M-16） |
| 7 | 双边报告无方向列视为缺列 | 方向融合在特性描述中（如 `Ø`、`Ra`） | **族差异，不判**（C-07 仅在方向列存在时判值域） |

本分则的两条 L1 条目共用 51 项判定规则（`C` / `M` / `S`），但**必备结构与必填字段不同**。本节只写差异，不改任何判定口径。

**五条执行纪律**：

1. **先定条目，再定族**。条目决定「该不该做内容级校验、用哪条链」；族决定「字段在哪儿」。顺序反了会拿 A 客户的字段位置去读 B 客户的文件。
2. **实测列语义不得跨条目混用**。UAES 是绝对实测、蔚来是偏差值，同一份文件只能落一条解释；一旦混用，全部派生指标失效——这是本类目最高频的误判来源。
3. **本节不新增级别与原因码**。上表所有落点均落在第 5.3 节既有码内。
4. **客户未在上表内** → 按总纲 4.8 落 L3，记 `S02`，**不得**退化为「按通用结构硬判」，也**不得**默认为通过。
5. **差异层与族签名冲突时**，字段位置以族为准、判定源以条目为准，冲突事实写第十章 10.6。

## 8. 严重级别与通过规则

### 8.1 严重级别

**只有两种级别。**

| 级别 | 定义 | 本类目典型情形 |
| --- | --- | --- |
| 阻断 | 至少一条审核规则**无法得出唯一结论**（取不到数，或结论方向不唯一） | 识别结论「判不出」；业务类型判不出（M-14）；双边缺一侧（M-15）；关键列缺失（M-04）；占位符残留（M-03）；测点图缺失（M-09）；签字区缺失（M-10）；判定依据列写成 `/`（C-01）；同源文件数值冲突（S-08）；`#REF!`（C-10）；测点号重复（C-05）；空白模板（M-06）；示例行/锁定行被当数据行（M-16）；公差带 ≠ 上−下（C-13）；属性特性整列填 `0`/`1`（C-14）；状态仅靠底色承载（S-17）；一列映射两字段（S-19） |
| 警告 | 判定仍可完成，但结果不完整或存在被误判风险 | 族无法由签名定（M-01②）；批内同零件重复（S-14）；占位符可唯一推断（M-03）；单行 Centering/Range 漏算（S-06）；均值舍入差（S-05）；样本数不足（M-07）；模板默认日期（C-08）；版本号恒 `0`（S-09）；空白与 `0` 混用（S-12）；文件名与表内不一致（S-03）；参考列脏值（C-16）；派生列除零（C-17）；属性特性个别行填 `0`/`1`（C-14）；定性值写法不一（C-15）；合并结构化空不可还原（M-17）；车型与阶段不可拆（S-16）；前导零丢失 / 日期格式（S-18）；对端件未提交（7.10） |

**五类状态、六个代码（`S01` / `S02` / `S03` / `S04-S` / `S04-C` / `S05`）不是级别**（`S05` 定义见总纲 3.1），不进本表，只进报告第六章状态登记表。用户能改的与属规则侧 / 属正式审核的必须分开列。

> **定级唯一判据**：这个问题是否让某条规则无法得出唯一结论（总纲 8.1）。与"是否严重""是否合规""整改成本多高"无关。

### 8.2 准入要件 A1～A6

第一级已确认"这是测量报告"，本节回答**它够不够格进入深度审核**。六项按作用分三组：**A1 决定要不要启动、A2 决定能判多少、A3～A6 决定能不能进**。

| 要件 | 满足的标准 | 判定依据 | 不满足时 | 谁能整改 |
| --- | --- | --- | --- | --- |
| **A1 归属确定** | 识别结论为「是测量报告」，且文档形态可判 | 2.1 D1～D4、2.2 R1～R5 | 判不出 → **不通过（M-01 `B03`/`B01`）**；不是 → `S01` 范围外 | 提交方 / 解析侧 |
| **A2 族可识别** | 模板族可由**内容签名**落位（≥2 项，或页签 + 表头组合） | 6.2、2.3 | **警告 `W01`**（族未定），**不阻断**：通用预检规则照判，族特定规则项标「不可审」 | 材料侧 |
| **A3 业务类型确定** | 单方 / 双边可判；双边时两侧实测与程序、测量员、日期、样本列齐备 | M-14、M-15（6.3） | **不通过（`B04` / `B05`）** | 材料侧 |
| **A4 判定三要素齐备** | ① 特性清单（测点号 + 特性描述）② 公差参照（名义值 + 上/下公差或公差带）③ 逐件实测值——三者同时可读、可定位 | M-04、M-08、C-01、C-03 | **不通过（`B05`）** | 材料侧 |
| **A5 值可信** | 无占位符残留、无公式错误值、派生值可复算且一致、无伪定量冒充实测值 | M-03、M-06、C-10、C-13、C-14、S-11 | **不通过（`B05` / `B06`）** | 材料侧 |
| **A6 证据自洽** | 同源双形态、批内多文件、图文标注、派生列、列映射五处不冲突 | S-01～S-08、S-14、S-19 | **不通过（`B06` / `B02`）** | 材料侧 / 提交方 |

**原 A2 中的「规则链非空、六项族级参数齐备」已整段退出**（规则侧，总纲 2.3）：前者现象记 `S02`，后者改为内置常量（7.6.1）。因此 A2 现在只剩「族可识别」一个判据，且**不满足时只记警告**。

**A4 判定细则**：

- 三要素中**任一整体缺失** → 一律阻断（缺列 M-04、只有统计列 M-08、判定依据列写成 `/` C-01、整表公差带不可算 C-03）。
- **单行公差带为 `0`** 不算 A4 不满足——那是该行无判定对象（C-03），整表可算即通过 A4。**不得把"个别行不可算"升级为"整份不可审"**。
- **属性型特性**（通止规、公差带为 0 的定性判断）不要求"实测值"，但要求"定性值"承载；其数值化填写按 C-14 处理。

**A5 与 A4 的分界**：A4 判"有没有"，A5 判"能不能信"。有名义值、有公差、有实测值，但实测值全是 `0` 占位 → A4 通过、A5 不通过。

### 8.3 通过规则

无阻断即通过，存在任一阻断即不通过并给出原因码；警告不影响结论但须 100% 列报并移交；状态项不参与判定但不得略去不记（总纲 8.2 / 8.3）。

本分则补充：判定顺序见 5.2（门① → 文件级定级，取第一命中项）；**不得用「部分文件属其他类目」放过已知阻断**——只要有一处材料侧阻断，结论就是不通过；移交预判、份数陈述、能力缺口、范围外文件四项不参与判定，对端缺项按 `W01` 参与警告记录但不拦结论。

### 8.4 定级优先级与去重

同一发现可命中多条规则时，按以下顺序定级，**不重复计分**：

1. 结构性缺失优先于内容缺失。
2. 值不可取得优先于值不规范。
3. 无法判定优先于判定不满足。
4. 同一原因引发的多处表现只计一条（如"空白模板"同时导致公差带为 0、统计列为空 → 只记 M-06）。
5. 跨层重复时记在最靠近根因的层。
6. **级别取各条款明示值与其调整条件**；同一规则内已分档的（C-06、C-14、M-12）按命中档位取级别。
7. **同一字段的双重缺失只记一条**：M-07 与 S-10、M-14 与 M-15 按第 4 条合并。
8. **禁止降级**：某类问题在全批次普遍存在，不得因其普遍性而降低级别；须注明"该问题在本批次普遍存在，属系统性缺口，非个别疏漏"。
9. **允许的调整**：警告 → 阻断（该警告直接导致下游规则完全无法计算）；阻断 → 警告（存在同源替代载体，须注明位置）；任何级别 → `S01`/`S02`/`S03`（须记录确认来源）。

## 11. 执行要求与约束

1. **先识别，后检查**：逐文件识别结论未给出前，不得进入任何 C / M / S 检查——识别错会导致整页伪缺陷。
2. 不跳过**门①（有无本类目文件）**、模板族识别、三维度检查（判「未执行」时终止于门①）。

4. **不评价规则、不评价字典、不评价口径**：不得输出任何关于规则集状态、规则链、族级参数、字典版本的问题或结论（总纲 2.3）。

6. 正确性优先依据字段类型、公差方向、量级、值域；完整性必须做占位符检测并按 7.7 区分 `0` 的字段含义；公式引用结果须回溯源单元格。
7. 一致性不预设关联键，须自主推断并把推断依据写入证据链；三维度并列，任一维度存在阻断即不通过。
8. 采用相对严格标准，但对"无适用行"必须判空过（不记任何问题）。
9. 遵守 5.3 原因码与 5.4 状态口径：**不出现「不适用」字样**，按 `S01`/`S02`/`S03`/`S04-S`/`S04-C` 表述。

21. **派生字段一律按定义重算**，不采信表内缓存值与模板说明。
22. **必须执行 7.11 的八项判定修正**。
23. **字段键与要素码双向可对**：每条问题须同时给出字典字段键与要素码；且必须能定位到具体文件与位置。
24. **警告必须 100% 列报**，不得省略、合并、概括；报告第八章局限性声明须逐字保留。
25. 遵守 12.4「不要做 / 不要画」清单。

### 12.4 不要做 / 不要画

**不要做**

1. 不要跨模板族套用规则链——正确结论是"该族无规则链 → `S02`"。
2. 不要把「测点级别 A/B」映射为「类型 CC/SC/AC」；二者语义无关。
3. 不要把「极差 Rng（绝对值）」当作「Range（极差 ÷ 公差带）」。
4. 不要混用实测列语义——NIO 是偏差值、理想/UAES 是绝对实测。
5. 不要用「字段非空」代替「字段有效」；必须做占位符检测并按字段类型区分 `0`。
6. 不要采信公式引用出来的 `0` 或常数；须回溯源单元格（S-11）。
7. 不要代替正式审核下合规结论（超差、阈值、签字、类型值域、合格率），一律记 `S03`。
8. 不要对 MSA / SPC 类文档做本规则任何检查；不要用 Centering / Range 推断过程能力；不要把"逐件 ≥5 件"当 MSA 重复测量次数；不要把"检具号有值"当作"检具合格"。
9. 不要臆造不存在的页签或列（NIO 实例中"测量报告页"对应 `Datum-001` / `Gap&Flush-00x`）。
10. 不要在无适用行时判不通过（方向码不含 ND/Gap/Flush **及其负向形式**）。
11. 不要因 PDF 里有数字就声称完成复算。
12. 不要修改原始文件；不要给出超出规则的结论（如"合格率 97% 不达标"）。
13. 不要把「空白」与 `0` 混为一谈；不要把"空白模板"当作"字段缺失"。
14. 不要把「本批未见」写成「缺失」；不要以 `scope`、必备清单或份数判阻断。
15. 不要把调用方声明当作事实；`scope`、必备清单、项目阶段一律标注「未核实」，不得用于判定。
16. 不要重新评审规则文本、规则集状态、字典版本或判定口径——一律不在预检范围内（总纲 2.3）。
17. 不要把「未执行」写成「通过」或「不通过」；未执行须附"未对任何文件出具判定"声明。
18. 不要因三种报告没交齐就判不通过或判阻断；不要在没有 `compare_with[]` 依据时推断"应该还有一份"。
19. 不要把有 `compare_with[]` 依据的齐套缺项升级为阻断（记 `W01` 警告）。
20. 不要回退为"当场解析规则原文"执行。
21. 不要把坐标或名义值的 `0` 当占位；不要因缺报告单号判元信息缺失。
22. 不要把合并单元格下空当作逐行必填缺失；不要把派生列 `#DIV/0!` 判成阻断。
23. 不要用单元格底色判合格 / 不合格（状态须有独立文本或数值承载）。
24. 不要把示例行 / 锁定行算进数据行；不要把属性特性填的 `1.0` 当实测值。
25. 不要采信模板说明里的公式（样本3 说明文档把公差带误写为 `F17+G17`）。
26. 不要要求单方报告给出双方差异率，也不要要求双边报告给出 Centering。
27. 不要把字段落库、宽表转长表、布局探针写进判定项。
28. 不要把检查项前缀与成因类别对应起来（`C-16` 是维度编号，`V 类` 已废止）；不要由成因反推级别。
29. 不要把规则集自己的字段名、键路径或存储结构写进判定依据——判定条件必须是「某个事实是否成立」，不是「某个键有没有值」。
30. 不要把「不适用」写进报告；按 `S01` / `S02` / `S03` / `S04-S` / `S04-C` / `S05` 五类状态表述（`S05` 定义与边界见总纲 3.1 / 3.3）。
31. 不要用模板族签名判断"是不是测量报告"；不要把「是但族未定」与「不是测量报告」混为一类（处置相反）。
32. 不要把"检验记录"当测量报告审；不要跳过识别直接查列。
33. 不要用"没有阻断"代替"数据无问题"——结论只写「通过预检」，不得写「合格」「无问题」。
34. 不要把警告项省略、合并或概括为「其余若干」；警告必须 100% 列报。
35. 不要因执行方无视觉能力而把该项判成材料侧问题（应标注「未执行」，见 4.4）。

**不要画**

1. 不要画数据流图、系统架构图——本规则交付判定，不是系统设计。
2. 不要画趋势图、雷达图、箱线图描述测量数据——样本量 2～5 件且分属不同零件，作图无统计意义。
3. 不要画控制图或过程能力图——那属 SPC（PPAP-07）范畴。
4. 不要画合格率仪表盘——规则未定义合格率阈值，画出即暗示存在结论。
5. 不要为测点图绘制示意图——必须使用客户原件，重绘会造成图文不一致。
6. 不要用颜色编码替代文字判定——红/黄/绿在不同族含义不同，混用会误导。
