## 1. 目的与边界

**目的**：判定这份 PSW **是否具备可被对应客户审核的保证书结构**——字段是否齐、选项组是否单选、签署与印章是否成立、按所选认可结论应联动的项是否联动。

**为什么两家共用一份分则**：PSW 是同一份国际通行的提交文件，两家模板同源，差异集中在**签章规则**与**认可结论的联动要求**上。按字典号归并、差异放进 §7，与 `PPAP-T09` / `PPAP-T12` 处理一致。

**两家差异是实质性的，不可互换判据**：

| 维度 | UAES（`U17`） | 理想（`L17`） |
| --- | --- | --- |
| 签章要求 | 「供方代表签字」须为**手写签** + 文件含**印章** | 印章末两字须为「**公司**」；否则须附「部门章授权声明」表且表内有公司章 |
| 身份字段组 | 零件名称 / 客户零件号 / 图纸号 / 供应商零件号 / 工程更改级别 / 日期 / 其他工程更改 / 日期（8 项） | **15 项**，另含重量(kg)、街道地址、城市、省、国家、顾客名称、设计开发、采购工程、PTC 等 |
| 重量字段 | 不要求 | **要求，且须保留小数点后四位** |
| 交付物清单 | 不要求 | **要求**（同批依赖，`W01`） |
| 认可结论联动 | 无 | **要求**：勾「批准」须四项提交结果全勾；勾「条件批准」须 3 个月内 + 补充评论非空 |
| 选项组 | 安全及政府条例、材料信息、提交原因、提交等级（4 组） | 提交原因、认可情况（2 组） |
| 判据数 | 10 | 12 |

**边界三条**：

1. 本类目**不判实测值**，故不产生 `B06`；判日期时效（条件批准 3 个月），落 `W06`。
2. 理想**有跨文件依赖**（交付物文件清单），缺对端一律 `W01`，**不阻断**。**此处不产生 `S04`**——本分则判定源为 L2（总纲 4.7），只判结构存在性与必填性、**不做跨文件一致性判定**，故无「受阻判定项」；`W01` 为缺件提示。升为 L1 后须按总纲 3.2.4 补 `S04-S` / `S04-C`。
3. 客户差异层互不生效——报告须写明命中的是哪一条路由。

**UAES 为何选项组判 `W02` 而非 `B05`**：选项组存在、只是没勾或勾了多个——结构在、值不对，属「有结构无值 / 取值冲突」，按总纲 7.2 落 `W02`。

**5.2 选项组「有且仅有一项」的判定**

适用于 `U17-S2`、`U17-S6`、`U17-S10`、`L17-S9`：

| 勾选状态 | 判定 | 说明 |
| --- | --- | --- |
| 恰好 1 项被勾 | 通过 | — |
| 0 项被勾 | `W02` | 缺值 |
| ≥2 项被勾 | `W02` | 多选冲突（单选组不允许） |
| 勾选状态不可辨 | `W02` + `W05` | `W05` 记解析侧 |

**多选为何不判 `B05`**：选项组结构在、可读、规则可定位，多选是**取值冲突**，供应商改正即可。判 `B05` 会把一个可整改的填表错误升级为结构缺失。

**5.3 勾选三态与责任归属**

| 判读结果 | 判定 | 责任侧 |
| --- | --- | --- |
| 已勾选 | 按对应判据 | — |
| 明确未勾选（有框无勾） | `W02` | 材料侧 |
| 无法判读（扫描模糊 / 图形缺失） | `W02` + `W05` | 解析侧（`W05`） |
| 无勾选框结构（纯文字） | `W02` | 材料侧 |

**「无法判读」不得一律记为「未勾选」**：前者是解析问题，后者是材料问题，整改责任不同。

**5.4 UAES S8 手写签与印章的判定**

| 项 | 通过条件 | 不满足 |
| --- | --- | --- |
| 字段存在 | 「供方代表签字」字段在 | 缺 → `B05` |
| 手写形态 | 笔画粗细不均、有连笔或压感差异；**非**印刷体、**非**打字输入 | 印刷体 / 空白 / 打字 → `W03` |
| 印章 | 图像层存在印章图形（红 / 蓝 / 黑套印） | 无印章 → `W03` |

**「手写」只判形态，不判是谁签的、是否有授权**——后者属 `S03`。

**5.5 理想 S3 / S4 印章「末两字为公司」的判定**

1. 先判有无印章（无 → `W03`，S4 不生效）。
2. 印章文字可读时，取**文字末两字**：
   - 为「公司」→ S3 通过，**S4 不生效**。
   - 非「公司」（如「…质量部」「…技术部」）→ S4 生效，须存在「部门章授权声明」表且表内有公司章。
3. 印章文字**不可读** → 记 `W05`，S3 / S4 均记「无法判定」，**不记 `W03`**。
4. S4 的「表内有公司章」须实际检测表内图像层，**不得**仅凭表标题存在就判通过。

**5.6 理想 S1 同批依赖的处理（总纲 10.5）**

1. 建组键：**（客户 × 零件号）**。
2. 先在本批次内找对端《生产件批准交付物文件清单》；找到 → 逐行判「附件」列非空。
3. **未找到 → `W01`，写明「缺比对文件《生产件批准交付物文件清单》」，不阻断**（总纲 10.5、00-A §4.1）。
4. 行范围：**排除「零件认证相关行」**（该行允许附件为空）。
5. 对端存在但零件号不一致 → 视为未找到，记 `W01` 并写明不一致的具体值。
6. **不得**因缺对端而把 S2~S12 一并判缺失。

**5.7 理想 S7 的「15 字段」与 S1 的重叠说明**

S7 列举的 15 项中含「供应商名称/供应商代码」「重量(kg)」，这两项同时被 S5（格式）与 S2（重量格式）覆盖。处理规则：

1. **存在性 + 非空**由 S7 判（缺 → `B05`、空 → `W02`）。
2. **格式**由 S5 / S2 判（`W03`）。
3. **同一问题不重复计**：字段缺失只在 S7 记一次 `B05`，S2 / S5 记「字段缺失，无法判定格式」。

**5.8 理想 S11 「3 个月内」的口径**

1. 当前日期 = **预检执行日**，须在报告 10.2 写明。
2. 取「文件右下角日期」为条件批准日。
3. 判定：条件批准日 ≥ 当前日期 − 3 个月 → 通过；否则 `W06`。
4. 日期不可解析 → 记 `W03`（写法不规范），**不记 `W06`**。
5. 右下角日期缺失 → `W02`。

**5.9 客户差异层切换时的兜底**

若识别出的客户不在 UAES / 理想两家之内，**不得**按任一家判定——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（UAES 或 理想, PSW），置信度 ≥ 中 | 路由 = `U17` / `L17` |
| 2 | **按路由锁定判定项集**（§4.1 / §4.2），另一组不生效 | 生效判据清单 |
| 3 | 判「字段类」：UAES `S1`、`S4`、`S5`、`S7`；理想 `S7`、`S2` | `B05` / `W02` |

| 5 | 判「选项组类」：UAES `S2`、`S6`、`S9`、`S10`；理想 `S8`、`S9`（§5.2 / §5.3） | `W02` |
| 6 | 判「签章类」：UAES `S8`；理想 `S3`、`S4`、`S5`、`S6`（§5.4 / §5.5） | `W03` |

## 7. 客户差异层

### 7.1 两家差异对照（判据不可互换）

| 维度 | UAES（`U17`） | 理想（`L17`） |
| --- | --- | --- |
| 身份字段 | 8 项（零件名称 / 客户零件号 / 图纸号 / 供应商零件号 / 工程更改级别 / 日期 / 其他工程更改 / 日期） | **15 项**（另含重量、地址四段、顾客名称、设计开发、采购工程、PTC 等） |
| 重量字段 | 不要求 | **要求 4 位小数** |
| 区域划分 | 供方制造厂资料 / 买方资料 | 无此分区（用平铺字段） |
| 选项组 | 安全及政府条例、材料信息、提交原因、提交等级（4 组） | 提交原因、认可情况（2 组） |
| 签字要求 | **手写形态** | 未要求手写（只要求存在） |
| 印章要求 | 有印章即可 | **印章末两字须为「公司」**，否则须附部门章授权声明 |
| 交付物清单 | 不要求 | **要求**（同批依赖，`W01`） |
| 结论联动 | 无 | **有**：批准 → 四项结果全勾；条件批准 → 3 个月内 + 补充评论非空 |
| 判据数 | 10 | 12 |
| 受控章 | 不要求 | 不要求 |

### 7.2 三条硬约束

1. **签章规则不可互换**：UAES 判「手写 + 有章」，理想判「章末两字为公司」。把 UAES 的手写要求套到理想是加严；把理想的「公司」二字要求套到 UAES 也是加严。
2. **字段清单不可合并**：理想 15 项远多于 UAES 8 项。判 UAES 时要求「街道地址 / 城市 / 省 / 国家 / PTC」是加严。
3. **结论联动只对理想生效**：UAES 无「认可情况」选项组，不得因 S10~S12 而要求 UAES 提供提交结果勾选。

### 7.3 预留位

新增客户时在本表加行，并同步在 00-A §1 / §2 登记。客户差异**只允许增删判定项、调整必填范围**，不得改本分则 §5 的通用细则。

## 10. 不要做

1. **不要跨客户套用判据**（§7.2）。
2. 不要要求 UAES 提供 15 个字段（§7.2 第 2 条）。
3. 不要要求理想提供手写签名（UAES 的判据，§7.2 第 1 条）。
4. 不要要求 UAES 提供「认可情况」选项组与提交结果勾选（§7.2 第 3 条）。
5. 不要在未确定认可结论时判 `L17-S10`~`S12`（§6 第 7 步）。
6. 不要在未勾「批准」时判 S10、未勾「条件批准」时判 S11 / S12——记「本结论不适用」。
7. 不要因条件批准超期就判整份文件不通过——记 `W06`（§4.2 末段）。
8. 不要把多选记成 `B05`——单选组多选是 `W02`（§5.2 末段）。
9. 不要用「无法判读」代替「未勾选」，反之亦然（§5.3）。
10. 不要仅凭「部门章授权声明」表标题存在就判 S4 通过——须检测表内是否有公司章（§5.5 第 4 项）。
11. 不要判是谁签的字、是否有授权——那是 `S03`（§5.4 末段）。
12. 不要因缺《生产件批准交付物文件清单》而把其它判据一并判缺失（§5.6 第 6 项）。
13. 不要在 S7 与 S2 / S5 之间重复计同一个字段缺失（§5.7 第 3 项）。
14. 不要在未锁定路由时开始判据（§6 第 2 步）。
15. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
16. 不要在报告里出现「疑似」「可能」类未定级表述。
17. 不要新增章、调整章序或自定义报告字段。
18. 不要修改 `00-A §2.1 / §2.2` 的判据文本；判据有误应先改 00-A，再同步本分则。
