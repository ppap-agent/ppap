# 实验室资质证书 — 数据标准化预检规则

> 版本：v2.7
> 定位：正式业务规则审核前的输入质量门禁。
> 核心原则：**预检只判定「这批证书能否被可靠审核」，不判定「证书是否合规」。无阻断项即通过；警告不拦截，仅记录并随报告移交正式审核。** 每次调用独立判定，仅检查、判定和报告，不执行修复。
> 上位框架：《PPAP-00_数据标准化预检总纲_v0.14.md》，配套《PPAP-00-A 覆盖矩阵 · 路由表 v1.7》。本文件为其分则，二者冲突时以总纲为准。
> **路由前提**：先按总纲 4.5 定（客户 × 文件类型），再加载本分则。本分则只承载 **UAES × 实验室资质证书（`E04`）** 一条条目（**扩展类**，不在核心 17 类内）；其他客户同类型规则未提供 → 落 L3（总纲 4.8），记 `S02`（见 7.6）。
> 编制依据：UAES《实验室资质证书审核规则》（已解析定型，其判据固化于 4.1.1）；总纲 v0.6（级别体系、结论档位、状态词、责任归属、识别与路由）。

**运行前提**

1. 两段式运行：规则已在规则入口定型；进入本预检时判据已定型，**本预检不接收规则文件实体，不评判规则本身，不核验规则集可用性**。原「口径是否随规则集齐备下发」类校验按总纲 2.3 整项退出。
2. 受检对象是本次提交的本类目证书；项目级文件集仅作 L1/L2 的检索范围（D3）。

据此确定两条纪律：不判断"项目下应有但本次未交"；不裁决规则本身。**不设「可整改性校验」**——警告不拦截放行，无法整改的问题记警告即不再打回，不存在死锁（见 8.3 原则 7）。

## 1. 目的与定位

### 1.1 本域特征

证书通常 1～2 页，判据只有 3 个字段（截止日期、CNAS 标识、标题关键词）。**主要风险不在"数据写错"，而在"读不到 / 读错位"**：载体以整页扫描位图为主，常嵌数十个 1-bit "CNAS" 水印蒙版，大量证书无文本层（抽取返回 0 字符属常态）。

本域三类 NG 的归属：读取 / 定位失败由本预检拦为「文件无法解析」或「关键字段不可获得」；确实不符合归正式审核层（边界见 2.3）；L1/L2 归联动人工处置，先按 D5 判是否适用。

### 1.2 三层结构

预检（本规则）判"证书能否读、判据字段能否定位"，输出通过 / 不通过；正式审核判 C1～C5 满足性；L1/L2 归联动人工处置，先按 D5 判是否适用。状态登记（`S01` / `S03` / `S04-S` / `S04-C`）贯穿三层，定义见 8.1。

### 1.3 核心目的

核心目的、非目标与三维度口径见总纲第 1、2、7 节。本域的具体落点：在正式审核前拦截「读不到、定位不到、证据不足」的输入（读不到 / 定位不到归本预检，确属不符合归正式审核，边界见 2.3）。

## 2. 范围与非目标

### 2.1 范围内

- 接收本次提交的本类目证书集、文件清单、客户要求清单（D5 依据）。
- 以受检对象执行正确性、完整性、一致性检查，每个判据字段的实际版面锚点须写入证据链；项目级文件集仅在 L1/L2 中作检索范围。
- 自主推断跨文件关联项，重点为"资质实验室 ↔ 经 D5 纳入的试验报告出具机构"；判定 L1/L2 是否适用，适用时检查比对信息是否可获得。
- 区分"数据不规范"与"文件无法解析"，输出含状态登记章节的 Markdown 报告，给出文件级、预检项级、规则项级、文件集级四层结论。

### 2.2 非目标

- 不判定证书是否过期（属 C2）、CNAS 标识是否合规有效（属 C3）、标题是否满足规则（属 C4）、报告机构与实验室是否一致（属 L2 人工比对）。
- **不评判规则本身**：规则口径、规则集完整性、规则与字典的一致性均在规则入口处理。本预检只按 4.1.1 固化判据执行，发现执行不了时不登记规则侧问题、不自行补定义。
- 不判断"项目下应有但本次未交"：本次提交范围即判定边界，不得据"某类 0 份"下缺件阻断结论。
- 不以认可范围附件缺失为由判不通过（该情形记 `S01` 状态）。
- 不判定证书真伪，不到 CNAS 官网核验注册号。
- 不负责 OCR、版面分析、图像增强等底层实现，不规定解析工具（识别通道与分辨率须声明，见 4.3）。
- 不修复、不补全、不转换原始文件，不代填字段；不执行整改后复检；不输出程序可直接消费的 JSON Schema。

### 2.3 与正式规则审核的边界

| 判据 | 正式审核判定 | 预检只检查 | 预检不通过处置 | 预检通过后仍可能审核 NG |
| --- | --- | --- | --- | --- |
| C1 文件存在性 | 是否为规则所指的实验室资质证书 | 可访问、可打开、非空 | 打回补交 | 提交 CMA 认定证书而非 CNAS 认可证书 |
| C2 有效期 | `截止日期 > 当前日期` | 字段存在、可读；日期合法；生效 < 截止 | 打回补清晰版 / 补有效期页 | 字段清晰但确已过期 |
| C3 CNAS 标识 | 页面是否含 CNAS 标识 | 是否有可辨识图形印记，能区分 CNAS 与 ilac-MRA | 打回补清晰版 | LOGO 清晰但非本证书（需人工） |
| C4 标题关键词 | 标题是否含 13 字机构全称 | 标题行可定位、13 字可逐字读出 | 打回补清晰版 | 13 字可读但出现在页脚 |
| C5 可辨识性 | 由本预检提供结论（审核前置闸门） | 判据字段区域存在字符且可复原 | 阻断 | — |
| L1 联动 | — | 项目级检索是否完整、归属过滤是否可判定 | 适用但无法判定 → 警告 | — |
| L2 联动 | 出具机构与资质实验室是否一致（人工） | 实验室名称、报告出具机构是否可获得 | 适用但信息缺失 → 警告 | 二者确实不一致 → 人工判定 |

预检记录"能不能判"，审核出具"符不符合"；同一现象可能被两层同时记录，定性不同，报告中须分开表述。"不存在 / 不可辨识"结论须附已穷尽的定位范围，否则只能记「文件无法解析」（8.3 原则 2）。

### 3.1 状态词：四个必须区分的概念

**「不适用」一词禁用**，必须按总纲 3.1 拆分为四种之一。四者是**状态**，不是级别，不参与通过判定。

| 状态 | 代码 | 本域形态 |
| --- | --- | --- |
| 范围外 | `S01` | 该对象**本就不属**本次提交范围：不属于本类目的资质文件（CMA 认定、ISO 17025 自声明）。判据与「交没交」无关 |
| 对端未到 | `S04` | 属本次范围、**在可及证据集内不存在**（总纲 3.2.1）：本批未提交本类目证书、认可范围附件声明随附而未随附（原 A-01）。**分两子型**：`src=SUB`（证书与附件均可由提交方自行取得）→ `W01` + **`S04-S`**；`src=CUS`（仅由客户持有的批准 / 会签记录）→ 仅 **`S04-C`**、不配 `W01` |
| 规则不适配 | `S02` | 规则侧成因导致某项在本域无判定依据（预检不评，本版已无此类来源） |
| 移交 | `S03` | 报告出具机构一致性比对（原 A-02）、报告签发日与证书有效期时间窗（原 A-03）、有效期状态（原 A-04）——均属正式审核或人工判定，预检只登记 |

**关键区分：**

- 「范围外」≠「文件不含该对象」。前者是该对象本就不属本次范围，后者是交了但证书里没有这个字段。
- **「本批没交」不再等于「范围外」**：属本次范围而应收未到记 `S04`（对端未到，配套 `W01`），`S01` 只留给「本就不属本次范围」（总纲 3.1）。
- **`S04` 分两子型，判前必先核「可及证据集」（总纲 3.2，v0.7 新增）**：对端在 `SRC-1`（提交件）或 `SRC-2`（受控提供源：客户图纸、技术规范、客户表单模板、客户侧台账）内**已存在**的 → **正常比对，绝不记 `S04`**。集内确实没有时按 `src` 落码：`src=SUB`（提交方能自行补出）→ `W01` + **`S04-S`**；`src=CUS`（只能向甲方索取）→ 仅 **`S04-C`**、**禁配 `W01`**、不进缺件数、进报告七章 7.2b。`src` 一律查《PPAP-00-A》**§4.3 对端来源登记表**，查不到记 `S02` 并报缺口，**不得现场推定**。**本分则全文凡记 `S04` 之处，一律按本子型标注。**
- **`S05`（受控模板缺结构）继承总纲**：本分则凡判 `B05` 之处，须先按总纲 **3.1 三分界**与 **5.2 两问**确认成因——查《PPAP-00-A》**§4.4 客户受控模板登记表**：该（客户 × 类型）登记**有**受控模板、且**模板本体也没有该列** → 记 **`S05`**（状态，**不阻断**、不配 `B`/`W` 码、不进缺件数、进报告七章 **7.2c**）；登记**无**（不限定表单格式）或**模板有而文件没有** → 仍记 `B05`。**本分则的 3.1 状态词表不列 `S05`**——它的定义、边界与取证要求只在总纲 3.1 / 3.3 / 5.2 维护，避免同一概念在多处分别表述。**`B`/`W` 原因码取值与判定严格程度逐字未改。**　**枚举优先级**：本分则凡用列举方式写状态码的地方——**判定结果取值、状态登记清单、六章装填白名单、「必须按 3.1 拆为…」之类的执行要求**——`S05` **都在其列**（分「已核对」/「待核」两种形态）。**若某处枚举文本仍只列到 `S04-C`，以本条为准**，不得因该处漏列而拒绝登记 `S05`。理由：v0.9 把 `S05` 加进总纲 3.1 之后，各分则的枚举没有同步扩，若按枚举字面执行，`S05` 会**有判据、无落点**——判出来了却装不进状态登记清单，等于这一档不存在。
- 「文件不含该对象」（如证书版式本身无授权签字人栏）**是材料侧问题，记 `W01` 警告**（见 7.2），不得记 `S01` 或 `S02`。
- 「规则不适配」只用于规则侧成因。本版已无规则侧来源，保留代码仅为跨分则一致性。

## 4. 输入契约

### 4.1 必选输入

#### 4.1.1 固化判据（源自绑定规则集，预检直接执行）

本预检不接收原始规则文档，亦不接收规则集可用性报告。以下判据为已定型口径，逐条执行，不重议、不补定义。

| 判据 | 原子判据定义 | 原文关键表述 | 判据性质 |
| --- | --- | --- | --- |
| C1 | 实验室资质证书文件存在 | "有此文件……即可" | 存在性 |
| C2 | 截止日期 > 当前日期 | "文件中的截止日期＞当前日期；截止日期≤当前日期则不通过" | 阈值比较 |
| C3 | 页面含 CNAS 标识 | "文件中包含CNAS标识……缺一项则不通过" | 要素存在性 |
| C4 | 标题含机构全称 13 字 | "标题中包含'中国合格评定国家认可委员会'……缺一项则不通过" | 字符串匹配 |
| C5 | 证书整体可辨识 | "如果资质证书无法辨识则不通过，同时判定依据需提醒用户进行人工复核" | 前置闸门 |
| L1 | 项目级检索范围内存在《零部件设计验证报告》独立文件 → 判定依据中须提醒比对测试机构（检索按 D3、纳入按 D5） | "注意识别同批次提交的文件集中是否有零部件设计验证报告独立文件……" | 提示触发 |
| L2 | 存在试验报告（材料、性能等）→ 须人工比对出具机构与资质实验室是否一致 | "需人工比对一下测试机构，与提交资质的实验室是否一致" | 人工比对 |

#### 4.1.2 受检对象（本次提交的本类目证书）

- 常见形态：PDF 整页扫描件（无文本层、含水印蒙版）、文本型电子证书、同证书中英文双版、扫描件与截图混排。
- 单份通常 1～2 页（证书主页）；认可范围附件可达数十页且多为表格。
- 受检对象只含本类目证书；L1/L2 检索范围另按项目级取全集（D3）。仅取"本次对话中附带的文件"既不构成受检对象，也不构成合格检索范围。

#### 4.1.3 文件清单

- 用于确认受检对象的范围与数量，核对缺失、多出、命名不符。
- 清单格式不限定；无清单时以提交目录整体代替，并在报告中声明。

#### 4.1.4 客户要求清单（D5 判定依据）

- 用于判定 L1/L2 在当前项目下是否适用，须能回答"该客户本次 PPAP 要求范围是否包含实验室资质审核"。
- 无法获得时须向用户显式确认，不得默认"有要求"或"无要求"。

### 4.2 可选输入

- 字段别名与承载位置映射表：本域实例化为 14.2，与 7.3（一致性关联键清单）并列。

### 4.3 解析责任边界与能力前提

- OCR、版面分析、图像增强、印章/LOGO 判读由外部业务系统或模型层负责；本预检不规定是否使用 OCR 及引擎选型，但必须在报告中声明识别通道与分辨率。
- 本域强制要求：文本层字符数为 0 或显著低于版面可见文字量时，必须转视觉渲染通道（整页 ≥200 dpi，判据条带 ≥300 dpi），不得以"文本层为空"判"文件空白 / 不可辨识"。
- 穷尽上述手段后仍无法获得可判定证据，记录为「文件无法解析」，不得跳过检查、不得推断为缺失。
- **能力前提**：执行方不具备视觉通道时（如仅有纯文本解析能力），本域的 P-02、P-06、P-10、P-11 无法执行。此情形在报告"未进行的检查"栏声明，标「未执行」，**不记级别、不判供应商责任**——能力不足不是文件缺陷。

规则侧三项（可加载、条目覆盖、口径齐备）已随规则入口退出，此处只核验与受检对象的适配。

| 核验项 | 通过条件 | 不通过处置 |
| --- | --- | --- |
| 类型适配 | 受检对象确为 CNAS 实验室认可证书（据锚点 ② 与 ⑥ 判定） | 非本类目资质文件（CMA 认定、ISO 17025 自声明）记 `S01` 范围外并剔除；**若本类目下无任何 CNAS 证书**，另记 `W01` 警告（本批未识别到本类目证书），避免"交错件"被判通过 |

### 4.5 证据封闭性

判定证据须落在**可及证据集**内（`SRC-1` 提交件 ∪ `SRC-2` 受控提供源，总纲 3.2.1 / 4.4）；提交范围声明、项目上下文、应有件清单只能用于**排除**，不能用于**推定应有**。**不得因「应该有但没交」判缺件阻断**；缺项按两条通道分流——跨文件对端缺按 `src` 记 `W01`+`S04-S` 或仅 `S04-C`，本文件区块缺按 7.2 分流（承载关键字段 → `B05`，不承载 → `W01`）。

## 6. 执行流程

### 6.1 接收与文件集确认

1. 接收受检证书集、文件清单、客户要求清单，先按 4.1 / 4.4 完成核验。
2. 核对清单与实际文件：清单有实无 → 阻断 `B02`；实有清单无 → 警告 `W04`。
3. 去重与基准件指定：按文件指纹（MD5）与内容指纹（同注册号 + 同实验室 + 同日期）识别完全重复、内容重复、中英文双版、多格式双份，明确每组的基准件。
4. 两段式范围确认（L1/L2）：
   - 第①段 检索范围（D3）：以该 PPAP 项目为单位取全集，不限文件类型、不限编号目录。不得因"某固定目录下没看到"即判不存在，不得窄化为"本次对话中上传或引用的文件"。
   - 第②段 纳入范围（D5）：对第①段命中的每份试验报告逐份判定是否构成有效比对对象，须同时满足"客户本次 PPAP 要求清单含实验室资质审核"与"报告由供应商或其分供方委托出具"。客户直接提供的测试文档判为不纳入，并登记归属依据。
   - 两段结果均须写入报告：命中清单（第①段）+ 纳入/排除理由（第②段）。只写"不纳入"而无命中清单，视为范围收窄伪装，报告退回重做。
5. 确认文件可访问性与可判定内容；不可获得时记录问题并按严重级别判定。

## 7. 判定口径

### 7.1 数据正确性

关注单份证书内某信息本身是否真实、合理、符合基本逻辑。

| 编号 | 检查点 | 判据 | 典型异常 |
| --- | --- | --- | --- |
| K1 | 日期格式合法性 | 可归一为 `YYYY-MM-DD`；非法日期（如 `2030-02-30`）判错误 | 月份/日期越界 |
| K2 | 日期内部逻辑 | 仅判生效日期 < 截止日期；跨度上限不在此判，统一归 K3 | 生效晚于截止 |
| K3 | 日期跨度异常 | 跨度上限取第 11 节配置值（默认 6 年），超出记警告并要求核对原件 | 显示"有效期 20 年" |
| K4 | 注册号格式 | 形如 `CNAS L####`（字母 L + 4 位数字）；不符记警告 | `CNAS 1234`、无前缀 |
| K5 | 续期公告编号 | 若存在换版/续期公告号，须与注册号并存且不冲突 | 公告号被误当注册号 |
| K6 | 实验室名称合理性 | 含组织形式（有限公司/研究院/检测中心）等主体特征；不得为空白或纯符号 | 名称仅有"实验室"三字 |
| K7 | 地址合理性 | 含行政区划（省/市/区）+ 门牌或楼栋；邮编 6 位 | 地址缺城市名 |
| K8 | 认可依据 | 应为 `ISO/IEC 17025` 及 `CNAS-CL01`；出现 `ISO 17020` 等其他体系需登记 | 混用 17020/17025 |
| K9 | 单页完整性 | 页眉/页脚标注"共 x 页"须与实际页数一致；正文提及"附件"须有交付说明 | 标注共 2 页实际 1 页 |
| K10 | 文件命名 | 约定格式 `[实验室名称]_[CNAS]_[注册号]_[版本日期]`。不符约定但能唯一标识、同组多版本可区分 → 警告（改名可整改）；不能唯一标识或无法区分版本 → 与 `P-03` 基准件指定合并处理 | 文件名仅 `扫描件001.pdf` |

K 系列只判"数据本身是否合理"，不判"是否满足规则"。例如截止日期 2020-01-01 格式与逻辑均合法，K 系列不报错；"已过期"由 C2 判 NG，预检侧只登记 A-04 状态。

### 7.2 数据完整性

**必备要素与级别归属（11 项）**

| 级别归属 | 要素 |
| --- | --- |
| 阻断 `B03` / `B05` | 证书本体、截止日期、CNAS 图形标识、标题关键词（13 字）、实验室名称 |
| 警告（`W05` 读取失败 / `W01` 固有未载明） | 注册号、生效日期、地址 / 法人、印章、授权签字人 |
| `S01` 状态（不记级别） | 认可范围附件未随附（原 A-01） |

"读取失败"指本规则或文件的问题（裁切、模糊、分辨率不足、定位错误），可由重新提交消除 → 记 `W05`；"固有未载明"指证书本身无此字段，无法消除 → 记 `W01`。分不清时按"读取失败"处理，先跑满定位与渲染手段再定类。

> **「固有未载明」记 `W01` 的理由**：警告不拦截放行，记警告不会造成流程死锁，故不必为它设可整改性校验。责任侧仍为材料侧，但报告中须注明「供应商无法通过重新提交消除」，供正式审核区分。

逐项检查点见 6.4 的 `P-05`～`P-11`、`P-14`、`P-15`。

**其他完整性要求**

- 页面完整：扫描无缺角，裁切未切断文字行（尤其右侧地址、下部日期）。
- 图像可用性：主图 ≥150 ppi；关键条带放大后判据字段笔画可分辨。
- 附件关联：正文提及"见标有相同注册号的证书附件"时，须声明附件是否随附；未随附登记 `S01`（D4）。
- 联动文件可见性：项目级检索范围清单可获得。

允许合理推断（如由"（注册号：CNAS L4279）"推断注册号），但须写明依据、来源与置信度；禁止由文件名日期或行业惯例推断有效期。

### 7.5 严格标准及其边界

- 宁可严格误判，也不放过潜在不规范；但严格只作用于"是否登记问题"，不作用于"是否判字段缺失"——正确用法是多用警告、多写证据。
- **严格标准不得用于把"看起来很差"判成阻断**：阻断的唯一判据是 8.1（是否让某条规则无法得出唯一结论）。
- 未识别符号、未在白名单内的取值、未在别名表内的字段名，**不得自行归一化后放行**：写法明显不规范 → `W03`；确实定不了 → 按 8.3 原则 2 转视觉通道并穷尽定位。
- 所有推断性判断必须标注依据与置信度；低置信度推断不得单独构成阻断（总纲 8.6）。

### 8.2 通过规则

无阻断即通过，存在任一阻断即不通过并给出原因码；警告不影响结论但须 100% 列报并移交；状态项不参与判定但不得略去不记（总纲 8.2 / 8.3）。

本分则补充：报告须按责任侧分表列示——材料侧打回整改 / 提交方补正 / 解析侧核查（8.4）。

### 8.3 级别判定原则

1. **不可判定 > 不符合**：缺数据比数据写错更严重，审核层无法出具结论。
2. **"没找到" ≠ "不存在"**：文本层缺失或定位未见时，先转视觉通道并穷尽定位，只能记 `B01`「文件无法解析」或 `B05`「关键字段取不到可判定值」；读通后按实际改判，不得记"字段缺失"并引用为业务 NG。
3. **判据字段从严、支撑字段从宽**：C2/C3/C4 读取失败 → 阻断 `B05`；注册号、生效日期、地址、印章读取失败 → 警告 `W05`；上述支撑字段若为证书固有未载明 → 警告 `W01`。
4. **实验室名称单列为阻断**：名称虽非判据字段，但为证书主体识别主键，不可读则无法确认归属、无法执行 L2 → 记 `B03`。此条与原则 5 不冲突（原则 5 约束"比对结论不可得"，不含"主体识别不可得"）。
5. **联动结论不阻断**：L1/L2 比对结论不可得记警告 `W01`，不得因"无法比对机构"判证书不通过。
6. **状态不升格**：`S01` / `S03` 不得被严格标准升格为警告或阻断。附件缺失、机构待比对、时间窗待核、临近到期，均属"信息不完整但证书本身可判"。
7. **固有缺项记 `W01`，不设"可整改性校验"**：证书版式本身未载明的支撑字段（无签字栏、无注册号栏）记 `W01` 警告，并在影响栏注明"供应商无法通过重新提交消除"。**原 v1.3 的"定级前先判断能否整改、不能整改则不许定级"整条删除**——警告不再拦截放行，定级不会造成流程死锁。
8. **责任三侧**：材料侧（文件内容）/ 提交方（范围、版本、清单）/ 解析侧（可读性）。定级不等于定责；解析能力不足导致的不通过，责任侧为解析侧，报告中须写明。

### 8.4 责任侧与处理去向

| 责任侧 | 涉及预检项 | 处理去向 | 是否打回供应商 |
| --- | --- | --- | --- |
| 材料侧 | `P-04`、`P-06`～`P-19`（含全部判据字段与支撑字段、正确性、文件内一致性） | 打回整改（重扫 / 补页 / 补清晰版） | 是 |
| 提交方 | `P-01`、`P-03`、`P-20`、`P-21`、A-01～A-04 状态条目 | 补充清单 / 指定基准件 / 提供客户要求清单 / 补交附件 | 否 |
| 解析侧 | `P-02`、`P-05`（可打开性） | 转技术支持核查文件（损坏、加密、无文本层且渲染失败） | 否 |

**归口规则：**

1. 每个预检项**只能有一个主责任侧**，以 6.4 该行为准。
2. `P-05` 按成因二选一：文件不存在 → 提交方（清单有实无）；存在但打不开 / 为空 / 无有效版面结构 → 解析侧。
3. `P-16` 裁切致判据字段受损时，主责任侧随 `P-09`/`P-10`/`P-11` 定为材料侧，不重复计入解析侧。
4. 报告中"打回供应商整改"与"提交方补正 / 解析侧核查"必须分表列示。

## 10. 执行要求与约束

### 10.1 执行要求

1. 按本文件流程执行，不跳过适配核验（4.4）与三维度检查；不执行任何规则侧核验（总纲 2.3）。
2. 受检对象是本次提交的本类目证书集；L1/L2 必须站在项目级检索范围判定（D3），两者不得互相替代。
3. 三维度与严格标准的判定依据见第 7 节，级别判定见 8.1 与 8.3，不得另立口径。
4. 必须区分"数据不规范"与"文件无法解析"；证据定位到最小颗粒度：页码 + 版面锚点序号 + 条带区间。
5. 状态登记（A-01～A-04）、`S01` 结论、固有缺项（`W01`）必须单独登记，不得混入阻断清单。
6. 报告必须声明识别通道与分辨率；输出 Markdown，当前不要求程序化 Schema。
7. 警告项 100% 列报；状态项 100% 登记；不得以"无问题"代替"未检查"。

### 10.2 不要做 / 不要画

**读取与定位**

- 不要以"文本层字符数为 0"判定文件空白或不可辨识——必须转视觉通道。
- 不要在锚点 ⑤/⑥（名称、地址区）找生效/截止日期——日期只在锚点 ⑧。
- 不要"扫一眼没看到"就判字段不存在——必须先跑完 14.3 的四级降级定位流程。
- 不要低于 200 dpi 整页渲染就下"不可辨识"结论；条带二次核读 ≥300 dpi。
- 不要把单个字被水印压浅当作"标题不含关键词"或"整词不可读"。
- 不要输出未经证据支持的页码、版面区间或坐标。

**要素认定**

- 不要把 `ilac-MRA` 等同于 CNAS 标识（D1）。
- 不要把页脚重复出现的"中国合格评定国家认可委员会"当作 C4 证据，也不要用文件名或文档属性标题替代主标题行（D2）。
- 不要把圆形印章、授权签字人签名当作"证书在有效期内"的替代证据。
- 不要把文件名中的日期当作有效期证据——即使与生效日期一致，也只作佐证；不得用"CNAS 证书通常 6 年有效"反推到期日。
- 不要把"未提交认可范围附件"判为不通过（它不构成阻断）；但也**不要因此就不登记**——应按 `W01` + `S04-S` 记 1 条警告并写明缺哪一份附件。**更不要记 `S01`**（该对象属本次范围）。
- 不要把"证书本身未载明"的支撑字段判为阻断——记 `W01`，并注明供应商无法消除。
- 不要把供应商名称与证书实验室名称不同判为不一致（第三方检测属正常）。
- 不要把重复文件（MD5 相同、中英文双版）计为多份独立证书。

**状态登记纪律**

- 不要把**纯状态项（`A-02`～`A-04`）**计入警告数或阻断合计，也不要据此阻止进入正式审核或作为打回理由。**`A-01` 例外**：它配 `W01`，**计入警告数并进整改单**（见 `A-01` 条目与 3.1 表）。
- 不要在状态项未逐项判定时略过——每项须给出状态与依据。
- 不要写"不适用"——按总纲 3.1 只能写 `S01` / `S02` / `S03` / `S04`，也不要把 `S01` 当成"通过"。

**审核范围归属（D5）**

- 不要把客户（OEM）直接提供的测试文档当作供应商举证材料去比对机构。
- 不要因"该客户没要求实验室资质审核"跳过 D3 全集检索——必须先列命中清单再逐份过滤。
- 不要在无客户要求清单依据时自行假定"有要求"或"无要求"——须向用户显式确认。
- 不要因某固定编号目录（如 02-1/02-2）下没看到就判不存在设计验证报告；不要把"同批次"窄化为"本次对话上传或引用的文件"。

**结论表述**

- 不要把"预检通过"表述为"证书合规"或"审核通过"。
- 不要在 C5 不满足时输出 C2/C3/C4 的"不满足"——只能输出"无法判定"。
- 不要由 AI 直接给出"报告机构与资质实验室一致 / 不一致"的结论——L2 要求人工比对。
- 不要把置信度为"低"的判读作为阻断依据；不要虚构文件中未出现的字段值、认可范围项目或页码。
- 不要输出任何关于规则集、口径、字典的问题，也不要因"某判据执行不了"而登记规则侧缺口——本预检不评规则（总纲 2.3）。
- 不要对"项目下应有但本次未提交"下缺失结论——本次提交范围即判定边界。但**也不得因此就不登记**：属本次范围而应收未到的，按总纲 3.2.4 登记 `S04-S`（配 `W01`）或 `S04-C`。"不下缺失结论"与"登记 S04"是两件事，前者管话术与级别，后者管状态可追溯。

**执行纪律**

1. 必须逐锚点过一遍，报告中体现每个判据字段命中的锚点序号。
2. 日期只在 ⑧ 找，不在 ⑤/⑥ 找（在名称/地址区找日期是本域已确认的定位误区）。
3. 分辨率门槛：整页 ≥200 dpi；判据字段二次核读按纵向条带放大至 ≥300 dpi。低于门槛的识别结果不得用于"不可辨识"结论。
4. 水印容错：页面上常叠数十个 1-bit "CNAS" 水印蒙版，造成个别字淡化；单字淡化不等于整词不可读，须放大或调整局部对比度复原，不得据此判 C3/C4 不满足。
