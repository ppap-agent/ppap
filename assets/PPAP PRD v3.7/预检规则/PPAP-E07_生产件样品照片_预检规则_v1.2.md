## 1. 目的与边界

**目的**：判定提交物**是否为可读的图片**——即预检能否确认「这是一份样品照片」，并**强制在报告中留下人工复核提示**。

**这是 41 个条目中结构判据最弱的一条**，必须说清：预检对照片**只能确认形态**，不能确认内容。UAES 规则原文对这一类目也只要求「提交生产件样品照片」，没有规定张数、角度、分辨率——因此预检的正确产出是「形态合格 + 明确移交人工」，而不是模拟图像审核。

**边界三条**：

1. 本类目**不判实测值**、不判图像内容，故不产生 `B06`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅 UAES 一家），客户差异层为预留位。

| 项 | 要求 |

## 4. 判定项（2 项）

> 判据文本以 `00-A §2.1` 为准，本节只把它落成可执行判定。

| # | 判定内容 | 判定方式 | 不满足时 | 来源条款 |
| --- | --- | --- | --- | --- |
| S1 | 提交文件为**图片格式**（可打开、非损坏） | 文件头识别 + 解码验证 + 像素尺寸读取 | 非图片 → **`B03`**；损坏 → `B01` | 1 |
| S2 | 报告须附提示「需人工确认样品照片是否符合要求」 | 检查报告 10.2 是否含该提示句 | 未附 → **报告不合格**（不记原因码） | 1 |

**S2 为何不是原因码**：它是**预检自身的产出义务**，不是对提交物的判定。若报告漏了这句，问题在预检侧，不在供应商侧——因此不产生 `B`/`W` 码，而是判该份报告不合格、须重出（总纲 8.1 的「报告完整性」约束）。

**S1 为何落 `B03`**：`B03` 在总纲 5.2 的标准语义是「识别失败」。本条目中它的具体含义是「**提交物形态与识别出的文件类型不匹配**」——被识别为「生产件样品照片」但提交的不是图片，判定链在这里断掉，无法进入任何结构校验。报告措辞须写「提交物非图片格式，本类目无法承载判定」，不得只写「识别失败」四个字。

## 5. 判定细则

**5.1 图片格式白名单（§3 表）**

白名单之外的扩展名（如 `docx` / `xlsx` / `pptx` / `dwg` / `zip`）一律记 `B03`。其中：

- `zip` / `rar` / `7z` 压缩包：**须先解包再逐张检测**，不得因「是压缩包」直接判 `B03`。
- `dwg` / `step` 等三维或矢量工程文件：不属照片，记 `B03`。

**5.2 纯图 PDF 的受理规则**

满足以下**全部**条件时，按图片受理：

1. 每页最多一张主图像，且该图像面积占页面 80% 以上。
2. 文字层为空，或提取结果仅为页眉页脚式的少量字符（< 20 字）。

受理后：

- 结论按图片判，10.2 注明「以 PDF 封装的图片，按图片格式受理」。
- **不得**因「扩展名不是图片」判 `B03`。

不满足全部条件（例如是带大量文字的排版文档内嵌照片）时，按 §5.3 处理。

**5.3 多页含文 PDF → `B03`**

被识别为样品照片、但提交物是可提取文字的多页文档时，记 `B03`，并在报告中加一句提示：「提交物为文档而非照片；若确含照片，请单独提取为图片格式后重新提交，或人工指定文件类型后重跑（总纲 4.9）」。

**5.4 不判图像内容（本分则最容易被越界的一处）**

以下项目**一律 `S03`，不记问题、不影响结论**：

| 不得判的项 | 理由 |
| --- | --- |
| 照片张数是否足够 | 规则原文未规定张数 |
| 拍摄角度、光照、背景 | 属工程判断 |
| 分辨率、清晰度是否达标 | 规则原文未规定阈值 |
| 是否覆盖全部特征面、是否体现特殊特性 | 属工程判断 |
| 照片是否为本批次实物（非旧图复用） | 属真实性核查，超出预检能力 |

极低分辨率（如小于 200×200 像素）**只记入 10.2 提示**，**不记任何原因码**。

**5.5 客户差异层为空时的兜底**

本期 `E07` 只有 UAES 一条路由。若将来出现其它客户的样品照片规则（例如规定了张数与角度），**不得**套用本分则的 2 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

## 6. 执行流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（UAES, 生产件样品照片），置信度 ≥ 中 | 路由 = `U13` / L2 |
| 2 | 压缩包先解包；读取文件头与扩展名 | 文件清单 |
| 3 | 逐张解码验证，读像素尺寸 | 可读 / 损坏 / 非图片 |
| 4 | 按 §5.2 判纯图 PDF；按 §5.3 判多页含文 PDF | `B03` 或受理 |
| 5 | 按 §4 表定级 | `B03` / `B01` / 通过 |
| 6 | **必须**在 10.2 写入 S2 提示句 | 报告（缺此句即不合格） |
| 7 | 按总纲第 11 节十章模板出报告 | 报告 |

**第 6 步不可省略**：即使结论为通过，也必须留下人工复核提示。本类目的预检结论**永远是「形态合格」而非「照片合格」**，报告不得让读者误以为照片内容已被审核。

## 8. 级别与原因码

级别定义与原因码含义见总纲 5.2 / 8.1，本节只列本类目的典型情形。

| 原因码 | 本类目典型情形 | 责任侧 |
| --- | --- | --- |
| `B03` | 提交物非图片格式（文档、工程图、三维文件）；多页含文 PDF | 提交方 |
| `B01` | 图片损坏 / 0 字节 / 解码失败 / 加密；多张中含任一损坏 | 材料侧 |
| `S03` | 张数、角度、清晰度、内容覆盖——**移交正式审核，不记问题** | 正式审核 |

**本类目不产生 `B05` / `B06` / `W01` / `W02` / `W03` / `W06`**：无结构块、无字段、无数值。
**本类目唯一可能产生的 `W` 码是 `W05`**：解码成功但元数据异常（如 EXIF 损坏），记 `W05` 并在 10.2 说明。

## 9. 报告与输出

按总纲第 11 节「统一报告模板 v1.0」十章输出，本分则不再另行定义章序。

| 挂载位置 | 内容 |
| --- | --- |
| 第二章 | 文件级结论列填「路由 `U13` / L2」；本类目无同批组，该列填 `—` |
| 第四章 | 阻断项：`B03`（非图片）/ `B01`（损坏） |
| 第九章 | 2 项结构判据结果（`RS-U13-S1`~`S2`），S2 须标明提示句是否已写入 |
| 10.1 | 提交物清单：文件名、识别格式、像素尺寸、可读性、是否解包所得 |
| 10.2 | 解析说明 + **S2 强制提示句**：如需确认样品照片是否符合要求，须人工复核 |

**结论口径**：任一 `B` 码 → 不通过；仅 `W` 码 → 通过；S2 未满足 → 该份报告不合格，须重出。

**识别置信度低不等于「未执行」**：低置信度按总纲 4.8 记 `B03`（识别失败 · 身份不可归属），出路为 4.9 人工指定。总纲 5.1 已把「未执行」收窄为**单一成因**（该条目既无分则也无 `required_structure`），识别置信度不在此列——把它记成「未执行」等于让一份认不出是谁的文件**免检放行**。

## 10. 不要做

1. 不要判照片拍得清不清楚、角度对不对、够不够张数——那是 `S03`。
2. 不要判照片是否体现了特殊特性或覆盖全部特征面——那是工程判断，属 `S03`。
3. 不要因为扩展名不是图片就判 `B03` 而不看一眼内容——纯图 PDF 必须按图片受理（§5.2）。
4. 不要因为「是压缩包」直接判 `B03`——须先解包（§5.1）。
5. 不要在结论为通过时省略 S2 的人工复核提示——这是本类目唯一不可省的输出。
6. 不要用「识别失败」四个字代替具体措辞（§4 末段）。
7. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
8. 不要因本批次缺其它文件记任何问题——本类目无同批依赖。
9. 不要在报告里出现「疑似」「可能」类未定级表述。
10. 不要新增章、调整章序或自定义报告字段。
11. 不要修改 `00-A §2.1` 的判据文本；判据有误应先改 00-A，再同步本分则。

## 11. 可配置项

| 项 | 是否可配置 | 说明 |
| --- | --- | --- |
| S1 图片格式白名单 | 可配置 | 只允许**扩充**格式，不得删减 |
| 纯图 PDF 的图像面积阈值（80%） | 可配置（不得低于 60%） | 降低阈值会把图文混排文档误当照片 |
| 纯图 PDF 的文字层字数阈值（20 字） | 可配置（不得高于 50） | — |
| S2 提示句文案 | **不可配置** | 提示句是义务本体，改写即等于取消 |
| 置信度门槛 | 可配置（不低于「中」） | **低于中 → `B03` 识别失败（总纲 4.8）**；**不得返回「未执行」**——其成因已由总纲 5.1 收窄为唯一一种 |
| 深度档 | **不适用** | 深度档只对 L3 试探（总纲 7.7）；本条目为 L2 |
