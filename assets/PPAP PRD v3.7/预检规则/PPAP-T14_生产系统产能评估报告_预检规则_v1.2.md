## 1. 目的与边界

**目的**：判定这份《生产系统产能评估报告》**是否具备可被理想审核的产能测算结构**——即评估表是否存在、5 个身份字段是否填全、风险列与措施列是否齐备，以及**三条产能算式是否算得平**。

**这是 22 条 L2 路由中唯一会产生 `B06` 的类目**，必须说清区别：

| 判定类型 | 本分则的处理 | 依据 |
| --- | --- | --- |
| 字段是否存在、是否填了 | `B05` / `W02` | 总纲 7.2 |
| 风险列与总体结论是否**逻辑自洽** | `W06`（S5） | 内部不自洽，不影响取数 |
| 三条算式是否**代数自洽** | **`B06`**（S6 / S7 / S8） | 总纲 7.1 第 2 优先级「正确性」；`00-A §4.2.3` 明确「计算关系不符」**不得放宽** |

**S5 判 `W06`、S6~S8 判 `B06`**：前者是「说得好不好」（高风险的项却写了总体通过），属内部不自洽；后者是「数算得对不对」，属代数自洽。**算不平的产能表无法被审核**——任何下游结论都建立在错误基数上，这正是预检必须阻断的唯一情形。

**边界三条**：

1. 本类目**只复算给定算式，不评价算式的合理性**——产能是否够用、口径是否合理是 `S03`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅理想一家），客户差异层为预留位。

## 5. 判定细则

**5.1 表标题与列名近义通过**

| 应有项 | 可接受的写法（示例，非穷举） |
| --- | --- |
| 零件产能评估表 | 产能评估表 / 产能评估 / 生产系统产能评估 / 产能分析表 |
| 零件名称 / 零件号 / 供应商名称 / 供应商编码 | 产品名称、件号、供方名称、供应商代码 |
| 产能评估总体结论 | 总体结论 / 评估结论 / 产能结论 |
| 线体/工序类别 | 线体类别 / 工序类别 / 产线工序 |
| SOP+1 / SOP+2 / SOP+3 达成风险 | 达成风险（SOP+1）、SOP1风险、量产风险 |
| 后续措施 | 后续计划 / 改善措施 / 应对措施 |
| 单线体/工序总产出 JPH | JPH / 单线产出 / 每小时产出 / 节拍产出 |
| 净利用时间 | 有效利用时间 / 净工时 / 有效工时 |
| 参与测试线体数量 | 线体数量 / 测试线体数 / 参与线体数 |
| 线体/工序预估月度产能 | 月度产能 / 预估月产能 / 月产出 |
| 现有线体数 | 线体数量 / 现有产线数 |
| 班次/天 | 每日班次 / 班次 |
| 每班净利用时间 | 每班有效工时 / 单班净时间 |
| 每月标准工作天数 | 月工作天数 / 标准工作天数 |
| 累积良率 | 综合良率 / 累计良率 / 总良率 |

近义**只用于确认列存在**。

**5.2 S3 与 S6~S8 的关系（避免重复计问题）**

1. S3 是**通用行内完整性**判定（行键有值则同行全列非空），其中包含 S6~S8 涉及的数值列。
2. 若同一个空单元格同时触发 S3 与某条算式的「无法复算」，**只记 S3 的 `W02`**，算式侧记「无法复算」，**不另记原因码**。
3. 算式侧只在**列齐、值齐、算不平**时才记 `B06`。

**5.3 复算的执行范围**

| 情形 | 处理 |
| --- | --- |
| 该行任一参与列非数值（如 `-`、`待定`、空） | 跳过该行，**不记 `B06`**；若为空则按 §5.2 处理 |
| 分母为 0 或空 | 跳过该行，记 `W03`（除法基数无效），**不记 `B06`** |
| 结果为负 | 记 `B06`（代数上不可能） |
| 全部行均可复算且均在容差内 | 通过 |
| 任一行超出容差 | `B06`，报告须列出该行行号、两个数值、差值 |

**5.4 容差规则（`B06` 是否会误报，全看这一节）**

复算结果与表内值比较，按以下顺序取容差：

| 优先级 | 条件 | 容差 |
| --- | --- | --- |
| 1 | 能取到该单元格的**显示小数位数 k** | `0.5 × 10^-k`（半个末位） |
| 2 | 取不到显示精度（PDF / 扫描件） | **相对误差 ≤ 1%** |
| 3 | 结果为 0 或极小（< 10^-6） | 绝对误差 ≤ 10^-6 |

**百分比口径统一**：

1. 良率、累积良率若带 `%`，按 `值 ÷ 100` 参与运算。
2. 同一列内口径混用（有的写 `95%`、有的写 `0.95`）时，**先统一再复算**，并记 `W03`（写法不统一）；复算仍不平 → `B06`。
3. **不得**因口径写法不同直接判 `B06`——`B06` 只给「统一口径后仍算不平」。

**5.5 「无法复算」的处置**

以下情形记「**无法复算**」，**不记 `B06`**，报告 10.2 须说明原因：

1. 某参与列不存在（此时已记 `B05`）。
2. 某参与列为空（此时已记 `W02` 或 S3 的 `W02`）。
3. 「累积良率」无法定位到具体列或单元格。
4. 数值层不可读（`W05`）。
5. 该行明确标注「不适用」且有说明。

**「无法复算」不是通过**：报告须在第九章该算式项下写「无法复算（原因：…）」，**不得**写「通过」。

**5.6 S5 的逻辑自洽判定**

| 三风险列取值 | 总体结论 | 后续措施 | 判定 |
| --- | --- | --- | --- |
| 全为低风险 | 任意 | 任意 | 通过（S5 不触发） |
| 任一为「中风险」或「高风险」 | 含「条件通过」或「未通过」 | 非空 | 通过 |
| 任一为「中风险」或「高风险」 | 含「通过」（不含「条件」） | — | `W06`（高风险项却判通过） |
| 任一为「中风险」或「高风险」 | 含「条件通过 / 未通过」 | 空 | `W06`（风险未闭环） |

**S5 只判逻辑自洽，不判风险评得对不对**——把「高风险」评成「低风险」属 `S03`，预检不掌握评审依据。

**5.7 客户差异层为空时的兜底**

本期 `T14` 只有理想一条路由。若将来出现其它客户的产能评估规则，**不得**套用本分则的 8 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

按总纲第 11 节「统一报告模板 v1.0」十章输出，本分则不再另行定义章序。

| 挂载位置 | 内容 |

## 10. 不要做

1. 不要判产能是否够用、风险评级是否恰当、后续措施是否有效——那是 `S03`。
2. 不要在参与列缺失或为空时记 `B06`——先记 `B05` / `W02`（§5.5）。
3. 不要用绝对相等判定算式结果——必须套用 §5.4 容差。
4. 不要因百分比写法不同直接判 `B06`——先统一口径再复算（§5.4）。
5. 不要对分母为 0 的行判 `B06`——记 `W03` 并跳过（§5.3）。
6. 不要跳过非数值行并据此判不通过——跳过不等于缺陷。
7. 不要把「无法复算」写成「通过」（§5.5 末段）。
8. 不要重复计 S3 与算式侧的空值问题（§5.2）。
9. 不要判风险评级本身是否恰当（§5.6 末段）。
10. 不要用设备清单（`T13`）或过程能力（`PPAP-07`）的判定项套本类目（§2）。
11. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
12. 不要在报告里出现「疑似」「可能」类未定级表述。
13. 不要新增章、调整章序或自定义报告字段。
14. 不要修改 `00-A §2.2` 的判据文本；判据有误应先改 00-A，再同步本分则。

## 11. 可配置项

| 项 | 是否可配置 | 说明 |
| --- | --- | --- |
| 8 项结构判据与三条算式 | **不可配置** | 来自客户规则；改算式即等于改规则 |
| 表标题与列名近义词典（§5.1） | 可配置 | 只允许**扩充**，不得删减 |
| 容差规则（§5.4） | **不可配置为「无容差」** | 无容差必然误报；只允许在 1% 基础上收紧至更小，不得放大至 5% 以上 |
| 百分比口径统一方式 | 可配置 | 只允许按模板口径更新换算方式 |
| 触发 S5 的风险取值（中风险 / 高风险） | 可配置 | 只允许按理想模板口径更新 |
| 置信度门槛 | 可配置（不低于「中」） | **低于中 → `B03` 识别失败（总纲 4.8）**；**不得返回「未执行」**——其成因已由总纲 5.1 收窄为唯一一种 |
| 深度档 | **不适用** | 深度档只对 L3 试探（总纲 7.7）；本条目为 L2 |
