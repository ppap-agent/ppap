## 1. 目的与边界

**目的**：判定这份《试装单》**是否具备可被 UAES 审核的三个基本区域**（流转记录 / 试装结论 / 检验结论），以及结论区**是否已勾选、勾的是哪一项**。

**不是**判定试装结果好不好。规则原文对未通过判「不通过」，但那是**业务结论**——预检只记录「勾没勾、勾的什么」，是否应当放行由正式审核决定。这是本类目最重要的口径校准（`00-A §4.2.1`）。

**边界三条**：

1. 本类目**不判实测值**，故不产生 `B06`。
2. 本类目**无跨文件依赖**，不得因本批次缺其它文件记任何问题。
3. 本类目**没有分则专属的客户差异**（本期仅 UAES 一家），客户差异层为预留位。

## 4. 判定项（6 项）

> 判据文本以 `00-A §2.1` 为准，本节只把它落成可执行判定。

| # | 判定内容 | 判定方式 | 不满足时 | 来源条款 |
| --- | --- | --- | --- | --- |
| S1 | 含「流转记录」区域 | 区域标题近义匹配 | **`B05`** | 1 |
| S2 | 含「试装结论」区域 | 同上 | **`B05`** | 1 |
| S3 | 含「检验结论」区域 | 同上 | **`B05`** | 1 |
| S4 | 流转记录含「流程结束」与「流程完成」两项 | 区域内文本匹配（两项须同时存在） | `W01` | 2 |
| S5 | 试装结论已勾选「通过」 | 勾选状态判读 | 未勾选 → `W02`；勾「不通过」→ **`S03`** | 3 |
| S6 | 检验结论已勾选「合格」 | 同上 | 未勾选 → `W02`；勾「不合格」→ **`S03`** | 4 |

**S5/S6 的定级是本分则的关键判断，务必按原文执行**：

- **未勾选 / 无法判读 → `W02`**：属「该填未填」，是缺值，供应商可补。
- **勾了「不通过」/「不合格」→ `S03`**：预检**只记录事实**，不据此判整份文件不通过。理由：规则原文的「不通过」是**业务结论**，预检的职责是「能否被可靠审核」——勾选已存在、可读、可判断方向，说明这份文件**完全可审核**。试装没通过是供应商要整改的事，不是预检要阻断的事。**预检若在此处判阻断，等于替 UAES 做了放行决策。**

## 5. 判定细则

**5.1 区域标题近义通过**

区域标题**意思相近即视为存在**：

| 应有区域 | 可接受的标题写法（示例，非穷举） |
| --- | --- |
| 流转记录 | 流程记录 / 审批流转 / 流转信息 / 流程履历 |
| 试装结论 | 试装结果 / 装配结论 / 试装判定 |
| 检验结论 | 检验结果 / 检查结论 / 质检结论 |

近义**只用于确认区域存在**。区域内的勾选状态另按 §5.3 判读，不得因「标题近义通过」而连带放行结论项。

**5.2 区域存在但区域内全空 → `W02`**

区域在、内容空，属「有结构无值」，按总纲 7.2 记 `W02`。**不得**升为 `B05`——`B05` 只给「区域根本不存在」。

**5.3 勾选状态的三态判读**

| 判读结果 | 判定 | 说明 |
| --- | --- | --- |
| 已勾选「通过」/「合格」 | S5/S6 通过 | — |
| 明确未勾选（有框无勾，且同组其它选项被勾） | `W02` | 缺值，供应商可补 |
| 勾了「不通过」/「不合格」 | `S03` | 记录事实，不影响结论 |
| 无勾选框结构（纯文字描述） | `W02` | 无法确认结论方向，须补勾选 |
| 图形不可辨（扫描模糊） | `W02` + `W05` | `W05` 记解析侧，`W02` 记缺值 |

**「无法判读」不得一律记为「未勾选」**：前者是解析问题（记 `W05`），后者是材料问题（记 `W02`）。二者在整改责任上完全不同。

**5.4 不得代客户判定「该不该通过」**

以下项目**一律 `S03`，不记问题、不影响结论**：

1. 试装结论为「通过」是否恰当（试装条件是否充分、样本量是否足够）。
2. 检验结论为「合格」是否恰当（检验项目是否齐全、判定依据是否有效）。
3. 试装与检验结论之间是否存在矛盾（例如试装通过但检验不合格）——这是**业务一致性**，不是结构缺陷，记 `S03` 并写明两处取值即可，不判阻断。

**5.5 客户差异层为空时的兜底**

本期 `E09` 只有 UAES 一条路由。若将来出现其它客户的试装单规则，**不得**套用本分则的 6 项——须先在 00-A §1 登记、§2 抽 `required_structure`，再在本分则 §7 增列差异层。

## 6. 执行流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 识别：（客户, 文件类型）=（UAES, 试装单），置信度 ≥ 中 | 路由 = `U15` / L2 |
| 2 | 定位三个区域（§5.1 近义表） | 每区域：存在 / 不存在 |
| 3 | 检查流转记录是否含「流程结束」「流程完成」 | `W01` 或通过 |
| 4 | 判读试装结论与检验结论的勾选状态（§5.3 三态） | 通过 / `W02` / `S03` |
| 5 | 按 §4 表定级，汇总问题清单 | `B05` / `W01` / `W02` / `S03` |
| 6 | 按总纲第 11 节十章模板出报告；区域与勾选结果挂 10.1 | 报告 |

**执行顺序不可调换**：先判区域存在性（S1~S3），再判区内内容（S4~S6）。区域不存在时区内项一律记「无法判定」，不得逐项报缺失。

## 8. 级别与原因码

级别定义与原因码含义见总纲 5.2 / 8.1，本节只列本类目的典型情形。

| 原因码 | 本类目典型情形 | 责任侧 |
| --- | --- | --- |
| `B05` | 三个区域任一缺失 | 材料侧 |
| `W01` | 流转记录缺「流程结束」或「流程完成」；区域存在但区内全空 | 材料侧 |
| `W02` | 结论区未勾选 / 无勾选框结构 / 勾选不可辨 | 材料侧 |
| `B01` | 文件损坏 / 加密 / 扫描件无文字层 | 材料侧 |
| `B03` | 客户或文件类型识别不出 | 提交方 |
| `W05` | 勾选图形不可辨，结论方向无法确认 | 解析侧 |
| `S03` | 试装勾「不通过」、检验勾「不合格」；结论是否恰当、两结论是否矛盾——**记录事实，移交正式审核，不判阻断** | 正式审核 |

**本类目不产生 `B06`**：无数值比对、无跨文件比对、无代数关系。
**本类目 `S03` 不影响结论**：`S03` 不是结论码，只写进报告 10.x 供正式审核参考。

按总纲第 11 节「统一报告模板 v1.0」十章输出，本分则不再另行定义章序。

| 挂载位置 | 内容 |

| 第四章 | 阻断项：仅 S1~S3 的区域缺失 |
| 第五章 | 警告项：S4 缺项、区内全空、结论未勾选 |
| 第九章 | 6 项结构判据逐项结果（`RS-U15-S1`~`S6`），S5/S6 须标明「勾选项名称」 |
| 10.1 | 区域与勾选结果表：区域名、实际标题、命中方式、区内是否非空、勾选项 |

## 10. 不要做

1. 不要因为试装结论勾了「不通过」就把整份文件判不通过——记 `S03`（§4 末段）。
2. 不要因为检验结论勾了「不合格」就判阻断——同上。
3. 不要用「无法判读」代替「未勾选」，反之亦然（§5.3）。
4. 不要判试装条件是否充分、检验项目是否齐全、判定依据是否有效——那是 `S03`。
5. 不要判试装结论与检验结论之间是否矛盾并据此阻断——记 `S03` 说明即可（§5.4 第 3 项）。
6. 不要在区域不存在时逐项报区内缺失。
7. 不要用模板版式反推客户或文件类型（总纲 4.5 识别禁令）。
8. 不要因本批次缺其它文件记任何问题——本类目无同批依赖。
9. 不要在报告里出现「疑似」「可能」类未定级表述。
10. 不要新增章、调整章序或自定义报告字段。
11. 不要修改 `00-A §2.1` 的判据文本；判据有误应先改 00-A，再同步本分则。
